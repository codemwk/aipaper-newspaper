[11/3] AI 모델: 메이퇀 LongCat-2.5 — 1.6조 파라미터, 그림도 ‘글자처럼’ 읽는 에이전트 모델. 전 과정을 중국산 칩으로 학습했고, 에이전트의 ‘실패 기록’을 다시 숙제로 만든다

배달 플랫폼 메이퇀이 11/1~2 LongCat-2.5를 공개했다. 총 1.6조·토큰당 약 480억 활성 파라미터의 네이티브 멀티모달 모델로, 이미지를 이산 토큰으로 바꿔 글과 같은 줄에서 처리한다. 장기 코딩 에이전트용 강화학습, 실제 에이전트 실패 궤적을 재현 가능한 학습 과제로 바꾸는 파이프라인, 국산 가속기에서 4비트(W4A4) 추론. 자체 표에선 Claude-Opus-4.8과 Opus-5 사이. longcat.ai와 API로 제공.

분류: AI 모델

한줄 요약

LongCat-2.5는 “긴 일을 끝까지 하는” 에이전트를 목표로 한 멀티모달 모델이다. 메이퇀은 학습 전 과정을 중국산 AI 가속기에서 돌렸다고 강조한다(LongCat 블로그, 메이퇀 뉴스).

무엇이 새로운가 (코드 없이)

  • 그림을 글자처럼: 이미지를 여러 단계의 ‘시각 단어’(이산 토큰)로 바꿔, 텍스트와 같은 형식으로 한 뼈대에 넣는다. 그래서 별도 비전 인코더 없이 웹페이지·3D 전시 페이지 같은 시각 코딩을 한다.
  • 실패를 숙제로: 실제 에이전트가 실패한 궤적을 모아, 통과 여부를 자동 검증할 수 있는 학습 과제로 바꿔 계속 추가한다. GitHub PR·이슈에서 과제와 환경을 합성하고, 테스트로 검증.
  • 편법 차단: 과제 환경에서 인터넷을 끄고 git 기록·캐시를 지운 뒤, LLM 심판이 궤적을 감사해 ‘점수만 따는’ 꼼수를 걸러낸다.
  • 국산 칩 최적화: 장기 문맥 학습, 4비트 가중치·활성값(W4A4) 추론. W8A8 대비 프리필 처리량 +43.3%, 디코드 +42.8%(회사 수치).

왜 중요한가

  • 순위보다 흥미로운 건 제조법이다. ‘실패 궤적 → 검증 가능한 과제’ 루프와 ‘보상 해킹 감사’는 에이전트 모델을 만드는 쪽이 공통으로 겪는 문제에 대한 구체적 답이다.
  • 수출 규제 속에서 1조급 모델을 국산 칩으로 학습·4비트 서빙까지 했다는 건 중국 AI 인프라의 자립 신호. 사용은 longcat.ai 웹과 동시 공개된 API로 가능하다(가중치 공개는 이번 발표에 없음).
