[11/3] GitHub 트렌드: 에이전트가 ‘폰 안으로’ — 숨은 화면에서 앱을 대신 조작하는 Mika(★5천, 닷새), 루팅 없이 APK 하나로 DeepSeek Harness를 돌리는 DSH-Android. 결제 직전엔 멈춘다

이번 주 GitHub 급상승의 한 축은 안드로이드 에이전트다. Mika(10/29 생성, 11/3 기준 ★약 5,200, Apache-2.0)는 별도의 ‘백그라운드 화면’에서 앱과 웹을 사람처럼 보고 눌러 일을 끝낸다 — 쓰는 동안 내 화면은 그대로. DSH-Android(★약 750)는 루팅·Termux 없이 APK 하나로 DeepSeek Harness를 폰에서 돌리고, 조건부 자동화와 내장 리눅스 환경까지. 둘 다 결제 전 확인·서버 없음 등 안전장치를 내세우지만, 권한 감사 도구는 아직 뒤처져 있다.

분류: GitHub 트렌드

한줄 요약

지난번 저장하신 DeepSeek Harness와 이어지는 소식이다. 데스크톱·코딩용이던 에이전트가 이번 주 스마트폰 앱 조작으로 넘어왔다(Claracle W45 정리, Mika, DSH-Android).

Mika — “한 문장 말하면 폰이 알아서”

  • 숨은 화면에서 작업: 앱을 열고, 탭하고, 입력하고, 스크롤하는 걸 별도 백그라운드 화면에서 한다. 나는 폰을 평소처럼 쓰고, 작은 실시간 창으로 지켜볼 수 있다.
  • 앱 API 불필요: 사람처럼 화면을 보고 버튼을 찾으니 앱별 연동이 필요 없다. 내장 브라우저에선 보고 있는 페이지에서 바로 시키고, 화면을 터치하면 멈춘다.
  • 예시: “오늘 단톡방에서 무슨 얘기 했어?” 요약, “30달러 이하 별점 4.5+ 충전기” → 장바구니에 넣고 결제 직전에 멈춤, 배달 주문은 결제 전에 물어봄.
  • 쓸수록 선호를 기억하고, 끝낸 작업을 ‘스킬’로 저장. Mika 서버 없음 — 내 모델 API 키나 ChatGPT·xAI·OpenRouter 계정으로 로그인.

DSH-Android — “폰 위의 진짜 하네스”

  • DeepSeek의 에이전트 하네스(dsh)를 포크 없이 그대로 APK에 내장. 스킬·MCP·서브에이전트·웹 검색 사용 가능.
  • 화면 읽기·조작(접근성 서비스), 파일 정리, 밝기·와이파이·알람 같은 시스템 설정, 조건부 자동화(와이파이 연결·충전 시작·특정 장소 도착·알림 수신 시).
  • 폰 안에 리눅스 환경이 있어 파이썬·스크립트 실행. 안드로이드 14+에선 Shizuku를 켜면 가상 화면에서 작업해 내 화면을 안 가린다. DeepSeek 외 OpenAI·Claude·Gemini·Grok 등 모델 선택 가능.

조심할 점

  • 두 프로젝트 모두 접근성 권한 = 화면의 모든 것을 읽고 누를 수 있는 권한을 요구한다. Claracle 주간 분석도 “에이전트에게 손을 주는 속도를, 그 손을 지켜보는 도구(행동 로그·권한 경계·되돌리기)가 못 따라간다”고 짚었다.
  • 데모 상당수가 위챗·샤오훙수 등 중국 앱 기준. 메신저 자동 발송, 구직 사이트 자동 인사 같은 기능은 각 서비스 약관과 충돌할 수 있다.
  • 실사용은 보조 폰이나 결제 수단 없는 계정에서 먼저 시험해 보는 게 현실적이다.
