[10/24] 디자인/UI·UX: Canva 첫 자체 이미지 모델 ‘Craft’ — 그리기 전에 ‘배치 계획서’부터 쓴다. 템플릿 수백만 장으로 학습, 레이어 분리까지 염두

Canva가 사내 연구소 Canva Research에서 처음부터 학습한 이미지 모델 Craft를 공개(전 사용자, 공개 API; Canva MCP는 곧). 2단계 구조: 먼저 ‘계획 모델’이 요소·위치·크기·위계·들어갈 글자를 적은 구성안을 쓰고, 다음 ‘렌더링 모델’이 최대 2K·30개 이상 비율로 그린다. 사진보다 포스터·SNS·메뉴·인포그래픽 같은 사람이 만든 템플릿 비중을 높여 학습, 55개 언어 글자 렌더링. JSON 바운딩 박스로 Magic Layers 편집 레이어 변환이 빨라진다고. 더 싼 Craft-fast·ultrafast 예고.

분류: 디자인/UI·UX

한줄 요약

Canva가 남의 모델을 빌려 쓰던 단계를 지나 자체 이미지 모델 Craft를 냈다. 특징은 “잘 그린다”보다 “디자인처럼 짠다”에 있다(Canva 뉴스룸).

어떻게 다른가: 계획 → 렌더링

  • 계획 모델: 프롬프트를 읽고 “어떤 요소가, 어디에, 얼마나 크게, 무엇이 더 중요하게, 어떤 글자가” 들어갈지 구성안을 쓴다
  • 렌더링 모델: 그 구성안을 최대 2K, 30개 이상 비율(직접 입력도 가능)로 그린다

구성을 먼저 정하니 글자가 읽히고, 물체가 정확한 자리에 가고, 일부만 바꾸는 수정이 쉬워진다는 설명이다. 같은 구조 덕에 생성 이미지를 Magic Layers로 ‘편집 가능한 요소’로 쪼개기도 더 빠르고 정확하다(JSON 바운딩 박스).

무엇으로 배웠나

  • 사진 위주가 아니라 Canva 라이브러리의 사람이 만든 템플릿 수백만 장(포스터, SNS, 발표 자료, 인포그래픽, 메뉴, 타이포 중심 레이아웃) 비중을 높였다
  • 사내 전문 디자이너가 연구자들과 2만 5,000쌍 이상 비교 평가. 자동 평가와 디자이너 판단이 다르면 디자이너 편을 들었다고
  • 55개 언어로 이미지 속 글자 생성

어디서 쓰나

  • Canva Dream Lab(전 세계 전 사용자), 공개 API(마케팅·쇼핑몰·광고·인쇄 서비스에 내장)
  • Canva MCP는 “곧” — 에이전트가 큰 작업 중 한 단계로 런칭 그래픽을 만드는 식
  • 더 빠르고 싼 Craft-fast / Craft-ultrafast 예고. 가격은 이번 발표에 없다

왜 중요한가

Krea·Ideogram·Canva가 같은 주에 보여 준 공통점: 이미지 AI의 경쟁 축이 화질에서 ‘고칠 수 있음’(레이어·벡터·계획)으로 넘어가고 있다. 디자이너 입장에선 “한 방에 완성”보다 “다음 단계로 넘길 수 있는 결과물”이 더 값지다.
