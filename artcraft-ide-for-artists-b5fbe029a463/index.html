[10/18] GitHub 트렌드: ArtCraft(~3.2만★, 주간 +2만) — ‘프롬프트 대신 크래프팅’, 3D로 장면·카메라·포즈를 먼저 잡고 AI 이미지·영상을 뽑는 아티스트용 IDE

storytold/artcraft(Rust, Apache-2.0, ~3.17만★): 10/11~17 GitHub 주간 트렌딩 2위(+20,267★). ‘아티스트를 위한 IDE’ — 2D 합성, 3D 장면 스테이징, 원하는 모델 선택. 이미지→로케이션(같은 공간에서 여러 컷), 3D 이미지 합성(배경·전경·소품 깊이), 이미지→3D 메시, 캐릭터 포즈·카메라 배치, 키트배싱 블로킹, 마네킹으로 인물 정체성 전달, 배경 제거. 프롬프트 운에 맡기지 않고 ‘반복 가능한 결과’를 노림. 데스크톱 앱 배포.

분류: GitHub 트렌드

한줄 요약

AI 이미지·영상의 가장 큰 불만은 “원하는 구도가 안 나온다”는 것이다. 프롬프트를 열 번 고쳐도 카메라 각도와 인물 위치는 운이다. 이번 주(10/11~17) GitHub 주간 트렌딩 2위에 오른 ArtCraft는 이 문제를 “먼저 장면을 짓고, 그다음 생성한다”로 푼다. 이번 주에만 별 +20,267개, 누적 약 3.2만 개(GitStock 주간 스냅샷 · GitHub).

무엇을 하는 도구인가

스스로를 “아티스트를 위한 IDE”라고 부른다. 개발자가 코드 에디터에서 일하듯, 아티스트가 2D로 합성하고 3D로 장면을 배치하고, 작업에 맞는 AI 모델을 골라 결과를 뽑는 작업대다.

  • 이미지 → 로케이션: 사진 한 장을 일관된 공간으로 만들고, 그 방 안에 가상 배우를 세워 여러 컷을 같은 장소에서 계획.
  • 3D 이미지 합성: 배경·전경·소품을 3D 레이어로 쌓아 깊이 있는 구도.
  • 이미지 → 3D 메시: 그림 속 물체를 3D로 바꿔 돌리고 놓고 프레이밍.
  • 캐릭터 포즈·카메라: 인물 자세와 카메라를 먼저 정한 뒤 최종 컷 생성.
  • 키트배싱 블로킹: 3D 에셋 키트를 조합해 카메라 각도·물체 위치·깊이를 통제.
  • 인물 정체성 전달: 포즈를 잡은 마네킹을 가이드로 써서 내 캐릭터를 그 자리에 앉힌다.
  • 2D 합성·배경 제거·드로잉 도구도 포함.

숫자와 조건

Rust로 작성, Apache-2.0 라이선스, 저장소 자체는 2022년에 만들어졌지만 이번 주 급상승했다. 데스크톱 앱으로 배포(getartcraft.com, GitHub Releases). 생성은 사용자가 고른 모델에 맡기는 구조라, 모델별 비용·약관은 따로 확인해야 한다.

왜 중요한가

영화·광고 현장의 언어로 말하면 ArtCraft는 ‘프리비즈(사전 시각화)’를 AI 생성 앞에 붙인 것이다. 같은 주 Kling 4.0이 ‘레퍼런스 15개·키프레임 10개’로, Figma·Photoshop이 디자인 시스템으로 통제력을 늘린 것과 같은 흐름 — 생성 AI 경쟁이 “더 놀라운 결과”에서 “의도대로 반복되는 결과”로 옮겨 가고 있다. 브랜드 필름이나 캠페인 키비주얼처럼 같은 인물·같은 공간을 여러 컷 유지해야 하는 작업에 특히 맞는다. GitHub 주간 분석가들도 이번 주 흐름을 “사람이 중간에 확인하고 고칠 수 있게 하는 도구”로 요약했다(AI之上 주보).
