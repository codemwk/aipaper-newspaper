[11/26] AI 모델: 업스테이지 Solar Mini 4.5 Preview — 활성 3B에 512K 문맥, 미리보기 동안 90% 할인(입력 100만 토큰당 0.01달러)

업스테이지가 11/23 Solar Mini 4.5 Preview를 콘솔·OpenRouter에 올렸다. 총 35B·활성 3B의 작은 모델에 512K 문맥, 최대 128K 출력, 추론 모드·구조화 출력·도구 호출을 지원한다. 자체 학습법으로 에이전트 성능을 크게 올렸다고 밝혔고, 미리보기 동안 정가의 90%를 깎아 입력 100만 토큰당 0.01달러다. 정식판은 12/3.

한줄 요약

한국 회사 업스테이지의 작은 모델 새 버전이 미리보기로 나왔다. 핵심은 싸고, 길게 읽고, 도구를 부를 수 있다는 것(업스테이지 콘솔 문서, OpenRouter).

사양

  • 크기: 총 35B, 활성 3B.
  • 문맥: 512K 토큰, 최대 출력 128K.
  • 기능: 채팅, 추론 모드, 구조화 출력, 도구 호출.
  • 학습 데이터 기준: 2026년 8월.
  • 회사 설명: 업스테이지 자체 학습법으로 에이전트 성능이 크게 향상(구체적 점수는 문서에 없음).
  • 언어: 문서상 지원 언어 표기는 영어.

가격·일정

  • 정가: 입력 0.10 / 출력 0.40 / 캐시 0.01달러(100만 토큰당).
  • 미리보기 기간 90% 할인 → 입력 0.01 / 출력 0.04 / 캐시 0.001달러.
  • 12/3 정식 출시. 그날부터 solar-mini-4-5-preview 호출은 자동으로 정식 모델로 넘어간다.
  • 사용처: 업스테이지 콘솔·Playground, OpenRouter, 온프레미스.
  • API 입력은 학습에 쓰지 않고, 서비스 제공에 필요한 경우가 아니면 저장하지 않는다고 명시.
