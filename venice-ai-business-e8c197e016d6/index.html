[11/27] AI 비즈니스: Venice — ‘대화를 서버에 남기지 않는’ AI 채팅·API로 연 환산 매출 2억 달러, 14주 만에 두 배

ShapeShift 창업자 Erik Voorhees가 2024년 만든 Venice가 11/23 연 환산 매출(run rate) 2억 달러를 넘었다고 밝혔다. 8월 1억 달러에서 약 14주 만에 두 배. 돈은 월 18~200달러 구독과 API 크레딧에서 나오고, 회사는 2026년 1분기부터 흑자라고 말한다. 파는 것은 ‘더 똑똑한 모델’이 아니라 ‘대화를 서버에 저장하지 않고, 덜 거절하는 AI’다. 모든 숫자는 회사 발표이며 검증되지 않았다.

분류: AI 비즈니스

한줄 요약

OpenAI·Anthropic이 일부러 비워 둔 자리, “내 대화를 남기지 않는, 덜 걸러진 AI”에 돈을 내는 사람이 생각보다 많았다. Venice는 그 틈 하나로 연 환산 매출 2억 달러(회사 주장)까지 왔다(Runtime Wire, 11/24, The AI Receipts 정리, 11/26 확인).

누구를 위한 회사인가

  • 개인 사용자: 채팅·이미지·영상·음악·코드를 한 앱에서 쓰되, 프롬프트를 서버에 저장하지 않는다(대화는 내 기기에 남음)는 점을 산다.
  • 개발자·에이전트: 200개 넘는 모델을 API로 부른다. 오픈 웨이트 모델은 Venice가 직접 호스팅하고, Claude·GPT 같은 폐쇄형 모델은 프록시를 거쳐 연결한다.
  • 7월 기준 등록 사용자 350만 명, 월 1.3조 토큰, 하루 약 200만 API 호출(Venice 블로그). 유료 사용자 수는 공개하지 않았다.

돈 버는 구조

요금제월 가격핵심
Free0달러기본 모델, 하루 텍스트 10회·이미지 15회
Pro18달러텍스트 무제한, 이미지 하루 1,000장, 크레딧 1달러분
Pro Plus68달러크레딧 75달러분, 2개월 이월
Max200달러크레딧 225달러분, 3개월 이월
  • 크레딧(100크레딧=1달러)이 영상·음악·최상위 모델·API 사용료가 된다. 많이 쓰는 사람일수록 요금제 가격보다 더 낸다 — 구독 + 사용량 과금의 하이브리드.
  • 암호화폐 층: VVV 토큰 보유자는 API 용량을 받고, 회사는 매출 일부로 VVV를 되사서 소각한다고 밝혔다.

숫자 타임라인 (모두 회사 발표)

  • 2026년 1분기: 외부 투자 없이 흑자 전환(The Block 보도).
  • 7/1: 연 환산 7천만 달러+, Dragonfly 주도 시리즈 A 6,500만 달러(기업가치 10억 달러) — 첫 외부 자금.
  • 8/17: 1억 달러 돌파 → 11/23: 2억 달러 돌파(Voorhees의 X 게시물).

왜 중요한가

  • 지금까지 다룬 AI 비즈니스는 대부분 기업 고객·성과 과금(Sierra, Fin)이나 크리에이터 도구였다. Venice는 소비자가 ‘프라이버시와 덜한 검열’이라는 속성 자체에 직접 돈을 내는 드문 사례다.
  • 모델을 직접 만들지 않는다는 점도 눈여겨볼 만하다. 오픈 모델 호스팅 + 폐쇄 모델 중계 + 정책 차별화만으로 이 규모가 나온다는 것은, “모델 회사가 아니어도 포지셔닝으로 큰 소비자 AI가 된다”는 신호다.
  • 개인화 구독 OS 구상과 연결하면: 사용자가 “내 데이터가 어디에 남는가”를 구매 이유로 꼽는 시장이 실재한다는 증거다.
  • 주의: run rate는 최근 일정 기간을 1년으로 환산한 값이고, 어떤 기간인지·구독과 API 비율은 공개되지 않았다. 이익·마진 수치도 없다. ‘덜 걸러진 AI’는 규제·평판 리스크도 함께 안고 있다.
