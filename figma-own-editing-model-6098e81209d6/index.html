[10/30] 디자인: Figma가 ‘자기 모델’을 만들었다 — 캔버스 수정은 자체 모델, 새 이미지·벡터는 외부 최고 모델. 되돌리기 60% 감소

Figma가 10/29 블로그에서 Figma 에이전트에 들어간 1차(자체) 편집 모델의 학습 방식을 공개했다. 프런티어 모델이 Figma 파일 구조를 못 읽어 프롬프트로 버티면 토큰이 너무 많이 들었기 때문에, ‘원본 디자인 + 합성 수정 요청 + 성공한 수정본’ 쌍으로 지도 미세조정(SFT)을 했다. 베타→정식 사이 일반 작업 약 20% 빨라짐, 전문 디자이너 비교에서 이전 에이전트와 같거나 나음 62%, 사용자 평점 33%↑, 되돌리기 60%↓(회사 발표).

분류: 디자인/UI·UX

한줄 요약

Figma 에이전트는 이제 두 종류의 두뇌를 쓴다. 간격·색·레이아웃 같은 잔손질 수정은 Figma가 직접 학습시킨 모델이, 새 이미지·벡터·완전히 새로운 시안은 외부 최고 모델이 맡는다(Figma 블로그).

왜 자체 모델인가

  • 디자이너의 하루는 “간격 조금”, “색 바꿔”, “피드백 반영해서 레이아웃 다시” 같은 작고 반복적인 수정이 대부분이다. 이런 일은 정답이 딱 떨어지지 않고, 느리면 흐름이 끊긴다.
  • Figma에 따르면 처음엔 프런티어 모델이 Figma 파일 문법을 이해하지 못해, 긴 시스템 프롬프트로 메워야 했고 토큰 비용이 컸다.

어떻게 학습했나

  • 학습 예시 하나 = 시작 디자인 + 합성으로 만든 수정 요청 + 성공한 수정 결과.
  • 디자인을 Figma 고유 파일 형식 그대로 넣어, 모델이 내놓는 변경을 캔버스에 바로 적용할 수 있게 했다.
  • 디자인 시스템 자산(테마·컴포넌트)을 바꾸는 요청도 합성해 넣었다.
  • 예: “사진 왼쪽 위에 위치 태그 컴포넌트 넣어줘” → 태그가 정렬·가독성을 지키며 들어가고, 관계없는 요소는 건드리지 않는다.

숫자 (회사 발표)

지표결과

사용자 평점33% 상승
사용자가 결과를 되돌린 비율60% 감소

왜 중요한가

  • “되돌리기 60% 감소”가 핵심 숫자. AI 디자인 도구의 진짜 비용은 생성 시간이 아니라, 마음에 안 들어 되돌리고 다시 시키는 시간이다.
  • 큰 모델 하나 vs 작업별 모델 조합. 같은 날 Canva도 자체 편집 모델 Brush를 냈다(다음 기사). 디자인 툴들이 “편집은 우리 모델, 생성은 빌려온 모델”로 수렴하고 있다.
  • 지난번 저장하신 Figma 에이전트·디자인 시스템 기사와 이어지는 소식이다.
