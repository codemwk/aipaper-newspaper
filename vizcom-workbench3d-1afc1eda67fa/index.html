[11/18] 디자인: Vizcom ‘Workbench3D’ — 스케치에서 3D 모델을 뽑아 카메라 각도를 고정하고, 그 시점 그대로 새 렌더를 생성

제품·산업 디자이너용 AI 툴 Vizcom이 11/17 3D 생성을 노드형 작업 캔버스 ‘Workbench’로 옮겼다. 스케치나 렌더를 Make3D 블록에 연결해 3D 모델을 만들고(Standard·Real-Time·Edit Ready·Max Detail 프리셋), 그 모델을 Modify 블록에 꽂아 원하는 카메라 각도에서 새 이미지를 생성한다. 저장한 카메라 뷰로 모든 시안을 같은 각도로 비교할 수 있고, 외부 3D 모델도 올릴 수 있다.

분류: 디자인

한줄 요약

이미지 생성 AI의 고질병은 카메라 각도를 말로 설명해야 한다는 점이다. “정면에서 4분의 3 각도로”라고 써도 매번 다르게 나온다. 제품 디자인 AI 툴 Vizcom이 11/17 내놓은 Workbench3D는 이 문제를 3D 모델로 각도를 직접 잡는 방식으로 푼다(Vizcom 블로그).

무엇이 바뀌었나

  • 3D가 캔버스 안으로: Vizcom의 3D 생성은 원래 별도 화면(2D Studio)에 있었다. 이제 디자이너가 매일 쓰는 노드형 작업 캔버스 ‘Workbench’에 블록으로 들어왔다. 이미지, 애니메이션 옆에 3D 모델이 같이 놓인다.
  • 스케치 → 3D: 스케치나 렌더 이미지를 Make3D 블록에 연결하고 프리셋을 고르면 3D 모델이 나온다. 프리셋은 쓰임새별로 넷이다.

- Standard: 범용
- Real-Time: 가볍게 최적화된 에셋
- Edit Ready: 직접 다듬을 기본 형태
- Max Detail: 디테일 최우선

  • 3D → 원하는 각도의 렌더: 3D 모델을 Modify 블록에 꽂고 화면 구도를 잡으면, 그 시점 그대로 새 이미지를 생성한다. 프롬프트로 각도를 빌 필요가 없다.
  • 저장한 카메라 뷰: 정면 4분의 3 같은 각도를 한 번 저장해 두면 모든 시안에 같은 각도를 쓴다. 시안을 나란히 비교할 때 제품 컷이 정확히 맞는다.
  • 외부 모델도: 다른 툴에서 만든 3D 파일을 이미지처럼 올리면 같은 3D 요소가 된다. 기존 Make3D 블록도 그대로 남아 있다.

왜 중요한가

AI 이미지 생성이 실무에 들어가려면 ‘같은 조건에서 하나만 바꾸기’가 돼야 한다. 색이나 소재만 바꾼 시안 10장을 같은 각도로 비교하는 일이다. Workbench3D는 3D를 최종 결과물이 아니라 ‘각도를 고정하는 도구’로 쓴다. 11/12 Figma가 3D 변형(3D transform)을 냈던 것과 함께, 디자인 툴 전반에서 3D가 ‘구도 제어 장치’로 쓰이는 흐름이 보인다. 브랜드 작업에서도 패키지·굿즈·공간 시안을 같은 각도로 반복 비교할 때 바로 쓸 수 있는 방식이다.
