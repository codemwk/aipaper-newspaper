[11/6] GitHub: Conductor → Meta — 병렬 코딩 에이전트 워크스페이스, 클라우드 11/20 종료

병렬 에이전트 워크스페이스 도구 Conductor가 11/4 Meta 합류를 발표했다. 신규 가입·다운로드 중단, 기존 Pro는 당분간 무료. Conductor Cloud는 11/13 읽기 전용→11/20 종료·데이터 삭제. 로컬 앱은 2027년 초까지 모델·치명 버그 패치. 차기 인터페이스는 내년 초 예고.

분류: GitHub

한줄 요약

여러 코딩 에이전트를 병렬 워크스페이스로 돌리던 Conductor가 Meta에 들어간다. 제품은 잠시 남지만 클라우드는 2주 안에 꺼진다(Conductor 공지, TechCrunch 11/4).

지금 뭐가 뜨나

  • 타임라인: 11/4 신규 가입·앱 다운로드 중단, Pro 기능은 기존 유저 무료 유지. 11/13 클라우드 읽기 전용·구독 환불. 11/20 클라우드 종료·데이터 삭제 시작.
  • 로컬: 2027년 초까지 새 모델·치명 버그 픽스. 클라우드→로컬 이전 메뉴 제공.
  • 제품 성격: 에이전트 모델은 자사가 아니라 Anthropic·OpenAI 등을 워크스페이스에 배치. 클라우드·로컬·폰.
  • Meta 맥락: Muse Code·Muse 에이전트(회사 주장 1,000만+ 유저) 강화 흐름. 창업자 Charlie Holtz는 Alexandr Wang·Nat Friedman과의 협업을 언급.

왜 중요한가

지난번 저장하신 orca·headroom·에이전트 하네스 테마와 맞닿는다. ‘병렬 에이전트 IDE’가 독립 SaaS로 남기보다 빅테크 차기 인터페이스로 흡수되는 패턴이다. 클라우드에만 쌓인 채팅·워크스페이스는 11/20 전 내보내기가 숙제다. OpenAI-Pierre와 같은 주 — 코딩 에이전트 주변 UI가 M&A 전쟁터가 됐다.

주의

인수 금액 미공개. “내년 초 새 인터페이스”는 티저일 뿐 스펙이 없다. 데이터는 학습·판매하지 않았다고 하나, 종료 전 백업은 사용자 책임.
