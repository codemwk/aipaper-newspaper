[10/21] AI 도구: 코딩 에이전트 ‘운영 수칙’ 업데이트 — Claude Code는 ‘이 대화 다시 열면 5시간 한도를 꽤 먹는다’고 미리 경고하고 작업 브랜치 삭제 버그를 고쳤다, GitHub Copilot은 GPT-5.5 등 6개 모델 퇴역

Claude Code 2.1.304(10/20 06:34 KST 배포): Pro·Max에서 오래 쉰 대화를 재개하면 5시간 사용 한도의 상당 부분을 쓸 때 경고(새 대화로 시작하고 이전 대화는 필요할 때 찾아보게 할 수 있음), 프로젝트·최근 세션을 읽어 auto 모드를 가르치는 /auto-mode-setup, Managed Agents 설정을 공식 보안 가이드와 비교만 하는 점검 명령, --worktree 종료 시 HEAD가 분리됐거나 다른 브랜치일 때 묻지 않고 작업트리·브랜치를 지워 커밋을 잃을 수 있던 버그 수정, 마운트 드라이브 rm -r 안전 확인 추가. 2.1.305(10/21 05:46 KST): 2.1.304의 Vertex·Bedrock 요청 실패 회귀 수정. GitHub Copilot은 10/19부터 Gemini 3.7 Flash, GPT-5.5·5.4, GPT-5.4 mini·GPT-5 mini, Grok 4.5 퇴역(대안 Gemini 3.8 Flash, GPT-6.1 Sol, GPT-6 Luna, Grok 4.7), 기업용 모델 정책 REST API 정식.

한줄 요약

에이전트로 일하는 사람에게 이번 주 중요한 업데이트는 새 기능보다 ‘돈과 작업을 잃지 않게 하는 장치’다. Claude Code와 GitHub Copilot이 하루 사이 나란히 그런 변화를 내놨다.

Claude Code 2.1.304 — 한도·안전·설정

2026-10-20 오전(한국 시간 06:34) 배포(릴리스 노트).

  • 재개 전 경고: Pro·Max 요금제에서 오래 쉬었던 대화를 다시 열면 5시간 사용 한도의 눈에 띄는 비율을 쓰게 될 때 미리 알려 준다. 그대로 재개하거나, 새 대화를 시작하고 필요하면 Claude가 이전 대화를 찾아보게 할 수 있다. (긴 대화는 캐시가 식으면 처음부터 다시 읽혀 비싸다.)
  • /auto-mode-setup: 프로젝트와 최근 세션을 읽어 auto 모드에 내 작업 환경을 가르치는 안내형 설정.
  • 보안 점검: Managed Agents 에이전트 설정을 Anthropic이 공개한 보안 가이드와 비교만 하는 명령(아무것도 바꾸지 않음).
  • 중요한 버그 수정: claude --worktree로 연 작업을 끝낼 때, HEAD가 분리됐거나 다른 브랜치에 있으면 묻지 않고 작업트리와 브랜치를 지워 커밋을 잃을 수 있던 문제를 고쳤다. 마운트된 드라이브 최상위(/Volumes, /media, WSL /mnt/c)를 rm -r 할 때도 이제 안전 확인을 받는다.
  • Code Review: 리뷰 강도를 Quick·Standard·Deep 중에서 고르고 저장소별로 덮어쓸 수 있다(MUVO 정리).

2.1.305 — 하루 만의 보정

한국 시간 10/21 05:46 배포. 2.1.304에서 생긴 Vertex·Bedrock 등 다른 제공자 경유 시 모든 요청이 실패하던 회귀를 고쳤다(도구 검색을 거부하는 게이트웨이면 그것 없이 재시도). 무인 재시도 모드가 사용 한도가 일찍 풀린 것을 알아채는 설정도 추가됐다. AWS·Google 클라우드로 Claude Code를 쓰는 팀은 2.1.304를 건너뛰고 바로 2.1.305로 가는 게 안전하다.

왜 중요한가

에이전트 비용의 상당 부분은 ‘모델 가격’이 아니라 습관에서 나온다 — 오래된 대화를 계속 이어 쓰기, 한도를 모른 채 밤새 돌리기. Claude Code의 재개 경고는 그 습관을 도구가 먼저 지적하기 시작했다는 신호다. 실천 팁: 큰 작업은 세션을 짧게 끊고, 이어 갈 맥락은 decisions.md 같은 파일에 남겨 새 세션이 읽게 하자(오늘 PKM 기사 참고). Copilot을 쓰는 자동화가 있다면 모델 이름이 하드코딩된 곳부터 찾아 바꿀 것.
