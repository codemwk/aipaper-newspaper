[11/4] AI 모델: Tencent WeVisOne-VL — 찾기·세기·글자 읽기부터 ‘머리카락까지 누끼’까지 한 모델로. 없는 물건은 ‘없다’고 답하는 오픈 2B·4B

WeChat 비전팀의 WeVisOne-VL(2B·4B, Qwen3-VL 기반)이 공개됐다. 물체 탐지·지칭·개수 세기·포인팅·OCR(물체 단위)과 지칭 분할·알파 매팅(픽셀 단위)을 960만 파라미터짜리 작은 픽셀 디코더 하나로 통합. SAM 같은 무거운 외부 모델이 필요 없다. 찾는 대상이 없으면 ‘None’을 내도록 학습해, 자체 벤치 거부율 96.4%(비교 모델 73.0%). 코드 Apache-2.0.

분류: AI 모델

한줄 요약

“사진에서 왼쪽 컵 몇 개야?”와 “이 사람만 배경 빼고 머리카락 경계까지 따 줘”를 같은 모델이 한다. 디자이너에겐 ‘말로 하는 누끼’, 앱 개발자에겐 가벼운 만능 비전 부품이다(Hugging Face 4B, GitHub).

무엇이 새로운가

  • 모든 시각 작업을 ‘텍스트’로: 상자·점 좌표를 <0>~<1000> 좌표 토큰으로 쓰고, 픽셀 작업이 필요하면 상자 뒤에 특수 토큰을 붙인다. 그 토큰의 내부 상태 + 상자 + ViT 특징을 960만 파라미터 픽셀 디코더가 받아 전체 해상도 마스크나 연속값 알파 매트를 낸다.
  • ‘없으면 없다’: 대상이 이미지에 없으면 None. 자체 WeRef-Bench 거부율 96.4%(비교 대상 73.0%)로, 없는 걸 지어내 그리는 환각을 줄였다(FreeLLM 정리 11/3).
  • 데이터 엔진: 지식 그래프로 개념을 고르고, 여러 전문 모델로 위치를 찾고, VLM이 검증한 뒤 마스크·매트로 확장 — 이 자동 파이프라인으로 이미지 1억 장+에 라벨을 달았다고.

왜 중요한가

지금까지 ‘찾기’는 VLM, ‘따내기’는 SAM 계열, ‘누끼’는 별도 매팅 모델로 이어 붙였다. 하나로 합치면 에이전트가 이미지 편집을 직접 다루는 파이프라인이 단순해진다. 2B·4B라 로컬에서도 현실적이다.

주의

  • 논문(arXiv 2610.31329)과 가중치는 10월 말부터 올라와 있었고, 11/3 공식 발표로 알려졌다. 수치는 모두 회사 측 결과.
  • 단일 이미지·단일 턴용. 영상은 픽셀 디코더가 받지 않는다. 모델 카드는 개인 식별 용도를 명시적으로 배제한다. 서드파티 구성요소는 원 라이선스를 따른다.
