[10/22] GitHub 트렌드: Kronos(~4.3만★) — 차트의 ‘캔들’을 단어처럼 읽는 금융 시장 전용 기반 모델, 45개 거래소 데이터로 학습해 다음 봉을 ‘확률적으로’ 그린다

10/21 GitHub 일간 인기 9위 shiyu-coder/Kronos(~42.8K★, 하루 +570, MIT): 캔들(K-line, 시가·고가·저가·종가·거래량)을 위한 첫 오픈소스 기반 모델이라 소개. 45개 이상 글로벌 거래소 데이터로 사전학습. 2단계 구조 — 연속값 캔들을 계층적 이산 토큰으로 바꾸는 전용 토크나이저 + 그 토큰을 이어 쓰는 자기회귀 트랜스포머. 공개 모델 Kronos-mini(4.1M, 문맥 2,048)·small(24.7M)·base(102.3M, 문맥 512), large(499.2M)는 비공개. 여러 번 샘플링하는 확률적 예측, 다종목 배치 예측, 중국 A주 Qlib 미세조정·백테스트 예제(“실전 퀀트 시스템 아님” 면책). AAAI 2026 채택, 마지막 코드 푸시는 2026-04 — 새 기능이 아니라 ‘재유행’.

분류: GitHub 트렌드

한줄 요약

10/21 GitHub 일간 인기 목록은 대부분 이미 소개한 에이전트 도구(orca·headroom·ponytail·graphify)였다. 그 사이 금융 쪽에서 눈에 띈 게 Kronos다. 한 줄로 말하면 “차트 캔들을 언어처럼 학습한 모델” (GitHub, GitStock 10/21).

무엇을 하나 — 쉬운 말로

  • 우리가 차트에서 보는 봉(캔들) 하나에는 시가·고가·저가·종가·거래량이 들어 있다. Kronos는 이 숫자 묶음을 ‘토큰(단어)’으로 바꾸는 전용 토크나이저를 먼저 만든다.
  • 그다음 ChatGPT가 다음 단어를 쓰듯, 다음 봉들을 이어 쓰는 트랜스포머를 학습시켰다. 학습 데이터는 45개 이상 글로벌 거래소.
  • 결과물은 미래 구간의 시가·고가·저가·종가·거래량 예측 표. 온도·top-p·샘플 수를 조절해 여러 갈래의 미래를 뽑는 확률적 예측이 가능하고, 여러 종목을 한 번에 돌리는 배치 예측도 있다.
  • 웹 데모는 BTC/USDT의 향후 24시간 예측을 보여 준다.

왜 지금 인기인가, 그리고 주의할 점

  • 저장소의 마지막 코드 푸시는 2026년 4월. 새 버전이 나온 게 아니라, AI 트레이딩 관심이 커지며 다시 주목받는 경우다.
  • 저장소가 직접 경고한다: 중국 A주 데이터(Qlib)로 미세조정·백테스트하는 예제는 “시연용이며 실전 퀀트 시스템이 아니다”. 안정적 초과수익엔 포트폴리오 최적화·리스크 요인 중립화 같은 추가 작업이 필요하다고.
  • 예측이 그럴듯해 보이는 것과 수수료·슬리피지 뒤에 돈이 남는 것은 다른 문제다.

어떻게 쓰면 좋나

LLM 에이전트(TradingAgents류)는 뉴스·재무제표 같은 글에 강하고, Kronos 같은 모델은 가격 패턴을 숫자로 본다. 둘을 섞어 “에이전트가 Kronos 예측을 하나의 근거로 참고”하는 구조가 자연스럽다. 다만 오늘 IBKR 기사처럼 실행은 별도 계좌·상한·킬 스위치 뒤에 두고, 먼저 모의 계좌에서 검증할 것.
