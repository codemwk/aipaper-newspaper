AI 모델: GPT-6 Sol·Luna — Vercel AI Gateway에 올라 ‘코딩 에이전트 라우팅’

Vercel changelog(2026-09-22): openai/gpt-6-sol·openai/gpt-6-luna를 AI Gateway에 추가. Astra보다 낮은 가격대에서 전문·코딩·사실성. Codex·fx·AI SDK·호환 API. 가격전쟁 기사와 다른 ‘유통·게이트웨이’ 각도.

분류: AI 모델

한줄 요약

Vercel(2026-09-22)이 GPT-6 Sol과 GPT-6 Luna를 AI Gateway 카탈로그에 넣었다. Sol은 복잡한 프로·코딩 루프, Luna는 대량 에이전트·일상 작업용 저비용 축. 며칠 전 가격·벤치 뉴스와 달리, 오늘은 한 키로 Codex·fx·AI SDK에 꽂는 유통 이야기다.

쓰는 법 (changelog)

  • 모델 ID: openai/gpt-6-sol, openai/gpt-6-luna.
  • npx vercel ai-gateway setup 후 Codex /model, fx /model, AI SDK streamText({ model: 'openai/gpt-6-sol' }), OpenAI 호환 Chat/Responses.
  • 주장 포인트: Astra 대비 낮은 가격대에서 전문 업무·코딩·컴퓨터 사용·사실성·소통(전문 용어·저가치 세부 감소).

왜 중요한가

에이전트 제품의 병목은 “최신 모델 이름”보다 라우팅·사용량·페일오버를 한곳에서 보는 것이다. Gateway에 Sol/Luna가 오면, 팀 표준을 Astra 고정에서 작업 난이도별 티어로 나누기 쉬워진다.
