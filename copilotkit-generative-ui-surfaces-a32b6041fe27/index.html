[10/31] 디자인: 에이전트 UI가 채팅창 밖으로 — CopilotKit ‘Surfaces’는 페이지 아무 곳이나 에이전트가 그리게 하고, 70개 컴포넌트 카탈로그로 디자인 시스템을 지킨다

에이전트 UI 프레임워크 CopilotKit이 10/29 Generative UI 대규모 업데이트를 냈다. 폼·차트·지도 등 70개 표준 컴포넌트 카탈로그(구글 A2UI 1.0 기본 18개 + 자체 52개), 내 컴포넌트로 덮어쓰기, 채팅 밖 페이지 영역을 에이전트가 렌더링하는 ‘Surfaces’, 답변 텍스트와 UI가 함께 흘러나오는 마크다운 모드. 생성된 UI는 카탈로그 검사를 통과해야만 그려지고 코드를 실행하지 않는다.

분류: 디자인/UI·UX

한줄 요약

지금까지 ‘에이전트가 만든 UI’는 채팅 말풍선 안의 카드였다. 이번 업데이트로 에이전트는 쇼핑몰 ‘추천 상품’ 줄, 상품 페이지, 장바구니 같은 실제 화면 영역을 직접 다시 그릴 수 있다(CopilotKit 블로그).

무엇이 새로 생겼나

기능디자이너가 알아야 할 의미
표준 카탈로그 70개레이아웃·텍스트·입력·표·차트·지도·미디어. 링크 미리보기·인용·상품 카드 같은 블록 포함
extend / omit / override표준 옆에 내 컴포넌트 추가 / 안 쓰는 건 빼기(프롬프트도 줄어듦) / 표준을 내 디자인 시스템 컴포넌트로 교체
Surfaces페이지 한 영역을 감싸고 “이 영역은 무엇을 위한 곳인지 + 쓸 수 있는 컴포넌트”를 지정. 평소엔 원래 화면이 대체(fallback)로 보임
마크다운 모드텍스트와 UI가 한 답변 안에서 같이 스트리밍
라이브 값·액션슬라이더를 움직이면 가격·차트가 브라우저에서 즉시 재계산 — 토큰 0
테마브랜드 색·폰트, 다크 모드
인스펙터무엇이 그려졌는지, 무엇이 거부됐고 왜인지, 모델이 받은 정확한 프롬프트

안전장치가 디자인 시스템이다

  • 에이전트가 보낸 모든 조각은 카탈로그와 대조한 뒤에만 렌더링된다. 안 맞으면 이유를 에이전트에게 돌려보내 다음 턴에 고치게 한다. 생성된 UI는 페이지에서 코드를 실행하지 않는다.
  • 즉 “에이전트가 아무 화면이나 만든다”가 아니라 “허락된 부품 상자 안에서만 조립한다”. 이 부품 상자가 곧 디자인 시스템이다.

주의

  • A2UI 1.0 사양이 확정 전이라 실험적 기능이며 API가 바뀔 수 있다.

왜 중요한가

  • 10/29 다룬 Google A2UI Express가 ‘결정용 UI’ 패턴이었다면, 이번엔 제품 화면 자체가 사용자별로 재구성되는 패턴이다. 디자이너의 산출물이 “완성 화면”에서 “영역 정의 + 허용 부품 + 대체 화면”으로 바뀌는 신호다.
