디자인/UI·UX: Relume Publish 베타 — 내보내기 대신 호스팅·에이전트 팀, Library MCP로 ‘실제 컴포넌트’ 주입

Relume Publish(2026-08 베타): Webflow/Figma/React 내보내기 대신 Relume에서 빌드·퍼블리시·호스팅. Strategist·Designer·Copywriter·Analyst 에이전트. Library MCP는 환각 UI 대신 실제 Relume React 컴포넌트를 에디터에 넣음.

분류: 디자인/UI·UX

한줄 요약

Relume Publish(2026-08, CEO Dan Anisse)는 “AI가 사이트를 초로 만들면 끝”이 아니라 론치 이후 성장을 제품으로 잡는다. 기존 200만+ 사이트가 Webflow·Figma·React로 내보내기하던 흐름을, Relume 안에서 빌드·퍼블리시·Cloudflare 엣지 호스팅으로 접는다. 병렬로 Library MCP는 Cursor 등 MCP 클라이언트에 실제 라이브러리 컴포넌트(슬러그 단위)를 넣어, 환각 UI 대신 편집 가능한 React를 떨어뜨린다.

제품으로 보면

  • 에이전트 팀: Strategist·Designer·Copywriter·Analyst가 라이브 사이트·내장 애널리틱스를 보고 CTA·캠페인·SEO를 제안, 인간이 승인.
  • 컴포넌트 시스템: 인간 제작·브레이크포인트 테스트·접근성·시맨틱 SEO를 기본값으로. AI는 레이아웃을 “창작”하기보다 라이브러리에서 조립.
  • 협업 요금: 에디터 초대 시트비 없음 주장. 프리랜서·에이전시의 클라이언트 협업을 전제로 설계.
  • MCP 경로: Connect → 자연어로 섹션 검색 → 프리미티브·Tailwind preset과 함께 프로젝트에 벤더링. Publish MCP(Webflow/코드 익스포트)는 커뮤니티 업데이트에서 “수주 내”로 언급된 로드맵이므로 미출시 전제로 구분한다.

왜 중요한가

Webflow Agent Instructions·Figma Weave와 다른 포지션: 마케팅 사이트 OS + 컴포넌트 진실원. 퍼스널 OS의 “모듈형 대시보드”에도, AI가 픽셀을 그리는지 vs 검증된 블록을 고르는지가 품질·유지비 차이를 만든다.
