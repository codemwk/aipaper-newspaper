[11/8] 세컨드 브레인: Obsidian 1.15.1 얼리 액세스 — ‘관련도순’ 검색, 악센트 무시, 즉시 뜨는 작업 공간, 그리고 조용한 보안 강화

Obsidian 1.15.1(데스크톱 얼리 액세스, 11/3)이 검색을 손봤다. 관련도순 정렬, cafe로 café 찾기, 수천 개 결과도 빠르게. 시작 시 로딩 화면 없이 작업 공간이 바로 뜨고 인덱싱이 빨라졌다. 모르는 파일 형식 열기 확인, URI 콜백 기기별 설정, 플러그인 설치 시 vault에 딸려온 설정 무시 등 ‘에이전트가 vault를 만지는 시대’의 안전장치도 들어갔다.

분류: 세컨드 브레인 / PKM

한줄 요약

큰 기능 하나 대신 매일 쓰는 감각을 고친 릴리스다. 검색·속도·보안 세 갈래(Obsidian 체인지로그).

검색

  • Relevance(관련도) 정렬 추가 — 검색어에 가장 잘 맞는 노트부터.
  • 백링크·아웃라인·북마크의 검색 필터까지 악센트 무시(cafe→café), ø·ł·ß·æ 등을 기본 문자로 취급(lodz→Łódź, strasse→Straße).
  • 수천 개 노트가 걸리는 검색과 타이핑 중 갱신이 훨씬 빨라졌다.

속도

시작할 때 로딩 화면 대신 작업 공간이 바로 뜨고 진행 상황은 상태 표시줄에. 읽기 모드 렌더·vault 인덱싱(특히 긴 노트), 큰 폴더·대형 캔버스도 빨라졌다.

조용하지만 중요한 보안 변경

  • 노트 링크로 모르는 형식의 파일을 외부 앱으로 열 때 확인 — 일부 파일은 코드를 실행할 수 있어서.
  • Allow URI callbacks는 이제 vault 동기화가 아니라 기기별 1회 설정. 쓰던 분은 기기마다 다시 켜야 한다.
  • 공유받은 vault는 처음 연결할 때 설정·테마·스니펫·단축키를 기본적으로 동기화하지 않음.
  • 커뮤니티 플러그인 설치 시 vault에 미리 들어 있던 설정을 쓰지 않고 data.json.bak으로 보관.
  • 개발자: CLI eval이 top-level await 지원, 휴지통 이동 실패 시 오류 표시.

왜 중요한가

에이전트·스크립트·공유 vault로 노트에 들어오는 경로가 늘수록, 남이 심어 둔 설정·링크가 내 기기에서 실행되는 위험도 커진다. 1.15.1은 그 문을 기기 단위로 좁혔다. Vault Operator·LLM Wiki 같은 플러그인을 쓰는 obsidian 태그 관심사와 바로 연결되는 업데이트다.

주의

얼리 액세스(Catalyst 라이선스 대상) 빌드다. URI 콜백을 쓰는 자동화(Shortcuts 등)는 업데이트 후 기기마다 다시 켜야 동작한다.
