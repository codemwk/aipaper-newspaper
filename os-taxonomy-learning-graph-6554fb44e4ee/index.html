[10/21] GitHub 트렌드: os-taxonomy(~6.6천★) — 초등 과정 ‘무엇을 배우나’를 1,616개 작은 주제와 3,317개 선수 관계로 엮은 공개 지식 그래프, ‘이걸 알려면 먼저 뭘 알아야 하나’를 데이터로

10/20 GitHub 일간 인기 목록에 오른 withmarbleapp/os-taxonomy(~6.6K★, 하루 +284): 교육 스타트업 Marble이 공개한 ‘Marble Skill Taxonomy’ v1. 초등 과정을 가르칠 수 있는 최소 단위 1,616개 ‘마이크로 토픽’(설명·숙달 판단 근거·유형·과목·나이대)으로 쪼개고, 3,317개 선수(prerequisite) 관계(필수/권장, 이유 한 줄)로 순환 없는 그래프 구성. NGSS·Common Core·영국 국가교육과정·호주 교육과정 v9 등 8개 출처 3,881개 기준과 연결, 과학·수학 1,049개 주제에 교수법 연구 기록, 부모용 요약 176개. 순수 JSON, 데이터 ODbL 1.0·텍스트 CC BY-SA 4.0.

분류: GitHub 트렌드

한줄 요약

10/20 GitHub 일간 인기 목록은 여전히 코딩 에이전트 도구가 대부분이었다(ai-job-search, opencode, orca 등 — 이미 소개). 그 사이에서 눈에 띈 건 코드가 아니라 데이터 저장소다. 교육 스타트업 Marble의 os-taxonomy는 “아이들이 초등 시기에 무엇을, 어떤 순서로 배우는가”를 하나의 그래프로 공개했다(GitHub, SegmentFault 일간 순위).

무엇이 들어 있나

  • 1,616개 마이크로 토픽: 하나씩 가르칠 수 있는 최소 단위(예: ‘문장 만들기’, ‘별의 겉보기 밝기’). 각각 쉬운 설명, 숙달했다고 볼 근거, 유형(개념·절차·표현·언어·메타), 과목·영역, 대략의 나이대가 붙어 있다.
  • 3,317개 선수 관계: “X를 배우려면 Y가 먼저”라는 화살표. 필수/권장 구분과 이유 한 줄이 달려 있고, 순환이 없는 그래프다.
  • 교육과정 연결: 미국 NGSS·Common Core, 영국 국가교육과정, 호주 교육과정 v9 등 8개 출처, 3,881개 기준과 이어진다.
  • 교수법 연구: 과학·수학 1,049개 주제에 가르치는 방법·활동·피드백·평가 안내와 출처(나머지 567개는 아직 없음).
  • 부모용 요약 176개, 과목 구성은 과학 547·수학 529·영어 286·역사 90 등.
  • 형식은 순수 JSON(실행 의존성 없음). 데이터베이스는 ODbL 1.0, 텍스트는 CC BY-SA 4.0. 웹에서 3D 그래프로 탐색도 가능하다.

왜 인기인가

AI 튜터가 흔해졌지만, 대부분 “다음에 뭘 가르칠지”를 모델의 감에 맡긴다. 이 저장소는 그 순서를 사람이 검토할 수 있는 데이터로 꺼내 놓았다. 학생이 분수에서 막히면 그래프를 거꾸로 따라가 어느 선수 개념이 빠졌는지 찾을 수 있다 — LLM이 잘 못하는 일을 구조가 대신한다.

세컨드 브레인 관점

이건 사실상 ‘교육판 LLM Wiki’다. 노트(토픽)마다 정의와 근거를 달고, 노트 사이에 이유가 붙은 링크를 거는 방식은 Obsidian 볼트를 에이전트가 읽기 좋게 만드는 원칙과 같다. 내 볼트에도 “이 개념을 이해하려면 먼저 읽을 노트”를 prerequisite 속성으로 달아 두면, 에이전트가 학습 순서를 짜 주는 개인 커리큘럼을 만들 수 있다.
주의: 한국 교육과정은 아직 연결돼 있지 않고, 연구 기록은 과학·수학 일부에만 있다.
