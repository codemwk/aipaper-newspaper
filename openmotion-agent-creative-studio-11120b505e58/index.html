[11/24] AI 콘텐츠: OpenMotion 0.2 — 내 코딩 에이전트를 ‘영상·소리·디자인·게임 스튜디오’로. 스튜디오 7개, 템플릿 287개, 브랜드 키트 152개를 한 작업장에

‘Claude Motion·CapCut의 오픈소스 대안’을 내건 OpenMotion이 11/20 0.2.0, 11/21 0.2.1을 냈다. 참고 영상을 넣으면 내 브랜드 키트로 편집 가능한 모션 그래픽을 만들고 MP4로 뽑는다. 0.2에서는 이미지·시네마·사운드·디자인·게임 등 스튜디오 7개, 스킬 104개, 템플릿 287개, 브랜드 키트 152개를 한 작업장으로 묶었다. Claude Code·Codex 등 22개 에이전트에서 쓰고 Apache 2.0. 지난 7일 약 5,000★가 늘어 약 1.6만★.

분류: AI 콘텐츠

한줄 요약

OpenMotion은 내가 이미 쓰는 코딩 에이전트(Claude Code, Codex 등)를 영상 제작 스튜디오로 바꾸는 오픈소스다. 출발점은 “이 영상 느낌으로, 우리 브랜드로” 모션 그래픽을 만드는 일이었고, 0.2에서 이미지·소리·디자인·게임까지 넓혔다(GitHub, 0.2.0 릴리스, 0.2.1 릴리스).

무엇을 하나

  • 참고 영상 → 편집 가능한 모션 그래픽: 레퍼런스 영상을 넣으면 내 브랜드 키트(색·서체·시각 방향)로 다시 만든다. YouTube·쇼츠·릴스·틱톡용 MP4로 내보낸다.
  • 스튜디오 7개: 이미지(배경 제거, 조명 바꾸기, 캐릭터 일관성), 시네마(카메라 제어, 멀티샷, 영상과 함께 나오는 소리), 사운드(음악·효과음·음성 합성, 파형 비교), 디자인, 게임 등.
  • 디자인 스튜디오는 영상 밖으로 나간다. 웹 프로토타입, 앱, 슬라이드, 인쇄 레이아웃, 데이터 시각화, WebGL까지 같은 작업장에서 만든다.
  • 게임 스튜디오(0.2.1): 플레이 가능한 템플릿을 내 캐릭터·문구로 리믹스하고, 직접 플레이해 보며 에이전트와 고친다. MCP 도구로 붙는다.
  • 결과물은 계속 편집 가능한 프로젝트로 남는다. 타임라인 확대·클립 속도·리뷰 댓글 같은 편집 기능도 다듬었다.

숫자와 조건

  • 스킬 104개, 템플릿 287개, 브랜드 키트 152개, 지원 에이전트 22개. 설명서 역할을 하는 Motion.md 가이드는 300개 이상이다.
  • Apache 2.0. 약 1.6만★, 최근 7일 약 +5,000★(k-state 창작 데일리 11/22 기준 +4,968).
  • 이미지·영상 생성은 연결한 외부 모델 제공사 몫이다. 제공사 페이지에 검증된 기능, 로그인·구독 안내, 가격 신호를 보여 준다. 즉 앱은 무료여도 생성 비용은 따로 든다.
  • 시작: npx skills add nexu-io/openmotion --skill openmotion 후 에이전트에게 “시네마 스튜디오 열어 줘”.

왜 중요한가

지난번 저장하신 OpenMontage(에이전트용 영상 제작 시스템)와 이어지는 흐름이다. 이번 주 창작 분야 GitHub 상승 상위권에는 OpenMotion 외에도 99가지 영화 스타일을 코드로 담은 lemo-opuscar, Remotion 기반 제품 홍보 영상 스킬 video-shotcraft가 함께 올랐다. “영상 편집기를 따로 배우지 않고, 에이전트에게 말로 시키는” 쪽으로 무게가 옮겨 가고 있다. 브랜드 스튜디오 입장에서는 브랜드 키트가 1급 기능이라는 점이 핵심이다. 아이덴티티 하나를 정해 두면 쇼츠·슬라이드·웹 시안·인쇄물이 같은 규칙으로 나온다. 개념 연구(가상 리브랜딩) 결과물을 여러 매체로 한꺼번에 펼쳐 보이는 데 바로 쓸 수 있다. 다만 0.x 버전이라 변화가 잦고, 외부 모델 비용은 미리 확인해야 한다.
