[11/14] AI 콘텐츠: Pine Drama Studio 오픈소스 공개 — 대본 한 편을 넣으면 에이전트가 캐릭터·샷·에피소드를 만들고, 사람은 ‘승인’만

Pine AI가 11/13 에이전트가 숏드라마 시리즈를 제작하는 오픈소스 AI 영화 스튜디오 Pine Drama Studio(Apache 2.0)를 공개했다. 스토리 바이블, 캐릭터·장소·소품 설계, 스토리보드, 샷 생성, 흔들린 테이크 재생성, 편집까지 에이전트가 하고, 크리에이터는 단계마다 승인한다. 한 호주 스튜디오는 1인당 하루 제작량이 2~3분에서 30~50분으로 늘었다고 했다(회사 발표).

분류: AI 콘텐츠

한줄 요약

영상 모델은 멋진 클립을 만든다. 하지만 시리즈는 수백 개의 샷이 에피소드 내내 일관돼야 한다. Pine AI는 이 문제를 에이전트 제작 파이프라인으로 풀고, 그 스튜디오를 오픈소스로 공개했다(PR Newswire).

어떻게 일하나

  • 프로듀서는 대본과 지시 하나로 시작한다. 그다음은 에이전트 몫이다: ① 스토리 바이블 작성 → ② 캐릭터·장소·소품을 시리즈 전체 기준으로 한 번 설계 → ③ 스토리보드와 모든 샷 생성 → ④ 테이크를 검사해 설정에서 벗어난 것만 다시 생성 → ⑤ 승인된 테이크를 에피소드로 편집.
  • 크리에이터는 디자인, 스토리보드, 테이크, 최종 편집을 승인한다. 무언가를 바꾸면 영향받는 샷만 다시 만든다.
  • 에피소드마다 클라우드의 Pine Computer 한 대가 돌기 때문에 여러 에피소드를 동시에 제작할 수 있다.

무엇이 공개되고 무엇이 유료인가

  • 스튜디오 코드는 Apache 2.0 무료다(GitHub). 워크플로가 평범한 스킬 파일로 돼 있어 고쳐 쓸 수 있다. 모델을 직접 고르고, 더빙·현지화 같은 단계를 추가할 수 있다. 프로젝트와 제작 노하우는 스튜디오 폴더 안에 남는다.
  • 실제 생성과 에이전트 작업은 Pine Computer 클라우드에서 돌고, 이 컴퓨팅이 유료다. 즉 “오픈소스 스튜디오 + 유료 클라우드” 구조다. 사용하려면 pinecomputer.io의 프로젝트 키가 필요하다.
  • 사례(회사 발표): 호주의 AI 숏드라마 스튜디오는 1인당 하루 제작량이 2~3분에서 30~50분으로 늘었다고 했다.
  • 같은 날 에이전트가 작업 중에 실제 전화를 거는 Pine Phone도 Pine Computer에 들어갔다.

왜 중요한가

지난번 저장하신 OpenMontage·ArtCraft 같은 ‘에이전트용 크리에이티브 스튜디오’와 이어지는 소식이다. 이번에는 시리즈 제작 + 단계별 승인까지 왔다. 핵심은 “에이전트가 다 한다”가 아니다. 크리에이터가 감독이 되는 구조라는 점이다. 브랜드 필름이나 연작 콘텐츠를 만든다면, 바이블(캐릭터·톤 규칙)을 먼저 문서로 정리해 두는 습관이 그대로 생산성이 된다. 다만 클라우드 컴퓨팅 요금은 발표에 나와 있지 않다.
