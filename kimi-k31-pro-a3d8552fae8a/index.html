[10/24] AI 모델: Moonshot ‘Kimi K3.1 Pro’ — 3조 파라미터급 오픈웨이트, 코딩·3D·재무 분석 강화, 입력 $2·출력 $10. 가중치는 11/4까지 공개 예정

Moonshot AI가 10/23 Kimi K3.1 Pro와 2~3배 빠른 Highspeed 공개. K3 위에 사후학습(강화학습) 연산을 크게 늘린 버전으로 100만 토큰 문맥·이미지 입력 유지. 회사 발표 기준 Terminal-Bench 4.0 65.7%, 사내 환각 스트레스 테스트에서 주장 단위 오류율 23.4%→8.3%. Blender·CAD 스크립트로 3D 파라메트릭 모델링, 연결된 재무 모델 작성. API 100만 토큰당 입력 $2·출력 $10(캐시 $0.20), Highspeed $4/$20. 오픈웨이트판은 사이버 공격 관련 데이터를 일부러 빼서 학습. 가중치는 11/4까지.

분류: AI 모델

한줄 요약

중국 Moonshot AI의 새 주력 Kimi K3.1 Pro가 10/23 나왔다. “3조(3T)급 오픈웨이트” 모델로, 가중치는 11/4까지 공개한다고 밝혔다(Kimi 블로그, Vercel).

무엇이 좋아졌나 (회사 발표)

  • 코딩: 작은 버그 수정부터 프로젝트 전체 제작, 여러 단계의 긴 에이전트 작업. Unity·Unreal·Godot 게임 엔진, Three.js 장면에서 타이포그래피·애니메이션 완성도가 좋아졌다고
  • 3D: 텍스트·스케치·참고 이미지에서 형태·비율을 추론해 Blender·CAD 스크립트를 직접 짜서 파라메트릭 모델(기계 부품, 가구 등)을 만든다. kimi.ai에 3D 프린팅용 다운로드가 되는 ‘3D Make’ 추가
  • 재무: 가정·시나리오를 바꿀 수 있는 연결된 재무 모델, 근거 문서 기반 리서치
  • 사실 정확도: 일부러 어렵게 만든 사내 테스트에서 주장 단위 환각률 23.4% → 8.3%(실사용 오류율이 아니라는 단서 포함)

눈여겨볼 점: ‘해킹 능력’을 일부러 덜어낸 오픈웨이트

Moonshot은 학습 데이터에서 사이버 공격 관련 데이터를 찾아 제거했다. 같은 파이프라인에서 제거하지 않은 버전은 사내 취약점 공격 테스트 90.5%, 최종판은 81.0%. “오픈웨이트가 사이버 능력의 최전선을 넘지 않게 한다”는 원칙이다. 오픈 모델 진영이 안전을 ‘숫자로’ 설명하기 시작했다는 점이 의미 있다.

어떻게 볼까

벤치마크 수치는 모두 회사 자체 측정이다. 실사용 관점에선 입력 $2라는 가격 + 11/4 가중치 공개 약속이 관전 포인트 — 공개되면 자체 서버·로컬 에이전트용 선택지가 하나 더 생긴다.
