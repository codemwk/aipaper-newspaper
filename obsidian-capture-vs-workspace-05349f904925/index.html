[10/24] 세컨드 브레인 / PKM: Obsidian AI 플러그인 두 갈래 — ‘가볍게 적고 내 메모에만 묻는’ xiaoji vs ‘읽기 전용으로 시작해 승인 후 고치는’ Glossa 1.1

이번 주 Obsidian 공식 커뮤니티에 올라온 두 AI 플러그인. xiaoji(10/23 소개): 책 속 한 줄·번뜩 아이디어·할 일 같은 ‘노트로 만들긴 작은’ 메모를 Shift+Enter로 저장, 리스트/메이슨리 보기, @ID 인용, 데스크톱 플로팅 창. 메모는 월·분기·연 단위 Markdown 파일로 볼트에 저장, 기록·검색은 완전 오프라인, AI는 내 API를 연결했을 때만 ‘내 메모에서만 답하기’ 가능. Glossa 1.1.0(10/20): 사이드바 AI 작업 공간 — 활성 노트 문맥, 부분 패치 편집, PDF·이미지 분석, 웹 리서치, 읽기 전용으로 시작해 쓰기는 승인, 체크포인트 복원, 백그라운드 대화·채팅별 기록 파일.

분류: 세컨드 브레인 / PKM

한줄 요약

Obsidian에 AI를 붙이는 방식이 두 방향으로 나뉘고 있다. ① 적는 순간을 가볍게(xiaoji) ② 고치는 순간을 통제하게(Glossa). 둘 다 이번 주 공식 커뮤니티에 올라왔다.

xiaoji — ‘노트가 되기엔 작은 생각’ 전용

  • 문제의식: 책 속 인상적인 한 줄, 문득 떠오른 생각, 오늘 할 일 셋… 노트 한 장씩 만들긴 아깝고 아무 데나 두면 흩어진다(Obsidian 포럼)
  • 적기: 열고 쓰고 Shift+Enter로 저장. 태그·체크박스·첨부·표·수식 모두 Markdown
  • 다시 보기: 리스트 또는 메이슨리(카드 벽) 보기, 중첩 태그 필터, ‘이번 주’·‘할 일’·‘보관’ 바로가기
  • 연결: 이전 메모를 ‘인용’하면 @ID가 들어가고, 클릭하면 원문으로 이동 — 작은 메모끼리 링크
  • 데스크톱 퀵 캡처: 항상 위에 뜨는 플로팅 창 + 전역 단축키
  • 저장: 볼트 안 Markdown 파일(월·분기·연 단위로 분할 가능). 기록·탐색·검색은 완전 오프라인
  • AI는 선택: 내 API를 연결하면 자동 검색 → “내 메모 안에서만 답하기” 모드, 출처 메모 펼쳐 보기, 대화 기록 끄기 가능
  • 작성자가 “AI와 함께 바이브 코딩했다”고 솔직히 밝힌 점도 참고

Glossa 1.1.0 — 사이드바를 ‘작업대’로

  • 문맥: 지금 보는 노트·선택한 문장·첨부 PDF·이미지를 자동으로 문맥에 넣는다(Obsidian 커뮤니티)
  • 정밀 편집: 문서를 통째로 다시 쓰지 않고 한 섹션만 패치, 정확한 문장만 교체, 여러 파일 동시 수정
  • 책임 있는 행동: 읽기 전용으로 시작, 쓰기는 승인, 도구 결과 확인, 체크포인트로 되돌리기
  • 1.1.0(10/20) 새 기능: 여러 대화를 동시에 돌리는 백그라운드 대화(승인 대기 중인 채팅 표시), 채팅마다 별도 기록 파일(100개 제한 없앰), 폴더 생성·이동·휴지통, 모델별 추론 강도 선택
  • 그 밖에 PDF 페이지 검색·OCR, 출처가 남는 웹 리서치, Canvas·Bases용 스킬, MCP 연결, Codex CLI 연동

어떻게 고를까

  • 생각을 많이 흘리는 편 → xiaoji: 마찰을 줄이는 게 먼저. AI는 나중에 ‘내 메모 검색기’로
  • 볼트를 AI와 같이 정리·편집 → Glossa: ‘승인 후 쓰기 + 되돌리기’가 있는 쪽
  • 공통 원칙: 원본은 Markdown으로 내 볼트에, AI는 그 위에 얹는 층. LLM Wiki를 만들 때도 같은 원칙이 기본이다

> 지난번 저장하신 Obsidian Copilot ‘에이전트 수정 검토’·‘고치지 않는 AI’ 기사와 이어지는 소식입니다.
