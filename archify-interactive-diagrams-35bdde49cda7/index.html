[11/1] 디자인: Archify — 말로 물으면 검증된 인터랙티브 HTML 다이어그램·한 페이지 답이 나온다. 에이전트 스킬

tt-a1i/archify가 아이디어·계획·코드베이스를 탐색 가능한 단일 HTML 다이어그램(또는 결론 우선 원페이지)으로 만드는 에이전트 스킬이다. 아키텍처·워크플로·시퀀스 등 10종, finalize 전 validate·deliver·check. Claude Code·Codex·Cursor·OpenCode·Copilot. Apache-2.0. BeWisp 주간 스타 +3.2K대.

분류: 디자인/UI·UX

한줄 요약

Mermaid ‘슬롭’ 대신 레이아웃·라벨·교차까지 검사한 뒤 브라우저에서 바로 열리는 맵을 받게 하는 스킬이다(archify.si, GitHub).

품질 게이트

finalize가 schema·교차·라벨 여백 등 검사 → 스테이징 렌더 후 원자적 교체 → 파일 해시 재확인. 브라우저 체크(해상도별 overflow)는 옵션. 빈 차트 칸은 0이 아니라 에러.
