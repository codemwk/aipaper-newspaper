[11/26] 디자인: 디자이너가 만든 ‘에이전트 팀 작업실’ Granular.Build — 상사 에이전트가 전문 에이전트를 고용하고, 앱·디자인·영상이 한 캔버스에서 미리보기로

디자인 툴 Glorify를 만들어 매각한 디자이너 Omar가 11/24 Granular.Build를 Product Hunt에 냈다(그날 2위, 232표). 폴더 하나를 가리키면 프로젝트의 목표·고객·결정을 적어 ‘뇌’로 만들고, 상사 에이전트가 Claude·Codex·Gemini·DeepSeek·GLM 등 여러 모델의 작업자를 각자 터미널과 프로젝트 사본에 배치해 병렬로 일하게 한다. 쓰던 AI 구독을 그대로 가져오고, 파일은 내 컴퓨터에 남는다.

분류: 디자인 / UI·UX

한줄 요약

터미널은 개발자용, IDE는 엔지니어용, 데스크톱 AI 앱은 한 회사 모델에 한 번에 한 대화. “디자이너·마케터·PM이 에이전트 팀을 부릴 화면은 없다”는 문제의식에서 나온 시각적 작업 공간이다(Product Hunt 소개).

무엇을 하나

  • 프로젝트가 ‘뇌’가 된다: 아무 폴더나 가리키면 미션·고객·결정 사항을 적어 두고, 그걸 로드맵 카드로 바꿔 에이전트가 카드 단위로 일한다.
  • 상사 에이전트가 팀을 꾸린다: 목표를 주면 상사 에이전트가 Claude, Codex, Gemini, DeepSeek, GLM 등 여러 모델의 작업자를 부른다. 각자 자기 터미널과 프로젝트 사본에서 일해 서로의 작업을 덮어쓰지 않는다.
  • 결과물이 한 화면에: 앱·디자인·영상이 라이브 미리보기로 모인다. 디자이너가 레퍼런스를 넣으면 SNS 게시물, 영상, 출시 이메일이 한 캔버스에 나오는 식.
  • 도구·키·파일은 내 것: 1,400개 이상 앱 연결, 암호화된 금고에 API 키 보관(에이전트는 쓰기만), 스킬·플러그인 추가. 모든 것이 내 컴퓨터의 실제 파일로 남고, 미리보기 공유는 무료, 배포는 내 호스팅으로.
  • 창업자는 홍보 영상도 Granular 안에서 Higgsfield·Premiere Pro MCP 연결로 만들었다고 밝혔다.

가격

  • 쓰던 Claude·Codex·Gemini 등 기존 구독을 그대로 연결 → 새 AI 요금 없음.
  • 무료: 프로젝트 2개, 프로젝트당 세션 4개(도구 제한 없음). Pro는 제한 해제(가격은 사이트 공개).

왜 중요한가

  • 디자인 도구의 경쟁 무대가 “그리는 캔버스”에서 “에이전트를 지휘하는 캔버스”로 넓어지고 있다. Figma 에이전트, Stitch Loop와 같은 방향을 비개발자 1인 스튜디오 쪽에서 푼 사례다.
  • 1인 브랜드 스튜디오라면 “웹사이트 + 출시 영상 + SNS 세트”를 한 프로젝트 기억 안에서 일관되게 뽑는 실험을 해 볼 만하다.
  • 주의: Product Hunt 순위·후기는 출시 당일 기준이다. 두 작업자가 같은 파일을 건드릴 때의 처리, 진행 중인 기존 프로젝트를 가져올 때의 동작은 댓글로 질문만 나왔고 공식 답은 확인되지 않았다. 디자인 시스템 검증 기능도 문서화돼 있지 않다(Design Agent 리뷰 지적).
