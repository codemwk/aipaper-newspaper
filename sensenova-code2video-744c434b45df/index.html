[10/28] AI 콘텐츠: 영상을 ‘그리지’ 않고 ‘코딩’한다 — 센스타임 SenseNova 6.8 Code2Video 오픈소스(27B, Apache-2.0). 모션그래픽·움직이는 글자·설명 영상을 코드로 만들고, “이 부분 색만 바꿔 줘”가 정확히 먹히는 이유

센스타임이 10/27 ‘코드로 영상 만드는’ 모델 SenseNova 6.8 Code2Video를 Apache-2.0으로 공개. Qwen3.8-27B를 다듬은 27B 모델로, 픽셀을 직접 생성하는 대신 실행 가능한 코드를 써서 렌더링한다. 그래서 수정 지시가 ‘다시 뽑기’가 아니라 ‘코드 고치기’가 되어 색·타이밍·요소를 정확히 바꿀 수 있다. 권장 실행 환경은 Claude Code + 전용 스킬로, 한 편에 10시간·2,000턴 이상 돌아가며 최종 영상과 함께 SPEC.md(설계서)·VERIFY.md(검수 기록)를 남긴다. 수치 벤치마크는 없고 ‘초기 결과’ 예시만 공개.

분류: AI 콘텐츠

한줄 요약

대부분의 영상 AI는 그림(픽셀)을 직접 만든다. Code2Video는 영상을 만드는 프로그램 코드를 쓴다. 그래서 결과물이 ‘수정 가능한 설계도’로 남는다(Hugging Face 모델 카드).

어떤 영상에 맞나

  • 모션그래픽, 움직이는 글자(키네틱 타이포그래피), 애니메이션 일러스트, 제품 소개, 설명 영상처럼 도형·글자·레이아웃으로 이루어진 짧은 영상.
  • 실사 촬영 같은 영상은 아니다. 대신 코드가 이미지·영상 생성 모델, 3D·편집 도구를 불러서 엮을 수 있다는 게 회사가 코드를 고른 이유다. 장기 목표는 “여러 생성 모델과 도구를 코드로 지휘하는 모델”.

만드는 과정 (모델 카드 안내)

단계누가결과물
1. 요청 다듬기강한 범용 모델(센스타임은 Claude Opus 5.5 사용)상세 기획서 dense_prompt.md
2. 제작Code2Video + Claude Code + code-video 스킬최종 영상 final.mp4, 설계서 SPEC.md, 검수 기록 VERIFY.md
3. 수정(선택)사람이 메모 → 같은 프로젝트에서 반영새 버전 영상
  • 한 편 제작이 10시간 이상, 2,000턴 이상 이어지는 ‘장거리 작업’이다. 코드를 쓰고 → 렌더링하고 → 프레임을 보고 → 고치기를 반복한다.
  • 문맥 512K. 예시 설정은 GPU 4장 분산 실행 기준이라 개인 노트북용은 아니다(INT4·INT8 경량판은 예정이라고 알려짐).
  • 제작 과정 기록(대화·도구 호출·그림 357장)도 함께 공개해 어떻게 만들었는지 따라가 볼 수 있다.

왜 중요한가

  • 수정이 정확해진다. 픽셀 생성 영상에 “로고 색만 바꿔 줘”라고 하면 다른 부분까지 바뀌기 쉽다. 코드 영상은 해당 값만 바꾸면 된다. 브랜드 컬러·폰트를 지켜야 하는 브랜드 모션 작업에 특히 맞는 방식이다.
  • ‘설계서 + 검수 기록’이 기본 산출물. 결과 영상만 주는 게 아니라 SPEC.md와 VERIFY.md를 남긴다는 점은, AI 제작물을 클라이언트에게 설명하고 넘겨야 하는 스튜디오 입장에서 실용적이다.
  • 같은 흐름의 신호들. 오늘 디자인면의 Rive(애니메이션을 마크업·코드로 다루는 도구)처럼, 크리에이티브 도구들이 ‘에이전트가 읽고 고칠 수 있는 형식’으로 모이고 있다.

주의할 점

  • 모델 카드는 성능을 ‘초기 결과’라고만 표현했고, 수치 벤치마크는 내놓지 않았다. 공개된 건 예시 영상과 제작 기록이다.
  • 권장 실행 방식은 에이전트가 명령을 묻지 않고 실행한다. 모델 카드도 “격리된 작업 환경에서 시작하라”고 적었다. 내 작업 폴더·계정이 있는 컴퓨터에서 바로 돌리지 말 것.
