[11/23] 디자인: 배민 ‘CLAYDesign’ — 범용 AI 디자인 도구가 ‘배민 같지만 배민 아닌’ 화면을 그리자, 디자인 시스템으로 직접 만든 사내 도구

우아한형제들 디자인시스템팀이 11/20 기술블로그에 사내 AI 도구 CLAYDesign의 구조를 공개했다. 한 줄 프롬프트로 배민 디자인 시스템(클레이 민트) 컴포넌트만 써서 화면을 만들고, Figma·React·SwiftUI·Compose 코드와 사내 테스트 앱으로 내보낸다. 핵심은 AI에게 코드를 쓰게 하지 않고 ‘화면 JSON 문서’를 쓰게 한 뒤, 디자인 시스템 코드에서 자동 추출한 카탈로그로 검사해 틀린 값은 저장을 막는 것. 전사 정식 운영 첫 주 300명 이상이 화면 1,000개 이상을 만들었다.

분류: 디자인 / UI·UX

한줄 요약

화면 하나는 기획자·디자이너·개발자가 세 번 그린다. 배민은 이걸 한 번으로 줄이려고 범용 AI 도구(Claude Design, Figma Make 등)를 써 봤다. 결과는 “그럴듯하지만 배민 디자인 시스템에 없는 컴포넌트를 쓰고 색과 간격을 지어낸” 화면이었다. 그래서 직접 만들었다(우아한형제들 기술블로그).

어떻게 동작하나 (6단계 요약)

  • 빈칸은 질문으로: 짧은 프롬프트에 빠진 정보(목적, 서비스, 화면 형태, 주요 행동 등)를 표준 질의서로 물어본다. 처음엔 모델이 질문 문장까지 만들어 6.8초가 더 걸렸다. 지금은 앱이 정해진 질문을 띄우고 모델은 ‘필요/불필요’만 판정한다. 판정 프롬프트가 6,288자 → 1,556자로 줄었다.
  • 빈 화면 대신 배민 화면에서 시작: 등록된 실제 배민 화면 템플릿 중 하나를 AI가 고른다(예: ‘마카롱 공방 장바구니’ → 푸드 장바구니 템플릿).
  • 디자인 시스템을 알려 준다: 쓸 수 있는 컴포넌트·속성·토큰·아이콘 카탈로그를 디자인 시스템 코드에서 자동 추출한다. 사람이 옮겨 적지 않는다.
  • AI는 코드 대신 ‘화면 JSON’을 쓴다: 화면을 요소 목록으로 적은 문서다.
  • 검사: 카탈로그에 없는 값이 있으면 유효성 검사가 저장을 막는다. 디자인 린트도 돈다.
  • 내보내기: 통과한 결과를 Figma 레이어, React·SwiftUI·Compose 코드, 사내 테스트 앱으로 바로 확인한다.

팀이 정리한 교훈

  • 코드가 아는 값은 모델에게 쓰게 하지 말고, 고르게만 하라.
  • 빈 화면보다 템플릿에서 시작하라.
  • 디자인 시스템은 코드에서 뽑아라.
  • 가이드로 못 정하는 화면 원칙은 디자이너가 직접 써라.
  • 화면은 JSON으로 쓰게 하라. 검사하기 쉽고 바뀐 부분만 고칠 수 있다.
  • 채점 기준을 먼저 정하고, AI에게 주는 내용을 고칠 때마다 다시 채점하라. 가이드 하나 추가가 템플릿 선택 정확도를 흔든 적이 있다.

왜 중요한가

요즘 “AI가 만든 화면은 다 비슷해 보인다”는 불만의 답이 여기 있다. AI에게 자유를 주지 말고, 브랜드의 부품 목록 안에서만 고르게 하라. 디자인 시스템이 탄탄한 회사일수록 AI 도구의 품질이 올라간다는 실증이다. 브랜드 스튜디오에도 그대로 적용된다. 클라이언트에게 아이덴티티를 넘길 때 ‘AI가 읽을 수 있는 토큰·컴포넌트 목록’까지 함께 납품하면, 그 브랜드는 AI 시대에도 흐트러지지 않는다. 다만 공개된 수치는 첫 주 생성량뿐이고, 제작 시간 단축률이나 실제 서비스 반영률은 아직 없다.
