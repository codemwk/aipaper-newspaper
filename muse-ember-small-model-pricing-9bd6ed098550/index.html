[11/11] Meta Muse Ember: ‘하루 종일 반복되는 에이전트 일’용 초저가 모델 — 그리고 긴 프롬프트 요금의 함정

Meta가 11/10 가장 작은 모델 Muse Ember를 냈다. 도구 호출·라우팅·추출·긴 문서 파싱용이며 짧은 프롬프트 기준 입력 0.10/출력 0.50달러로 GPT-6 Luna·Claude Haiku 5.5와 같다. 하지만 세 모델 모두 일정 길이를 넘으면 단가가 오른다.

분류: AI 모델

무엇인가

Meta가 Muse Ember 1.0을 공개했다. 스스로 “복잡한 추론 실행과 에이전트가 하루 종일 반복하는 일 — 도구 호출, 코딩 하위작업, 라우팅, 추출, 긴 문서 파싱”을 위한 가장 작고 효율적인 모델이라고 소개한다. 위 기사의 Fable·Carbon이 ‘팀장’이라면 Ember는 ‘실무자’ 자리다(Simon Willison 정리).

가격표를 끝까지 읽어야 하는 이유

세 소형 모델 모두 100만 토큰 입력을 지원하지만, 문턱을 넘으면 단가가 오른다.

모델문턱 이하 (입력/출력, $/M)문턱 초과
GPT-6 Luna≤272k: 0.10 / 0.500.20 / 0.75
Muse Ember 1.0≤200k: 0.10 / 0.500.30 / 1.50
Claude Haiku 5.5≤100k: 0.10 / 0.500.50 / 2.50

짧은 작업이면 셋이 같은 값이지만, 긴 문서·볼트 전체를 통째로 넣는 작업이라면 Luna가 가장 싸고 Haiku가 가장 비싸다. 캐시 입력은 Ember가 0.004달러로 가장 낮다 — 같은 시스템 프롬프트를 반복하는 에이전트에 유리하다.

성능은

Meta는 Ember가 Artificial Analysis 지표에서 “작업당 비용 대비 지능의 효율 경계(Pareto frontier) 위에 있다 — 이보다 싸면서 더 높은 모델은 없다”고 주장한다. 추론 단계가 minimal부터 max까지 6단계다. Willison의 간단한 SVG 테스트에서는 단계가 올라간다고 결과물이 꼭 좋아지지는 않았고, ‘high’ 단계는 SVG를 끝까지 출력하지 못하기도 했다. 다만 40배 비싼 Muse Wonder와 비슷한 품질의 결과도 나왔다고 한다.

실무 팁

  • 토큰 단가 비교는 이제 의미가 줄었다. 추론 토큰 사용량이 모델마다 크게 달라서 작업당 비용을 봐야 한다.
  • 세컨드 브레인 자동화(노트 요약·태그·링크 추천)처럼 반복적이고 짧은 일은 소형 모델로, 판단이 필요한 단계만 상위 모델로 올리는 2단 구성이 가장 싸다.

주의

효율 경계 주장은 Meta 발표 문구이며, 요금 문턱은 바뀔 수 있으니 실제 API 가격 페이지를 확인할 것.
