Design: Midjourney Alpha — 스타일 라이브 프리뷰·한국어 전면, Create 피드 개편

Midjourney Alpha Changelog(2026-09-23/24). Styles 사이드바 Live previews로 프롬프트×스타일 즉시 미리보기. 기본 파라미터 저장. Create 피드 풀폭 메이슨리. 편집 v8.1/8.2·HD. 한국어 midjourney.com 전면.

분류: Design / UI·UX

한줄 요약

Midjourney Alpha 9/23 변경(게시 9/24)이 탐색 UX를 손봤다. 모델 점수 발표가 아니라, 스타일을 고르기 전에 보이는 피드백을 주는 디자인 개편이다.

무엇이 바뀌었나

  • Style Live previews: Styles 탭에서 Live previews on → 스크롤하며 현재 프롬프트를 스타일별로 빠른 모델로 미리보기. 클릭 시 해당 스타일로 프롬프트 전송.
  • Default parameters: Settings → Advanced → Your defaults, 또는 “Set current pills as default”.
  • Create feed: 풀폭 메이슨리, 호버 시 프롬프트/버튼, 영상 호버 재생, Grid/List·Organize·Archive 개선.
  • Editing: 화살표로 편집 히스토리, v8.1/v8.2 편집 타입·HD 캔버스.
  • 한국어: 전주 alpha 도입 후 midjourney.com 전체에 라이브.

왜 중요한가

생성 도구의 차별화는 종종 모델보다 선택 비용(어떤 스타일? 어떤 기본값?)을 줄이는 UI다. Framer Skills·Stitch 브랜드 키트와 같은 날의 주제: 지시와 미리보기를 가깝게.
