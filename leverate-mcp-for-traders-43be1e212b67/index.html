Leverate MCP for Traders — 채팅으로 주문 준비, 예는 반드시 사람이

2026-09-16~17. Leverate가 MCP for Traders 출시. Claude·ChatGPT를 라이브 계좌에 연결, 주문은 채팅 안 yes 확정 후만. 브로커가 기본 off로 켠다. Finance Magnates·GlobeNewswire.

분류: AI Trading

한줄 요약

Finance Magnates·GlobeNewswire에 따르면, 화이트라벨 브로커 인프라 업체 Leverate는 2026-09-16경 MCP for Traders를 공개했다. ChatGPT·Claude 같은 MCP 호환 어시스턴트를 라이브 트레이딩 계좌 하나에 붙인다.

무엇이 바뀌었나

  • 7월에 낸 MCP for Brokers(CRM·리스크·백오피스 조회)와 달리, 이번엔 개별 트레이더 계좌와 주문 도구까지 연다.
  • 연결 도구는 약 15개: 읽기 10·주문/관리 5. 어시스턴트는 심볼·방향·크기·유형·가격·스탑·마진 영향을 다시 말한 뒤, 트레이더가 채팅에서 yes를 줘야 시장으로 간다.
  • 어시스턴트는 연결된 계좌·브로커 제공 상품만 답하고, 투자 조언·예측 요청은 거절하도록 지시된다고 회사는 밝혔다.
  • 브로커가 Broker Portal에서 브랜드별로 켜고, 그룹·약관·국가·수동 allowlist로 대상을 제한한다. 기본값은 off.
  • AI 발주 주문은 CRM에 별도 소스 플래그로 남고, 프롭 계정은 기존 리스크 엔진·챌린지·일손실 한도를 그대로 탄다. MT4/5용 커넥터는 후속 예정.

왜 중요한가

어제·그저께 본지에서 다룬 cTrader·eToro·MT5 테스터 라인과 같은 축이다. Leverate는 “브로커 소프트웨어 공급자가 클라이언트 채팅 체결을 연다”는 중간 계층. FM Intelligence 기준 상반기에 최소 10곳이 계좌를 AI에 열었고, Claude가 그중 9곳에 이름 올랐다. Investing.com(4월, 미국 투자자 938명)은 62%가 투자 결정에 AI를 썼고 39%는 잘못된 추천을 걱정했다. 사람 확인 루프가 제품의 중심이다.
