[11/6] 디자인: Kittl — ChatGPT·Claude 안에서 Brand Kit으로 제품컷·목업·숏폼을 만드는 MCP

Kittl이 11/3 ChatGPT·Claude용 MCP를 공개했다. 채팅에서 캠페인·리스팅·변형·폴더 일괄 처리를 요청하면 Brand Kit·목업·배경 제거·업스케일·벡터·영상이 이어진다. 유료 플랜 연결 시 7일 300장 보너스. Claude Code·Codex·원격 MCP도 지원.

분류: 디자인

한줄 요약

기획은 ChatGPT·Claude에서 하고, 시각물은 따로 툴을 열던 흐름을 Kittl이 같은 채팅 안으로 끌어들였다. 11/3 MCP 연결을 공개했다(Kittl 블로그).

지금 뭐가 뜨나

  • 한 번 연결: kittl.com/mcp에서 ChatGPT·Claude에 추가. Claude Code·Codex·원격 MCP 앱도 지원.
  • Brand Kit 유지: 색·폰트·로고가 결과물에 따라붙는다. 웹사이트 URL만 주면 Brand Kit을 새로 만들 수도 있다.
  • 워크플로 예시: 제품 한 장 → IG·스토리·광고·숏폼 / 베스트셀러 스타일로 신규 리스팅 세트 / 디자인 10변형 후 티셔츠 목업 / 폴더 전체 배경 제거·업스케일·벡터.
  • 보너스: 유료 플랜 연결 시 7일 안에 쓸 300장 분량 토큰(ChatGPT 2.5 Flare 기준 1,500 토큰 환산). 모델마다 소모량이 다르다.
  • 라이브 데모: 11/10.

왜 중요한가

지난번 저장하신 Studiolo·Lovart·Figma Agent 같은 ‘에이전트가 디자인 툴을 직접 조작’ 흐름의 브랜드 커머스 버전이다. 범용 이미지 모델이 제품을 왜곡하는 문제를, 디자이너가 짜 둔 워크플로+Brand Kit으로 줄이겠다는 접근이다. doop이 오픈소스 캔버스라면, Kittl은 판매용 목업·리스팅에 특화돼 있다.

주의

어시스턴트 기본 이미지 도구와 섞이지 않게 프롬프트에 “Use Kittl to…”를 명시하라고 안내한다. 최종 미세 조정·고해상도 내보내기는 Kittl 앱으로 돌아가라고 한다.
