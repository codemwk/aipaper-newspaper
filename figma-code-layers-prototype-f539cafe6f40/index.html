[11/4] 디자인: Figma 코드 레이어가 ‘프로토타입 연결선’을 읽는다 — 화면 사이 흐름을 다시 설명할 필요 없이 코드로. GitHub 저장소 복제는 기본 허용, 무료 기간은 오늘(11/4)까지

Figma가 11/3 디자인 프레임으로 코드 레이어를 만들 때 에이전트가 프레임 사이의 프로토타입 연결·인터랙션까지 읽도록 바꿨다. 같은 날 새 GitHub 저장소 연결은 Figma로의 복제(clone)가 관리자 추가 승인 없이 기본 허용(기존 연결 설정은 유지). 11/2엔 셰이더 4096px 출력과 코드 레이어 반영. 코드 레이어 생성·편집 무료 기간은 유료 플랜에서 11/4까지, 이후 AI 크레딧 차감.

분류: 디자인/UI·UX

한줄 요약

디자이너가 이미 프로토타입 탭에 그려 둔 “이 버튼 누르면 저 화면으로, 스르륵”이 이제 코드 생성의 입력이 된다. 흐름을 프롬프트로 다시 풀어 쓰는 수고가 줄어든다(Figma 릴리스 노트).

이번에 바뀐 것

날짜변경의미
11/3코드 레이어가 프로토타입 연결·인터랙션을 컨텍스트로 읽음화면 전환·조건 흐름을 에이전트가 이해하고 코드로 옮김. 남는 시간은 예외 상황(엣지 케이스) 찾기에
11/3새 GitHub 저장소 연결 시 복제 기본 허용기존 프론트엔드 코드를 바로 캔버스로. 관리자는 저장소별로 끌 수 있고, 기존 연결 설정은 그대로
11/2셰이더 최대 4096px 렌더·출력, 정식 제공 + 코드 레이어로 이어짐시각 효과가 인터랙티브 프로토타입까지 따라감(처음엔 Chrome 157부터) (UX News)

놓치기 쉬운 일정

코드 레이어는 오픈 베타로 모든 플랜에 순차 배포 중이다. 유료 플랜의 코드 레이어 생성·편집 무료 기간은 11/4까지, 이후엔 다른 에이전트 기능처럼 AI 크레딧을 쓴다(작업 복잡도에 따라 차감). 무료로 실험해 보려면 오늘이 마지막 날이다(Figma 도움말: Config India 2026).

왜 중요한가

  • 디자인 → 코드 변환의 약점은 늘 ‘화면 사이’였다. 정적인 화면은 잘 뽑아도, 상태와 전환은 사람이 설명해야 했다. 프로토타입 연결을 읽는다는 건 Figma 파일 자체가 동작 명세서 역할을 한다는 뜻이다.
  • 저장소 복제 기본 허용은 반대 방향(코드 → 캔버스)의 문턱을 낮춘다. 디자인과 코드가 한 캔버스에서 왕복하는 구조가 기본값이 되어 가는 중.

주의

  • 복제 기본 허용은 편리하지만 코드가 Figma 안으로 들어온다는 뜻. 민감한 저장소는 관리자가 개별로 막아 두자.
  • 오픈 베타라 계정마다 노출 시점이 다르다(툴바에 Code 아이콘이 보이면 사용 가능).
