AI 트레이딩: MT5 Build 6180 — 에이전트가 Strategy Tester 리포트·최적화를 직접 돌린다

Finance Magnates 2026-09-03. MT5 Build 6180. MCP 에이전트가 테스터 리포트·로그·최적화 결과 수집, 최적화 실행·기준 설정, 차트 지표 추가. 라이브 매매 판단은 여전히 미개방. Build 6060 네이티브 MCP 이후 연장. AI Assistant 3주 ~1조 토큰(8월 공개분).

분류: AI 트레이딩

한줄 요약

Finance Magnates(2026-09-03)에 따르면 MetaQuotes MT5 Build 6180은 AI Assistant·외부 MCP 에이전트가 Strategy Tester의 리포트·로그·최적화 결과를 읽고, 최적화를 시작하고 기준을 설정하며, 차트에 지표를 추가할 수 있게 했다. 연구·디버그·알고리즘 튜닝은 열리고, 라이브 계좌의 매매 판단은 아직 막혀 있다.

맥락

  • Build 6060(2026-07-23): 네이티브 MCP·에이전틱 AI 도입(릴리즈 노트).
  • 경쟁: cTrader AI Agent Connect는 매매 오퍼레이션까지, eToro Agent Portfolios는 한도 안 자율 매매 — MetaQuotes는 프로토콜 개방 + 판단 보수 포지션.
  • 사용량: 회사는 7월 MCP 롤아웃 후 3주간 AI Assistant가 1조+ 토큰을 처리했다고 8월에 공개(보도 기준 마지막 수치).

왜 중요한가

어제 RiskGate(신호 vs 리스크 분리)와 맞물리면, MT5 쪽 실무 루프는 “에이전트가 백테스트 QA 엔지니어” 단계다. 라이브 집행 전에 테스터·권한 게이트를 두는 설계가 기본값이 된다.
