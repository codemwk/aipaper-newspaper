[11/24] GitHub 이번 주: ‘에이전트가 진짜 소프트웨어를 만지게’ — 아무 프로그램이나 명령어로 바꾸는 CLI-Anything, 채팅 한 줄을 PR까지 끌고 가는 텐센트 LoopForge, 에이전트↔화면 규격 AG-UI

11/16~21 GitHub 트렌딩을 묶은 주간 정리에서 반복된 주제는 ‘화려한 데모가 아니라 배관’이었다. CLI-Anything(약 6.3만★)은 아무 소프트웨어나 에이전트가 부를 수 있는 명령줄 도구로 바꾸는 7단계 생성기와 공유 허브를 낸다. 텐센트 LoopForge(약 5,900★, 11/23 v0.4.2)는 채팅으로 요구사항을 받으면 도커 샌드박스에서 역할을 나눠 작업하고 사람 승인 관문을 거쳐 PR을 올리는 자체 호스팅 작업장이다. AG-UI는 에이전트와 사용자 화면을 잇는 약 16종 이벤트 규격이다.

분류: GitHub 트렌드

한줄 요약

에이전트는 생각은 잘하는데 진짜 프로그램을 다루는 건 서툴다. 이번 주 GitHub 상위권은 그 틈을 메우는 저장소들이었다. 11/16~21 트렌딩을 합친 주간 정리는 “불꽃놀이가 아니라 배관의 주”라고 요약했다(Tommy Zhang 주간 정리, 11/23 트렌딩).

CLI-Anything — “모든 소프트웨어를 에이전트용으로”

  • 무엇: 사람이 쓰던 프로그램을 에이전트가 부를 수 있는 명령어 도구(CLI)로 바꾼다(GitHub). 홍콩대 HKUDS 연구실 프로젝트, 약 6.3만★(11/23 하루 +699).
  • 두 갈래: ① 남들이 만든 도구를 CLI-Hub에서 찾아 설치, ② /cli-anything 명령으로 내 프로그램·사내 도구에 분석 → 설계 → 구현 → 테스트 계획 → 테스트 작성 → 문서화 → 배포 7단계 생성기를 돌린다.
  • 왜 CLI인가: 화면을 흉내 내며 클릭하는 자동화는 쉽게 깨진다. 명령어는 서로 이어 붙일 수 있고, --help로 스스로 설명하고, JSON으로 결과를 내 매번 같은 결과가 나온다.
  • 만든 도구에는 되돌리기(undo/redo)가 기본이고, Claude Code·Cursor·Codex·Copilot CLI 등에 붙는다.

LoopForge — 채팅 한 줄에서 PR까지, 사람 관문 포함

  • 무엇: 코딩 에이전트로 소프트웨어를 납품하는 팀을 위한 자체 호스팅 작업장(GitHub). 텐센트, 11/23 v0.4.2.
  • 흐름: 채팅으로 메인 봇에게 요구사항을 말하면 → 도커 샌드박스를 띄우고 저장소를 받아 → 기획·구현·리뷰 같은 역할에 나눠 맡기고 → PR을 올린다.
  • SOP로 저장: 한 번 검증된 방식은 “에이전트 + 스크립트 + 사람 승인 관문”으로 묶은 표준 절차가 된다. 실행은 관찰·재개할 수 있다.
  • 문제의식: “이 버그 고쳐”라고 시키면 그 한 번의 실행에 결과가 달려 있다. 계획을 건너뛰고, 테스트를 잊고, 자기 코드를 자기가 리뷰하고, 몰래 멈춘다. 데모엔 괜찮아도 팀이 납품하는 방식은 아니라는 것.
  • Claude Code·Codex·Cursor CLI·OpenCode·Kimi Code 등을 실행기로 쓴다. 기존 코딩 도우미 안에서 쓰는 LoopForge Local도 있다.

AG-UI — 에이전트와 ‘화면’ 사이의 공용어

  • 에이전트가 실행 중에 약 16종 표준 이벤트를 내보내면, 앱 화면이 그걸 받아 채팅 스트리밍·상태 동기화·생성형 UI·사람 확인을 처리한다(GitHub).
  • 정리하면 MCP = 에이전트에게 도구, A2A = 에이전트끼리, AG-UI = 에이전트와 사용자 화면. LangGraph, CrewAI, Google ADK, Mastra, Claude Agent SDK 등과 연동되고 MIT 라이선스다.

왜 중요한가

세 저장소의 공통점은 “모델을 더 똑똑하게”가 아니라 “모델을 일하게 하는 틀”이다. 메신저에서 시킨 일을 PR로 받는 흐름을 고민 중이라면 LoopForge의 SOP + 사람 관문 설계가 가장 직접적인 참고가 된다. 오늘 실린 Claude Ship이 “PR 이후”를 맡는다면, LoopForge는 “PR 이전”의 절차를 맡는 셈이다. CLI-Anything은 자동매매나 디자인 도구처럼 API가 없는 프로그램을 에이전트에 연결할 때 화면 클릭 자동화 대신 시도해 볼 만한 방법이다.
