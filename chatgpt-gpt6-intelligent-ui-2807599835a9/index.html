디자인/UI·UX: ChatGPT ‘Intelligent UI’ — GPT-6가 답을 글 대신 버튼·폼·차트·계산기로 ‘조립’한다, 오늘부터 무료 사용자까지

OpenAI가 10/7 GPT-6를 ChatGPT 전 등급에 배포하며 Intelligent UI를 공개했다. 모델이 질문에 맞춰 텍스트·이미지·탭 버튼·폼·차트·인터랙티브 도구를 조합하고, ‘네이티브 스트리밍 컴포넌트 라이브러리 + 컴파일러’가 화면을 점진적으로 그린다. 유료는 10/7, Free·Go는 10/8부터(GPT-6 Luna).

분류: 디자인/UI·UX

한줄 요약

챗봇의 답이 “긴 글”에서 “그 질문을 위한 작은 앱”으로 바뀌기 시작했다. OpenAI는 10월 7일 GPT-6를 ChatGPT에 배포하며 Intelligent UI를 공개했다. 유료(Plus·Pro·Business·Enterprise)는 10/7, Free·Go는 10/8부터 순차 적용된다(Unite.AI 정리).

무엇이 달라 보이나

  • 답변이 텍스트·이미지·탭 가능한 버튼·폼·차트·인터랙티브 체험의 조합이 된다. 비교는 나란히, 원리 설명은 클릭해 보는 다이어그램, 단순 질문엔 여전히 짧은 글.
  • 시연: 7단 자전거를 프레임·휠·구동계·브레이크·콕핏 5개 시스템으로 눌러 보는 해부도 / “일요일 양고기 로스트” 요청에 요리 이미지 + 인원수에 따라 바뀌는 장보기 계산기 + 체크리스트형 조리 타임라인.
  • “도구를 만들어 줘”도 된다 — 저축 계산기, 더치페이 계산기, 대화 안 게임.

디자이너가 볼 지점: 어떻게 만들었나

  • 네이티브·스트리밍 가능한 컴포넌트 라이브러리: 모든 답에 익숙한 디자인 기반을 주되, 배치는 모델이 결정한다. 즉 ‘디자인 시스템 위의 생성형 레이아웃’이다.
  • 컴파일러: 모델이 생성하는 동안 인터페이스를 처리해 화면이 점진적으로 나타난다(전체 답을 기다리지 않음).
  • 학습에 콘텐츠·레이아웃·시각·인터랙션 판단을 넣고, 생성한 UI를 명료성·유용성·완결성으로 평가했다. OpenAI 스스로 “모델의 디자인 판단력은 더 개선할 여지가 있다”고 밝혔다.

모델 쪽 변화도 함께

  • 생각하면서 답하기 시작(사고와 답변을 교차). 웹 검색이 필요한 질문에서 GPT-6 Instant는 GPT-5.6 Instant보다 평균 44% 먼저 답을 시작(회사 내부 평가).
  • 유료는 GPT-6 Sol, Free·Go는 GPT-6 Luna. Work·Codex 모델은 이번 변경 대상이 아니다.

왜 중요한가 (UI·UX 관점)

“사람이 소프트웨어에 맞추는 대신, 소프트웨어가 사람에게 맞춘다”는 게 OpenAI의 문장이다. 12억 주간 사용자가 매일 ‘즉석 UI’를 보게 되면, 사용자의 기대치가 바뀐다 — 정적인 대시보드·폼은 점점 낡아 보일 것이다. 제품 디자이너의 일은 화면 하나하나를 그리는 것에서 모델이 조립할 ‘부품(컴포넌트)과 규칙’을 설계하는 것으로 옮겨 간다. 개인 대시보드/퍼스널 OS를 구상한다면 직접 참고할 패턴이다.
