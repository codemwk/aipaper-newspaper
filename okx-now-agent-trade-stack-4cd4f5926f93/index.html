AI 트레이딩: OKX NOW — ‘프롬프트→전략’ AI Bot 시연, 에이전트에게 지갑을 ‘한도 안에서’ 맡기는 스택까지

10/6 싱가포르 OKX NOW에서 자연어로 개인 맞춤 전략을 만드는 AI Bot을 시연(출시일 미정). Agent Trade Kit·OnchainOS·Agentic Wallet·에이전트 마켓·AI Builder Program을 한 줄로 묶었다. 같은 주 Schwab Charley는 ‘매매 불가’, Webull Cloud MCP는 ‘주문 준비+별도 확인’ — 권한 스펙트럼이 선명해졌다.

분류: AI 트레이딩

한줄 요약

OKX가 10월 6일 싱가포르 OKX NOW 행사에서 “말로 설명하면 나만의 매매 전략을 만들어 주는” AI Bot을 시연했다. 출시는 “임박”이라고만 했고 날짜는 밝히지 않았다(TokenPost). 더 눈여겨볼 건 봇 하나가 아니라 에이전트가 ‘분석’에서 ‘실행’까지 가는 길을 통째로 깔았다는 점이다.

발표된 스택 (OKX AI 팀 설명 기준)

  • Agent Trade Kit: 내 AI 에이전트가 OKX 거래소 데이터에 붙고 주문까지 실행(OKX 가이드).
  • OnchainOS: 온체인 자산을 자연어로 조작.
  • Agentic Wallet: 미리 정한 가드레일 안에서만 AI에게 자금을 배정.
  • OKX AI 에이전트 마켓: 전문 트레이딩 에이전트의 시그널을 구독하고 카피트레이딩을 승인.
  • AI Builder Program: 개발자가 자기 모델·전략으로 돈을 버는 통로(MCP·CLI·API·OAuth 연동).

OKX가 내건 원칙은 “AI는 사용자 의도를 이해하고, 사용자가 정한 경계를 지키며, 사람의 판단이 필요한 지점에서는 사용자에게 돌아온다”였다(ChainCatcher 현장 보도).

같은 주, 세 회사의 ‘권한 온도차’

AI가 할 수 있는 일매매
Schwab Charley(10월 단계적 출시)잔고·포지션 조회, 관심종목·알림·배당재투자·수익자 등록불가, 상담원 연결
Webull Cloud MCP(9/29)리서치·포트폴리오 분석 후 주문 준비주문마다 별도 확인
OKX(10/6)전략 생성, 한도 내 지갑 위임, 시그널 구독·카피가드레일 안에서 에이전트 실행

Schwab은 자체 설문(고객·잠재고객 500여 명, 9/21~25)에서 65%가 “사람의 전문성과 결합될 때 AI가 일상 업무나 투자에 의미 있는 역할을 할 수 있다”고 답했지만, 의미 있는 계좌 조작은 사람이 하길 원했다고 밝혔다(Schwab). Webull은 Claude·Perplexity·Grok에서 쓸 수 있고 ChatGPT는 승인 대기(Webull).

왜 중요한가

전통 브로커는 “AI는 비서, 실행은 사람”, 크립토 거래소는 “돈을 나눠 맡기고 한도로 묶는다” 쪽으로 간다. 개인 자동매매 관점에서 OKX식 구조의 핵심은 서브 지갑+가드레일이다. MT5에서 EA 전용 계좌·일일 손실 한도를 따로 두는 것과 같은 발상이고, 에이전트 마켓·Builder Program은 “전략을 파는 사람”에게 수익 모델을 준다.

체크포인트

  • AI Bot은 시연 단계: 가격·지역·출시일 모두 미정.
  • 카피트레이딩·시그널 구독은 과거 성과가 미래를 보장하지 않는다. 위임 한도는 잃어도 되는 금액으로.
