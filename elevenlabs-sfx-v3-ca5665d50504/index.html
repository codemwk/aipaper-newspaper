[10/30] AI 콘텐츠: ElevenLabs SFX v3 — ‘환호 → 공 떨어짐 → 야유’를 한 문장으로. 여러 소리가 섞인 장면과 음악·보컬 효과음이 좋아졌다

ElevenLabs가 10/29 효과음 모델 SFX v3를 ElevenCreative와 ElevenAPI에 출시했다. 한 프롬프트에 여러 소리를 적어도 더 많이 반영하고, 음악·보컬이 섞인 효과음이 자연스러워졌으며, 징·차임·호루라기 같은 소리의 지글거림이 줄었다(회사 설명, SFX v2 대비 벤치마크). API 효과음은 0.1~30초, 루프 생성, MP3/48kHz WAV 지원.

분류: AI 콘텐츠

한줄 요약

축구 클립 하나에도 소리는 여러 겹이다. 관중 환호, 공이 떨어지는 소리, 몇 초 뒤 야유. 지금까진 이걸 한 번에 뽑으려면 여러 번 다시 시켜야 했는데, SFX v3는 한 문장에 적은 여러 소리를 더 잘 지킨다(ElevenLabs 블로그).

좋아진 세 가지 (회사 설명)

  • 여러 소리 한 프롬프트 — 적은 소리가 결과에 더 많이 들어간다. 장면의 주 동작을 먼저 쓰고 주변 소리를 덧붙이는 식으로 쓰라고 권한다.
  • 음악·보컬 — 짧은 음악 구절이나 목소리 연기를 생활 소음과 섞은 효과음이 더 그럴듯해졌다.
  • 잡음 감소 — 징의 울림, 차임의 여운, 호루라기의 음이 거칠게 깨지는 현상이 줄었다.

요금은 기존 효과음 과금 체계를 따른다(가격 페이지 기준 API 분당 과금, 앱은 크레딧 차감). v3 전용 가격 변화는 발표되지 않았다.

왜 중요한가

  • 영상 모델들이 오디오까지 같이 만들기 시작했지만(위 Pika H3 Flex 참고), 편집 단계에서 특정 소리만 다시 만드는 수요는 남는다. 효과음 전용 모델은 그 빈칸을 노린다.
  • 숏폼 제작자에게는 무료 효과음 라이브러리를 뒤지는 시간을 문장 한 줄로 바꾸는 도구다.
