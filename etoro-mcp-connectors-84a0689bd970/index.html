AI 트레이딩: eToro MCP 커넥터 — Claude·ChatGPT·Grok에 내 포트폴리오를 붙인다, 실행은 승인 후에만

eToro가 10/8–9 MCP 커넥터를 Claude·ChatGPT·Grok·Grok Bot에 출시. API 키 없이 SSO. 읽기 전용 또는 read-and-act(제안→승인). 입출금은 챗 밖. 리테일 조사 56%가 AI 투자 도구 사용·개방. 일부 관할(미·호·싱 등) 제한 보도.

분류: AI 트레이딩

한줄 요약

브로커 eToro가 Model Context Protocol(MCP) 커넥터로 투자 계좌를 사람들이 이미 쓰는 AI 어시스턴트에 붙였다. CEO 요니 아시아는 “접근 다음 단계는 지능, 통제권은 항상 투자자”라고 했다(FX News Group, 공식 ChatGPT 가이드).

동작 방식

  • 설정: 지원 디렉터리에서 eToro 검색·연결·로그인. 또는 커스텀 커넥터로 MCP 엔드포인트 추가(ChatGPT 가이드는 Developer Mode + https://mcp.public-api.etoro.com).
  • 권한: 읽기 전용(보유·포지션·잔고·성과 질문) 또는 read-and-act(가능한 곳에서 행동을 제안→사용자 승인). 입출금은 eToro 앱에만, 챗에 두지 않는다. 언제든 일시정지·해제.
  • 수요 조사: eToro Retail Investor Beat에서 리테일 56%가 ChatGPT·AI 에이전트로 투자를 고르거나 바꾸는 데 이미 쓰거나 열려 있다고 답했다(회사 인용).

주의

이차 보도는 미국·호주·싱가포르 등 일부 관할에서 아직 쓸 수 없다고 한다. 지역·플랜은 eToro 고지를 따른다.

왜 중요한가

Axi의 MT5↔Claude MCP(10/8)가 프로 트레이더·터미널이라면, eToro는 소셜·리테일 계좌를 소비자 AI 챗에 넣는 쪽이다. “시장이 아니라 내 포트폴리오를 물어보라”는 문장이 핵심 — 에이전트 트레이딩의 UX가 브로커 전용 봇에서 일상 어시스턴트로 이동 중임을 보여 준다.
