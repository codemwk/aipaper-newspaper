[10/24] 디자인/UI·UX: Ideogram Vector 1.0 — 프롬프트나 그림 한 장을 ‘고칠 수 있는 SVG’로. 로고·스티커·굿즈용, API는 장당 $0.10~$0.32

Ideogram이 10/22 첫 벡터 모델 Vector 1.0 공개. 글로 설명하거나 기존 이미지를 넣으면 확대해도 깨지지 않는 SVG를 만들고, 도형 하나하나를 선택·이동·크기 조절·색 변경할 수 있다. 용도는 타이포그래피, 일러스트, 로고·브랜딩, 인쇄·굿즈, 라벨·스티커. API 가격: 텍스트→벡터 저 $0.13·중 $0.16·고 $0.20(레퍼런스 포함 고품질 $0.32), 이미지→벡터 $0.10. fal에서도 제공. 레이어 그룹 묶기는 아직 없음.

분류: 디자인/UI·UX

한줄 요약

지금까지 AI 이미지의 약점은 “예쁜데 못 고친다”였다. 픽셀 그림이라 로고로 쓰려면 누군가 다시 따라 그려야 했다. Ideogram Vector 1.0(10/22)은 처음부터 SVG(벡터)로 결과를 낸다(Ideogram).

무엇이 되나

  • 두 가지 입구: ① 글로 설명 → SVG ② 이미 있는 그림 → SVG로 변환
  • 도형 단위 편집: 벡터 편집기(일러스트레이터, Figma 등)에서 모양 하나를 골라 옮기고, 키우고, 돌리고, 색을 바꿀 수 있다
  • 크기 무관: 작은 라벨부터 큰 포스터까지 가장자리가 선명
  • 브랜드 색 맞추기: 같은 그림을 브랜드 팔레트로 바꿔 끼우기
  • 용도: 타이포그래피·레터링, 일러스트, 로고·브랜딩, 인쇄·굿즈, 라벨·스티커

API는 비동기(생성 ID 받고 나중에 조회·웹훅)이고, 실행 없이 가격만 미리 보는 dry-run 옵션이 있다. fal에서도 같은 가격대로 text-to-vector·image-to-vector를 부를 수 있다(fal). 앱 안에서도 바로 쓸 수 있다.

주의할 점

  • Ideogram 벡터 변환 API 문서에 “도형을 레이어로 묶는 옵션은 아직 없음”이라고 적혀 있다(MODEL 정리). 도형은 고칠 수 있지만 레이어/그룹 구조는 아직 없다. 즉 ‘눈’, ‘글자’ 같은 의미 단위로 묶여 나오진 않는다 — 실무 로고 파일로 쓰려면 정리 작업이 남는다.
  • 생성 로고는 상표 등록·저작권 문제를 따로 검토해야 한다.

왜 중요한가

브랜드 작업에서 AI가 가장 덜 쓰이던 곳이 ‘최종 파일’ 단계다. 시안은 AI로, 납품은 사람이 다시 그리는 구조였다. 벡터가 나오면 시안 → 수정 → 납품의 거리가 확 줄어든다. 반대로 ‘아무나 로고를 뽑는’ 시대가 되면 차별점은 더욱 전략과 체계(아이덴티티 시스템) 쪽으로 이동한다.
