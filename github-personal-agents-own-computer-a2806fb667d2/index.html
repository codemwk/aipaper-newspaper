[11/12] GitHub 이번 주: ‘자기 컴퓨터를 가진 개인 비서 에이전트’를 각자 집에서 돌리는 흐름

11/5–11/11 GitHub AI 에이전트 상위권에 OpenMausBot(+9천 스타, 가상머신 포함), n8n의 nod(실제 웹사이트에서 인보이스 독촉·체험판 해지, 실행 전 확인), kwant(봇 팀을 한 바이너리로 셀프호스팅) 등 ‘개인용 상주 에이전트’ 오픈소스가 몰렸다. 공통 키워드는 셀프호스팅, 원하는 모델, 그리고 ‘행동 전 승인’.

분류: GitHub 트렌드

한줄 요약

이번 주 GitHub의 에이전트 분야는 “코딩 도우미”보다 “내 일을 대신 처리하는 상주 비서”가 눈에 띈다. 상용 서비스(Grok Bot, Claude Duet, OpenAI dots 등)를 내 컴퓨터에서 오픈소스로 돌리겠다는 프로젝트들이다. 아래 수치는 Upstar 주간 랭킹·GitStock 주간 스냅샷 기준.

무엇이 떴나 (쉽게 풀면)

  • OpenMausBot (+약 9천 스타, 총 2.1만): 상용 비서 에이전트의 오픈소스 대안. 핵심은 봇이 쓸 수 있는 가상머신을 함께 준다는 점이다. 에이전트가 내 실제 PC가 아니라 격리된 컴퓨터에서 브라우저·파일을 만진다.
  • nod by n8n (+약 400, 신규): 워크플로 자동화 도구 n8n이 낸 개인 에이전트. “자기 컴퓨터를 가지고 인보이스를 독촉하고, 통화를 준비하고, 실제 웹사이트에서 체험판을 해지한다. 행동 전에 묻는다.” 내 기기에서 내가 고른 모델로 돌아간다.
  • kwant (+약 470, 신규): ‘봇 한 명’이 아니라 봇 팀을 자체 호스팅 바이너리 하나로. 공간(space), 계정 연결, 봇 간 인계(handoff), 승인, 정기 루틴을 갖췄다.
  • learnharness (+3.3천): 어려운 주제를 배우는 데 특화한 에이전트 하네스. 같은 ‘하네스’ 개념이 학습 쪽으로 퍼지는 예.
  • 배경에는 지난주부터 이어진 vercel-labs/agent-desktop(컴퓨터 사용 CLI, 주간 +6.5천)과 휴대폰 조작 pinky·poki(11/11 기사)가 있다.

공통 패턴 세 가지

  • 에이전트에게 별도 컴퓨터를: VM·샌드박스로 내 본체와 분리.
  • 모델은 내가 고른다: 특정 회사 모델에 묶이지 않는 구조.
  • 승인 관문: “asks before it acts”, “approvals”가 기본 기능 목록에 들어간다. 위험한 행동 전에 멈추는 설계가 이제 차별점이 아니라 기본값이다.

왜 중요한가

지난번 저장하신 orca·멀티에이전트 운영, LYIO 태그의 하네스/메신저 워크플로와 같은 줄기다. 다만 이번 흐름은 개발자 도구가 아니라 생활 업무(청구서, 일정, 구독 해지)를 겨냥한다. 1인 스튜디오라면 “반복 행정 업무를 승인 기반 에이전트에 맡기는” 첫 실험 대상으로 볼 만하다.

주의

nod·kwant는 갓 공개돼 스타 수백 개 수준이다. 실제 계정·결제 수단을 연결하기 전에 권한 범위와 로그를 반드시 확인하고, 처음엔 승인 필수 모드로만 돌릴 것.
