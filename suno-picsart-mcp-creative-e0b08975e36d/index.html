[11/23] AI 콘텐츠: 창작 도구가 ‘대화창 안으로’ — Suno MCP 무료 플랜까지 개방, Picsart는 모델 250개를 키 하나·MCP 하나로

음악·이미지·영상 도구가 앱을 여는 대신 ChatGPT·Claude·Cursor 대화창에서 바로 쓰이는 쪽으로 움직인다. Suno는 11/18 Suno MCP를 무료 플랜 포함 모든 요금제에 열었다. 주소 하나를 커스텀 커넥터로 넣으면 노래·커버·연장·매시업, 스템 분리, MIDI 변환을 대화로 시키고 결과는 내 Suno 라이브러리에 쌓인다. Picsart는 11/20 Picsart Platform을 내놨다. 30여 회사의 이미지·영상·음성·텍스트 모델 250개 이상을 하나의 API 키·CLI·MCP 서버로 쓰고, 5달러부터 충전해 생성 건당 낸다.

분류: AI 콘텐츠

한줄 요약

창작 AI의 입구가 바뀌고 있다. 각 회사 앱 → 내가 쓰는 AI 비서의 대화창. 같은 주에 Suno(음악)와 Picsart(이미지·영상·음성)가 그 길을 크게 넓혔다.

Suno MCP: 무료 플랜까지

  • 11/18 Suno는 베타였던 Suno MCP를 모든 요금제(무료 포함)에 열었다(Suno MCP FAQ, Suno MCP).
  • 방법: AI 비서에 https://api.suno.com/mcp를 커스텀 커넥터로 추가하고 Suno 로그인·승인. API 키가 필요 없다.
  • 대화로 할 수 있는 일: 노래 만들기, 커버, 이어 붙이기(extend), 매시업, 스템 분리, MIDI 변환, 효과음, 라이브러리 정리. ChatGPT, Claude, Claude Code, Gemini, Cursor 등에서 쓴다.
  • 만든 곡은 내 Suno 라이브러리에 자동 저장되고, 요금제의 크레딧을 쓴다. 무료 사용자는 하루 크레딧 안에서 쓴다. 11/18 전한 Visuals(아트·루프 영상)는 유료 플랜이 필요하다.

Picsart Platform: 모델 250개, 키 하나

  • 11/20 Picsart가 자사 앱 뒤의 AI를 개발자·기업에 열었다(Business Wire, Picsart 가이드).
  • 30여 회사의 250개 이상 모델(이미지·영상·음성·텍스트)을 하나의 키와 잔액으로 쓴다. 모델을 바꿀 때 코드 대신 모델 id만 바꾼다.
  • 입구는 여러 개다: REST API, TypeScript·Python SDK, CLI, 플레이그라운드, 그리고 MCP 서버(OAuth 로그인, 키 없이 Claude Code·Cursor에 연결).
  • 범위: 최대 8K 이미지, SVG 벡터·투명 배경, 오디오가 붙은 최대 30초·4K 영상, 립싱크·더빙, 90개 이상 언어 음성, 노래·효과음. Picsart 자체 편집 모델(배경 제거 등)도 같은 목록에 있다.
  • 요금: 5달러부터 선충전, 생성 건당 과금, 잔액은 만료되지 않는다. 실행 전 비용을 미리 알려 준다. 대량 고객은 월 청구 계약도 된다.

왜 중요한가

지난번 저장하신 Suno Speech 소식과 이어진다. Suno는 이제 ‘음악 앱’이 아니라 다른 AI가 부르는 음악 엔진이 되려 한다. Picsart도 같은 방향이다. 창작 스튜디오 입장에서 실무 의미는 둘이다.

  • 하나의 작업 흐름: “브랜드 무드 이미지 4장 → 15초 영상 → 배경음악”을 한 대화에서 이어 붙일 수 있다. 앱을 오갈 일이 줄어든다.
  • 비용 관리: 크레딧이 여러 회사에 흩어진다. Suno는 요금제 크레딧, Picsart는 충전식 잔액이다. 에이전트에게 맡길 때는 한 번에 몇 개까지 만들지 상한을 먼저 정해 두는 게 좋다.
