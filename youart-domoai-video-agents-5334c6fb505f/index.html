[11/15] AI 콘텐츠: 영상 에이전트가 ‘편집 프로그램을 직접 만진다’ — YouArt 데스크톱은 After Effects·Premiere를 조작, DomoAI InkoAI는 한 문장에서 숏폼까지 ‘승인받고’ 생성

11/13 영상 에이전트 두 개가 나왔다. YC 출신 YouArt의 데스크톱 앱은 사용자 허락을 받아 After Effects·Premiere Pro·DaVinci Resolve·CapCut·Blender를 직접 조작하고, 슬랙·지메일로 온 클라이언트 피드백을 해당 샷에 붙여 수정한다. 사용자 API 키를 연결하면 가장 싼 제공사로 자동 연결해 준다. DomoAI의 InkoAI Agent는 모델 15개를 오가며 한 문장을 게시 가능한 영상으로 만들되, 생성 전에 무엇을 만들지 보여주고 승인을 받는다.

한줄 요약

AI 영상은 이제 클립 한 개를 뽑는 단계를 지나 제작 과정 전체를 대신 돌리는 단계로 가고 있다. 같은 날(11/13) 나온 두 제품은 방향이 조금 다르다. YouArt는 기존 프로 도구 안으로 들어가고, DomoAI는 대화 하나에 모든 과정을 담는다.

YouArt Desktop — 내 프로젝트 파일과 편집 프로그램을 그대로 쓴다

  • Y Combinator 출신 YouArt가 Mac·PC용 영상 에이전트 앱을 냈다(보도자료).
  • 사용자가 허락하면 After Effects, Premiere Pro, DaVinci Resolve, CapCut, Blender의 메뉴를 찾아 클릭하고 명령을 입력한다. 쓰던 템플릿과 플러그인을 그대로 쓸 수 있다.
  • 클라이언트가 슬랙이나 지메일로 보낸 피드백을 해당 샷·프레임에 붙은 코멘트로 가져와 수정한다. 무엇을 남길지는 사람이 고른다.
  • “우리 브랜드 블루로”, “이 타이틀 1초 더” 같은 말로 하는 편집도 된다. 타임라인 수동 조작은 그대로 남아 있다.
  • 가격 구조가 특이하다. 사용자 API 키(Higgsfield, fal, BytePlus 등)를 연결하면 같은 모델을 가장 싼 제공사로 자동 연결한다. 자체 요금으로는 Seedance 2.5 720p가 초당 0.208달러(연간 Max 플랜은 0.138달러)다. fal보다 56% 싸다는 건 회사 자체 비교다.

DomoAI InkoAI Agent — 한 문장 → 게시용 영상, 단계마다 승인

  • 크리에이터 500만 명이 쓴다는 싱가포르 DomoAI의 새 에이전트다(보도자료).
  • 아이디어 한 줄로 틱톡·쇼츠·릴스용 이미지나 클립을 만든다. 프롬프트 작성, 비율·길이 설정을 에이전트가 맡는다.
  • 숏드라마, 애니메이션, 카툰, 일반 스토리 스킬은 대본 → 캐릭터 → 샷 단계마다 사람의 승인을 받으며 완성 영상까지 간다.
  • GPT Image 2.5, Nano Banana Pro, Seedance 2.5, MiniMax H3 등 이미지·영상 모델 15개를 오간다. 대화 속 결과물을 기억해서 다시 올리지 않고 고칠 수 있다.
  • 핵심 문구는 “무엇을 만들지 보여주고 기다린다”. 크레딧이 사라지기 전에 승인을 받는 구조다.

왜 중요한가

두 제품 모두 “사람이 승인하고, 에이전트가 손을 움직인다”는 구조다. 특히 YouArt처럼 프로 편집 프로그램을 직접 조작하는 방식은 스튜디오에 의미가 크다. 새 툴로 갈아탈 필요 없이 기존 AE 템플릿과 브랜드 에셋 위에서 수정 라운드를 줄일 수 있다. 다만 둘 다 보도자료 단계라 실제 조작 정확도와 비용은 직접 확인이 필요하다.
