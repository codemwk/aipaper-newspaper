[11/4] 디자인: Framer ‘Agent Templates’ — 템플릿이 에이전트용 설명서를 품는다. 스킬·디자인 시스템 페이지·사용 영상이 같이 와서, 새 페이지도 ‘원래 템플릿처럼’

Framer가 11/3 Marketplace에 Agent Templates를 열었다. 각 템플릿에 스킬, 디자인 시스템 페이지, 구성 방식을 보여 주는 짧은 영상이 포함되고, 사용자가 ‘채용 페이지 만들어 줘’라고 하면 Framer 에이전트가 템플릿의 스킬을 따르고 기존 스타일·컴포넌트를 재사용한다. 판매자용 제작 가이드도 공개. 출시 당일 Basis 같은 에이전트 전용 UI 키트가 함께 나왔다.

분류: 디자인/UI·UX

한줄 요약

템플릿을 사면 지금까진 ‘완성된 페이지 몇 장’을 받았다. 이제는 “이 디자인으로 다음 페이지를 어떻게 만들지”에 대한 규칙까지 같이 받는다(Framer 업데이트 11/3).

무엇이 들어 있나

  • 스킬: 이 템플릿에서 새 섹션·페이지를 만들 때 에이전트가 따를 절차와 규칙.
  • 디자인 시스템 페이지: 색·타이포·컴포넌트를 한곳에 모은 페이지. 에이전트는 새로 그리지 않고 이걸 재사용한다.
  • 짧은 영상: 사람이 봐도 구성 방식을 알 수 있게.
  • 결과: 블로그 목록이나 채용 페이지를 새로 요청해도 처음 산 템플릿처럼 보인다. 템플릿 판매자는 가이드를 따라 자기 템플릿을 Agent Template로 제출할 수 있다.

출시 당일 반응

디자이너 Till Janek은 프리빌트 섹션 대신 네이티브 컴포넌트와 완결된 디자인 시스템을 담은 에이전트 전용 UI 키트 ‘Basis’(129달러)를 내놨고, 다른 제작자들도 여러 개를 동시에 올렸다(Design Radar 정리).

왜 중요한가

  • 그동안 저장해 두신 DESIGN.md, Stitch, ‘에이전트가 읽는 디자인 시스템’ 흐름이 마켓플레이스 상품 형태로 들어왔다. 템플릿의 가치가 ‘보기 좋은 첫 화면’에서 ‘에이전트가 일관되게 확장할 수 있는 규칙’으로 옮겨 간다.
  • 템플릿 제작자에겐 새 차별화 포인트다. 같은 외형이라도 스킬과 시스템 페이지가 잘 짜인 템플릿이 에이전트 시대엔 더 오래 쓰인다. 브랜드 스튜디오 입장에선 아이덴티티를 ‘에이전트가 따를 수 있는 형식’으로 납품하는 것이 하나의 산출물이 될 수 있다.

주의

  • 가격 정책(일반 템플릿 대비 추가 비용 여부)은 공지에 없다. 에이전트가 스킬을 얼마나 충실히 지키는지는 템플릿 품질에 크게 좌우된다.
