DeepSeek(10/17): V4.1 Flash를 1017 버전으로 웹·앱·API 동시 교체(모델명 deepseek-flash, 가격 동일: 입력 $0.30/출력 $1.20 per 1M, 비혼잡 시간 반값, 100만 토큰). 자체 강화학습(RLSF)으로 처음부터 프로젝트 만들기 개선, 출력 짧아짐. 자사 표 DeepSWE 74.2→77.0, Terminal-Bench 4.0 31.2→42.3(여전히 Opus 5 51.8 아래). MIT 가중치 HF·ModelScope. Search/Fetch API 각 1,000회당 $0.75, Harness·Claude Code·Codex 경유 호출은 10/31까지 무료.

분류: AI 모델

한줄 요약

DeepSeek가 2026-10-17 V4.1 Flash를 V4.1-Flash-1017로 바꿨다. API 모델 이름(deepseek-flash)도, 호출 방식도, 가격도 그대로다. 같은 돈을 내던 사용자가 아침에 일어나 보니 더 똑똑하고 말이 짧아진 모델을 쓰고 있는 셈이다(The Decoder · AICoder).

무엇이 바뀌었나

  • 학습법: ‘자기 피드백 강화학습(RLSF)’ — 사람 평가자나 별도 보상 모델 대신 모델 스스로의 확신도·자기 비평을 보상으로 쓴다. 목표는 게임·3D 장면처럼 프로젝트를 처음부터 끝까지 만드는 능력.
  • 더 빠르고 짧게: 같은 과제를 더 짧은 출력으로 끝낸다. DeepSeek는 이를 성능과 비용을 동시에 개선한 ‘파레토 개선’이라 불렀다.
  • 점수(회사 발표, 독립 검증 전): DeepSWE v1.1 74.2 → 77.0, Terminal-Bench 4.0 31.2 → 42.3, ProgramBench 20.3 → 29.1. 다만 Terminal-Bench·ProgramBench·HLE에선 여전히 Claude Opus 5보다 낮다(51.8 / 37.0 / 56.3).
  • 비용 그래프가 핵심: DeepSWE 과제 하나에 평균 $0.20 미만(저비용 설정은 약 $0.10로 72%). 이전 버전은 약 $0.50이었다. 경쟁 대형 모델들은 같은 차트에서 과제당 $2~$10 이상(DeepSeek 자체 차트).

가격과 공개 범위

  • API: 입력(캐시 미적중) 100만 토큰당 $0.30, 출력 $1.20, 비혼잡 시간 반값. 컨텍스트 100만, 최대 출력 38.4만 토큰.
  • MIT 라이선스 가중치를 Hugging Face·ModelScope에 공개(FP8, 전문가 층은 FP4).
  • Search·Fetch API 신설: 자사 내부 검색엔진을 외부에 열었다. 각 1,000회당 $0.75. DeepSeek Harness·Claude Code·Codex를 통한 서버 측 호출은 10/31 16:00 UTC(11/1 01:00 KST)까지 무료.

왜 중요한가

에이전트 시대의 비용은 “토큰 단가”가 아니라 “과제 하나 끝내는 데 드는 돈”이다. 모델이 말을 줄이면 같은 단가라도 청구서가 절반이 된다 — DeepSeek는 이 지점을 정확히 공략했다. 또 하나는 검색 API. 에이전트가 웹을 찾아보는 비용은 그동안 별도 검색 업체 몫이었는데, 모델 회사가 직접 싸게 붙이면서 “모델 + 검색” 묶음 경쟁이 시작됐다. 텐센트가 같은 주에 낸 기억 모델 평가에서도 비교 대상으로 DeepSeek V4.1 Flash가 쓰였을 만큼, 이 모델은 이미 오픈소스 에이전트의 기본 두뇌 자리를 노리고 있다. 단, 모든 점수는 회사 발표이며 실제 코드 품질은 써 봐야 안다.
