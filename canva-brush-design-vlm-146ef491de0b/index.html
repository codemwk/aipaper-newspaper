[10/30] 디자인: Canva Brush — 디자인을 ‘보고’ 고치는 자체 비전-언어 모델. 이전 에이전트보다 최대 69% 빠르고 수정 1건당 비용 46%↓

Canva가 10/29 자체 연구조직(Canva Research, 160명)이 만든 디자인 편집용 비전-언어 모델 Brush를 공개했다. 레이아웃·레이어·스타일 구조를 읽고, 카피 한 줄부터 덱 전체까지 고친다. 결과물은 모두 일반 Canva 요소처럼 편집 가능. 이전 디자인 에이전트 대비 일반 편집 최대 69% 빠르고 건당 비용 46% 낮다(회사 발표). 우선 Canva Pro 대상, 일주일 전 공개한 이미지 모델 Craft와 짝.

분류: 디자인/UI·UX

한줄 요약

일주일 전 이미지 생성 모델 Craft를 낸 Canva가, 이번엔 만든 디자인을 고치는 모델 Brush를 내놨다. Craft가 그림을 만들면 Brush가 그 주변 디자인을 다듬는 분업이다(Canva 뉴스룸).

무엇이 되나

  • 디자인을 열거나 Canva AI에 첨부한 뒤, 드롭다운에서 ‘Brush’를 고르고 말로 지시한다.
  • 예시: 색 구성·날씨·분위기 바꾸기, 여러 장짜리 덱의 제목을 한 번에 고치기, 발표 슬라이드를 인스타그램 이미지로 바꾸기(The AI Economy).
  • 결과는 이미지 한 장이 아니라 텍스트·이미지·색·레이아웃이 모두 따로 편집되는 Canva 디자인 그대로다.
  • 작업 중 캔버스를 다시 보고 결과를 스스로 보정하는 루프가 있다.

숫자와 범위 (회사 발표)

항목내용
속도이전 디자인 에이전트 대비 일반 편집 최대 69% 빠름
비용편집 1건당 46% 저렴
대상우선 Canva Pro 구독자(베타), 확대 예정
예정브랜드 키트 지원, 첨부 파일 참조, 이미지가 많은 레이아웃 개선

왜 중요한가

  • 비용 46%↓는 가격 정책의 예고편. Canva는 이 효율로 “수억 명에게 더 저렴하게” 주겠다고 했다. 외부 모델을 빌려 쓰면 사용자가 늘수록 원가가 늘지만, 자체 모델은 그 구조를 바꾼다.
  • Figma와 같은 날, 같은 결론. 두 회사 모두 ‘편집’은 자체 소형 모델로 가져왔다. 디자인 툴의 경쟁력이 “어떤 모델을 붙였나”에서 “우리 파일 구조를 얼마나 잘 아는 모델인가”로 옮겨 가는 중이다.
