[10/17] AI 모델: Elorian ‘Glimpse’ — 이미지를 한 번 보고 마는 대신 ‘다시 들여다보는’ 모델, 생각하다 말고 확대·프레임 추출·코드로 측정, 입력 $0.60/출력 $3

제품 출시 전 $5,500만 시드(기업가치 $3억)를 받은 Elorian(CEO 앤드루 다이, 전 DeepMind)이 10/16 첫 모델 Glimpse를 리서치 프리뷰로 공개. 추론 중 이미지 일부를 잘라 보고, 영상 프레임을 뽑고, 코드를 돌려 재는 ‘시각 스크래치 공간’. 수백 장 GPU로 학습한 비교적 작은 모델. API 100만 토큰당 입력 $0.60·출력 $3, 채팅은 대기자. 과학 차트·짧은 영상 캡션에서 우위 주장(자체 평가).

분류: AI 모델

한줄 요약

지금의 멀티모달 모델은 대개 이미지를 한 번 보고 토큰으로 바꾼 뒤, 기억에 의존해 글로 추론한다. 사진을 보고 나서 눈 감고 설명하는 셈이다. 팔로알토 스타트업 Elorian의 첫 모델 Glimpse는 생각하는 도중에 원본으로 계속 돌아간다(TechCrunch).

핵심 사실

  • 방식 — ‘시각 스크래치 공간’: 추론 중간에 이미지의 특정 영역을 잘라 확대하고, 영상에서 특정 프레임을 뽑고, 코드를 실행해 길이·크기를 재거나 비교한다. 휴대폰 사진을 두 손가락으로 늘려 다시 확인하는 동작과 비슷하다.
  • 새로운 발상은 아니다: OpenAI가 2025년 o 시리즈 추론에 자르기·확대를 넣은 바 있다. Elorian의 주장은 “모델 전체를 그 방식 중심으로, 싸게 만들었다”는 것 — 소규모 팀이 GPU 수백 장으로 학습했고, 비교 대상 프런티어 모델보다 상당히 작다고.
  • 가격: 100만 토큰당 입력 $0.60, 출력 $3. TechCrunch 표현으로 Sonnet·Sol 같은 중급보다 싸고 Haiku·Luna 같은 경량보다 비싸다.
  • 성능 주장(자체 평가): 과학 차트 추론과 짧은 영상 캡션에서 GPT-6 Astra를 앞서고, 다른 시각 추론 과제에서도 경쟁력. 외부 검증은 아직 없다.
  • 공개 형태: 리서치 프리뷰. API는 열렸고 채팅 인터페이스는 대기자 전용.
  • 회사: 6개월 전 스텔스 해제, Striker·Menlo·Altimeter 공동 주도 $5,500만 시드(기업가치 $3억), NVIDIA와 Google 수석과학자 Jeff Dean 참여. CEO는 전 Google DeepMind 연구자 Andrew Dai.

왜 중요한가

다이 CEO의 출발점은 보드게임이었다 — 끝난 판을 찍어 “누가 이기고 있냐” 물었더니 프런티어 모델이 답을 못 했다. “사람은 글자 없는 이케아 설명서로 가구를 조립하는데, 왜 AI는 못 하나.” 첫 고객으로 노리는 곳은 영상이 쌓여 있는 회사(로봇, 과학 연구소, 미디어, 크리에이티브)다. 콘텐츠·디자인 쪽에서 보면 의미가 크다: 레퍼런스 보드나 UI 스크린샷을 “대충 본” 모델이 아니라 픽셀을 다시 재 보는 모델이 있어야 브랜드 가이드 검수, 레이아웃 QA 같은 일이 자동화된다. 회사는 내년 “모든 시각 추론 테스트 1위”, 장기적으론 장면을 이해해 로봇을 직접 제어하는 단계까지 가겠다고 한다.
