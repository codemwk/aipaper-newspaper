[11/9] GitHub 트렌드: Hallmark v2 — ‘AI가 만든 티’를 브라우저에서 린트하는 디자인 스킬, 한 주 +6.9k 별

Together AI의 Nutlope가 만든 Hallmark는 Claude Code·Codex·Cursor·OpenCode용 디자인 스킬이다. v2는 50개 테마, 실제 브라우저 8개 폭에서 ‘AI 티’ 패턴을 검사하는 sloplint, 새 눈으로 보는 리뷰어 단계를 갖췄다. 지난주 약 +6.9k 별, 누적 약 5만 별.

분류: GitHub 트렌드

한줄 요약

‘AI 슬롭’ 디자인(모든 제목 위의 작은 라벨, 한 단어만 색칠한 헤드라인, 페이지 끝마다 뉴스레터 가입)을 금지 목록과 린터로 막는 스킬이다. Together AI에서 만든 오픈소스(MIT)로, 한 주 사이 약 6.9k 별이 늘어 누적 약 5만 별이다(Githot 주간 스냅샷, README).

무엇을 하나

  • 50개 테마: 테마는 ‘재료’(종이·타이포·색·표면·컴포넌트)이지 레이아웃 틀이 아니다. 같은 테마로도 프롬프트마다 다른 페이지가 나온다. 빌드마다 후보 3개를 제시한다.
  • 용도에서 출발: 예약 페이지는 예약을, 쇼핑몰은 판매를 하게 하고 페이지가 그 행동으로 끝난다.
  • 게이트 3단계: Floor(대비·포커스·모션 축소·지어낸 사실·깨진 모바일은 절대 출고 금지) → Reflex(모델의 습관적 기본값, 이유를 기록하면 예외 가능) → Finish(마감 디테일).
  • 검증: sloplint가 실제 브라우저에서 8개 화면 폭으로 검사하고, 새 맥락의 리뷰어가 마지막 판단을 한다. 히어로를 먼저 따로 만들어 냉정하게 본 뒤 나머지를 짓는다.
  • redesign / audit: 기존 페이지의 콘텐츠·링크·폼 연결을 유지한 채 리디자인하거나 점검만 한다. 사진은 위키미디어 공개 라이선스 755장에서 골라 출처를 표기한다(스톡 사이트 미사용).

왜 중요한가

디자인 스킬 경쟁이 ‘취향 프롬프트’에서 ‘검사 가능한 규칙’으로 옮겨가고 있다. 지난주 다룬 디자인 스킬 분류(5레인)에서 ‘검증’ 레인이 실제로 제품이 된 셈이다. impeccable(약 10.6만 별)과 비슷한 문제를 풀지만, Hallmark는 지어낸 사실 금지·실제 렌더 검사를 하드 플로어로 둔 점이 다르다. 저장해 두신 impeccable·UI UX Pro Max 후속 소식이다.

주의

‘AI 티가 안 난다’는 주관적 목표라 객관 비교 수치는 없다. 설치는 npx skills add nutlope/hallmark -g, 브라우저 검사는 puppeteer-core와 Chrome이 필요하다. 별 수는 스냅샷 시점 값이다.
