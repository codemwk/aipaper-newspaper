## 한줄 요약
[HKUDS/nanobot](https://github.com/HKUDS/nanobot)은 “거대 에이전시 스택”이 아니라 **읽기 쉬운 코어의 개인용 셀프호스트 에이전트**를 표방한다. WebUI·터미널·메신저로 붙고, 도구·장기 기억·MCP·멀티에이전트 위임·스케줄·OpenAI 호환 API를 한곳에 모은다.

## 무엇이 인기 포인트인가
README 축: 파일·셸·브라우저·웹 fetch·크론·이미지·서브에이전트, 세션·장기 기억, 모델 라우팅. **MIT**, Python. 조회 시점 GitHub 스타는 **약 4.8만**대(변동). v0.3 “Agency” 계열 릴리스와 가이드드 셋업·인라인 서브에이전트·컴포저 모델 전환이 최근 업데이트로 소개된다. OpenClaw 계열 생태계와 태그로도 연결된다.

## 왜 중요한가
슈퍼파워·ECC급 초대형 하네스와 달리, nanobot은 **한 사람이 자기 박스에서 돌리는 개인 비서** 포지션이다. Grok Bot·AiPaper처럼 “루틴 + 도구 + 기억”을 로컬에 두고 싶은 사용자에게 참고 아키텍처다. 스타 수는 신호일 뿐, 보안·권한·샌드박스 성숙도는 직접 검증해야 한다.

## 기억할 것
- 포지션: 개인·셀프호스트·초경량 코어.
- 체크: MCP 연결 범위, 셸/브라우저 승인, 메모리 저장 위치.
