## 한줄 요약
[PyPI obsidian-wiki 2026.9.1](https://pypi.org/project/obsidian-wiki/2026.9.1/) / [Ar9av/obsidian-wiki](https://github.com/Ar9av/obsidian-wiki)는 Karpathy식 **LLM Wiki**(한 번 컴파일하고 갱신)를 **에이전트 스킬 팩**으로 포장한 오픈소스다. Claude Code·Cursor·Codex·Gemini CLI 등이 같은 `.skills/`를 읽는다.

## 지금 뭐가 뜨나
- 설치: `pip install obsidian-wiki` → `obsidian-wiki setup --vault ~/brain`. 또는 에이전트에게 리포 URL만 주고 “set up my wiki”.
- 일상: `/wiki-ingest`, `/wiki-update`, `/wiki-capture`, `/wiki-query`, `/wiki-lint`, `/wiki-dedup` 등 **39 스킬**. 답에 `[[wikilink]]` 인용.
- 차별점: 채팅 로그를 쌓지 않고 **기존 페이지에 병합·모순 플래그**. 매니페스트로 **변경분만** 재처리. 클레임에 extracted / inferred / ambiguous 태그.
- 배포: docs의 Docker 경로로 vault를 **HTTP + Streamable MCP**(`/mcp`) 메모리 서비스로 노출. `memory_search`·`memory_read`·`memory_write` 등. `WIKI_API_KEY`로 보호.
- 저자 측 소규모 측정(38페이지 vault): 구조 질의에서 plain agent 대비 벽시계 ~4×, 정답률 향상 — **n이 작아 참고치**.

## 왜 중요한가
어제 다룬 librarian-mcp·pgvector 셀프호스트가 “검색 인프라”라면, 오늘은 **마크다운 위키를 컴파일하는 운영체제**다. 퍼스널 AI 저널·세컨드브레인을 만들 때 “RAG 다시 돌리기” vs “위키로 굳히기” 중 후자 실험이 GitHub에서 계속 수렴 중이다.
