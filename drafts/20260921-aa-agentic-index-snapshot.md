## 한줄 요약
[Artificial Analysis Agentic Index](https://benchlm.ai/benchmarks/aaagenticindex)(집계 페이지, Last updated ~2026-09-10 표기)는 여러 에이전트 벤치를 묶어 **모델 하나의 ‘에이전트 점수’**로 보여 준다. 오늘 읽은 표 기준 **Claude Fable 5.1 58.0%**가 1위다.

이어 Kimi K3, GPT-5.6 Sol, Qwen3.8 Max Preview 등

## 보드 읽기 팁
- Arena Agent는 **사람 선호·도구 성공** 중심, AA Index는 **교차 벤치 집계** — Astra가 Arena 2위여도 Index 6위일 수 있다.
- 점수는 퍼센트·갱신일이 바뀌니 **스크린샷 날짜를 남길 것**. 매출·가격은 이 표에 없음.

## 왜 중요한가
모델 고를 때 단일 왕관을 믿지 말고 **Agent Arena + AA Index + 실비(캐시·툴콜)**를 겹쳐 보는 습관이 비개발자에게도 안전하다.
