## 한줄 요약
Splice가 “샘플 가게”에서 **작업실 자체**로 들어왔다. Create는 Splice 카탈로그·악기·이펙트가 내장된 DAW로, 맥 베타는 무료, **내보내기는 Create Pro 월 9.99달러**(도입가). Windows·웹판은 예정([Splice 블로그](https://splice.com/blog/introducing-splice-create/)).

## AI가 하는 일
- **Rheo**: 음성·텍스트 명령으로 DAW를 실제 조작하는 에이전트. 소리 찾기, 드럼 그룹, 이펙트, 신스 패치 설계, MIDI 멜로디·편곡, 믹스 정리까지. MusicRadar 테스트에선 “보컬 루프를 16분음표로 자르고 하나 걸러 뒤집기”를 한 번에 해냈다([MusicRadar](https://www.musicradar.com/music-tech/splices-new-ai-daw-feels-like-a-cheat-code-for-music-production-but-it-left-us-with-one-big-question)).
- **두 모드**: *Assist*는 대신 실행, *Point*는 화면에 빛나는 커서를 띄워 “사이드체인 컴프레션은 여기 → 여기” 식으로 단계별로 가르친다. 초보에게 “만들어 주는 AI”와 “가르치는 AI”를 고르게 한 설계다.
- **샘플 흐름**: 빈 클립에 “여성 R&B 보컬”을 치면 키·템포에 맞춰 바로 깔린다. 샘플은 MP3 미리듣기로 마음껏 쓰고, **내보낼 때 라이선스**해야 한다(안 하면 무음으로 바운스). AI Variations는 원본과 같은 라이선스이고 원작자에게 보상이 간다.

## 돈 버는 구조
DAW는 무료로 깔고, 돈은 **세 갈래**에서 난다 — Create Pro 구독(내보내기), 샘플 라이선스, 그리고 **Rheo 유닛**(1,000유닛당 10달러, 무료 100유닛). Rheo 사용량이 별도 과금이라 “에이전트 작업 = 크레딧”이 음악 툴에도 들어왔다.

## 왜 중요한가
Suno식 “오디오를 통째로 생성”이 아니라 **라이선스된 재료 + 에이전트 조작**으로 간 점이 핵심이다. Logic Pro 13 AI 어시스턴트, FL Studio Gopher, MCP로 Ableton을 붙이는 흐름과 같은 줄기에서, 샘플 권리를 가진 회사가 DAW까지 묶은 첫 사례다.

## 주의
Rheo는 자체·외부 LLM을 섞어 쓰며 “전부 라이선스 데이터”라고 하지만 범위는 불분명하다. 서드파티 플러그인은 조작하지 못한다. “쉬운 모드가 내 소리를 만드는 과정을 빼앗나”는 리뷰어도 던진 질문이다.
