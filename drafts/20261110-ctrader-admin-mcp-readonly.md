## 한줄 요약
에이전트 트레이딩의 반대편, **브로커 백오피스**에도 MCP가 들어왔다. cTrader 개발사 Spotware는 **cTrader 10.4**에 **Admin MCP 서버**를 추가했다([FX News Group, 11/9](https://fxnewsgroup.com/forex-news/platforms/ctrader-admin-mcp-server-allows-brokers-to-connect-chatgpt-claude-to-platform-data/)).

## 무엇을 묻나
- **민원 조사**: “고객 주문이 왜 거절됐나?” → 주문 이력·연결 체결·계정 권한·심볼 설정을 모아 사건 순서를 재구성. 체결가 분쟁이면 주문 타임라인·가격 설정·과거 시세와 비교. 원인이 확정되지 않으면 “무엇이 불확실하고 무엇을 더 확인해야 하는지”를 말하게 돼 있다.
- **리스크·노출**: 지금 가장 큰 노출을 가진 심볼과 그 계좌들, A-book/B-book을 분리해 매수·매도·순포지션을 한 통화로 환산.
- **계좌 점검**: 스톱아웃에 가장 가까운 계좌(증거금 수준 vs 그룹 설정), 기간별 실현 손익 비교. 자동 감시나 예측은 하지 않는다.
- **자금 조사**: 스왑·수수료·보너스·입출금 기록을 설정과 대조, 데이터로 확인 안 되는 건 ‘추가 확인 필요’로 표시.
- **설정 검토**: 심볼 사양·세션·한도·마크업을 브로커 요구 사항과 비교한 체크리스트, 틱·바 데이터의 공백·이상 플래그.

## 권한 설계
- 서버는 **cTrader Admin 안에서 로컬로** 실행된다.
- **인증된 매니저 세션**이 필요하고, 그 매니저 권한 범위 밖 데이터는 못 본다.
- **모든 작업이 읽기 전용**: 거래 실행, 계좌 설정·구성 변경 불가. 결과는 운영 결정 전에 사람이 검증해야 한다고 명시.

## 왜 중요한가
지금까지 이 지면의 트레이딩 MCP 이야기는 “AI가 주문을 넣어도 되나”였다. cTrader는 반대로 **읽기 전용 + 권한 상속 + 불확실성 명시**라는 보수적 기본값으로 시작했다. 개인 트레이더에게도 의미가 있다. 브로커가 체결 분쟁·스톱아웃을 AI로 더 빨리 조사하게 되면, 내 에이전트가 낸 이상한 주문도 더 빨리 추적된다. 앞서 다룬 cTrader Agent Connect(트레이더 쪽)와 짝을 이루는 업데이트다.

## 주의
기능 설명은 Spotware 발표 기준이다. 정확도나 실제 브로커 도입 사례는 아직 공개되지 않았다.
