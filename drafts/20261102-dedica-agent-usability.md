## 한줄 요약
에이전트가 사람 대신 가격을 비교하고 가입까지 하는 시대, 사이트의 ‘사용자’에 **소프트웨어**가 추가됐다. Dedica는 그 사용자 기준의 사용성 테스트를 판다([getdedica.com](https://getdedica.com/), [Design Agent 주간 정리](https://design-agent.dev/blog/2026-10-29-design-news-digest-october-29-2026/), [Product Hunt](https://www.producthunt.com/products/dedica)).

## 무엇을 검사하나
| 영역(샘플 리포트 배점) | 예시 실패 |
|---|---|
| 발견 Discovery(20) | llms.txt·마크다운 버전 없음 |
| 접근 Access(30) | 가입 페이지가 에이전트에 **403 봇 확인 페이지** |
| 사용성 Usability(40) | 가격표가 **JS 실행 전엔 빈 화면** |
| 결제 Payments(10) | 에이전트가 끝낼 수 없는 결제 흐름 |

- 결과는 점수 + “먼저 고칠 것” 순 정렬(예상 점수 상승폭 표시). OpenAPI 명세 없음, MCP 서버 없음도 감점 항목.
- **수정 키트**: 이슈마다 지시서 파일 하나(무엇을 바꾸고, 어떻게 확인하는지). Claude Code·Codex·Cursor·Copilot에 바로 붙여 넣는 형식. **사이트당 1회 30달러**, 점수는 무료·가입 없음.

## 디자이너에게 무엇이 바뀌나
- 지금까지 ‘좋은 가격 페이지’는 눈에 잘 띄는 카드였다. 에이전트 기준으론 **페이지 텍스트에 플랜·가격이 있고, 봇 확인 없이 가입 폼이 열리는** 페이지다. 시각 디자인과 기계 가독성이 같은 화면의 두 레이어가 된다.
- 지난주 디자인 업계 흐름(Figma 생성 플러그인 버전 기록, Webflow 에이전트 존재 표시)과 묶으면, 디자인 시스템·UI 상태가 **사람용 + 기계용 인터페이스**로 동시에 설계되는 중이다.

## 주의
- “기업 사이트의 6%만 준비됨”, “준비된 곳이 1.9배 더 추천됨”은 회사 홈페이지 주장으로 방법론 미공개. 125개 항목의 세부·렌더링 방식도 공개 범위가 제한적이다.
- 봇 차단을 푸는 건 보안 트레이드오프다. Dedica도 “검증된 에이전트만 통과, 속도 제한은 유지”를 권한다.
