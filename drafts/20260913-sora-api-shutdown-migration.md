## 한줄 요약
OpenAI 공식 디프리케이션 표에 따르면 **Videos API와 sora-2 / sora-2-pro(및 스냅샷)** 가 **2026년 9월 24일** 제거된다. 소비자 Sora 앱·웹은 이미 **2026-04-26**에 종료됐다. 오늘(9/13) 기준으로 **열흘 남짓**이다.

## 무엇이 깨지나
- Videos API 엔드포인트 자체가 내려가면, 모델 별칭을 바꿔도 **호출이 실패**한다.
- 대체 모델을 OpenAI 표에 **공식 후속으로 적어 두지 않았다** — 이주는 각자 Veo·Kling·Seedance·PixVerse·Runway 등으로.
- 생성물·프롬프트 히스토리 등 계정 데이터가 컷오프 후 **복구 없이 삭제**된다는 안내가 이주 가이드·보도에 반복된다. **지금 다운받을 것.**

## 현실적인 대체 축 (역할만)
| 방향 | 누가 | 언제 고르나 |
|------|------|-------------|
| Veo 3.1 | Google | 시네마틱·네이티브 오디오·엔터프라이즈 API |
| Kling 3.0 | Kuaishou | 더 긴 단일/멀티샷 내러티브 |
| Seedance 2.0 | ByteDance | 텍스트·이미지·오디오·영상 참조를 한 요청에 |
| PixVerse V6 | PixVerse | 카메라 컨트롤·짧은 클립 비용 민감 |
| Runway Gen-4.5 | Runway | 편집·모션 툴과 한 파이프라인 |

초당 단가는 해상도·오디오·벤더에 따라 크게 갈리니, **가격만으로 고르지 말 것.** Sora용으로 다듬은 프롬프트는 다른 모델에서 그대로 안 나오는 경우가 많다.

## 왜 중요한가
AI 콘텐츠 생성에서 “한 API에 올인”한 파이프라인이 **제품 종료**로 한꺼번에 멈춘 사례다. 자동화(n8n/Zapier/자체 스크립트)에 Sora 호출이 숨어 있으면 9/24에 **조용히 깨진다.** 수동으로 웹 UI만 쓰던 사람은 API 재구축보다 **현재 모델이 돌아가는 브라우저 툴**로 옮기는 편이 빠를 수 있다.

## 기억할 것
- 1순위: **자산 백업**. 2순위: 호출 지점 인벤토리. 3순위: 소수 프롬프트로 A/B. 4순위: 다운스트림(해상도·오디오·썸네일) 점검.
- 공식 기준점은 OpenAI deprecations의 Sora/Videos API 항목; 실무 이주 안내는 여러 창작 툴 블로그가 정리 중(예: Miraflow 2026-09-12 가이드).
