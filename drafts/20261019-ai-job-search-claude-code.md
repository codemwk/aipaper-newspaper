## 한줄 요약
이번 주 GitHub 주간 트렌딩 1위는 여전히 앱을 역공학하는 **rea**(+24만★, 10/07 소개)였지만, 10위 안에서 가장 ‘사람 냄새’ 나는 프로젝트는 따로 있었다. **ai-job-search** — “당신의 컴퓨터에서 도는 구직 활동”([GitStock 주간 스냅샷, 10/18](https://gitstock.org/trending/weekly/2026-10-18)).

## 누가, 왜 만들었나
만든 사람은 지구물리학자 **Mads Lorentzen**. 2025년 말 자리가 없어지자 자기 구직을 위해 이 틀을 만들었다. 결과는 **맞춤 지원서 69통, 1차 면접 20회, 계약 1건** — 2026년 6월 AI 엔지니어로 취업했다. 고용주들에게 이 도구를 쓴다고 솔직히 말했더니 오히려 기술 대화의 계기가 됐다고 한다([README](https://github.com/MadsLorentzen/ai-job-search)).

## 무엇을 하나 (명령어 = 업무 단계)
- **/setup**: CV PDF, 링크드인 내보내기, 졸업장, 과거 지원서를 넣은 폴더를 읽거나, CV를 붙여넣거나, 인터뷰로 프로필을 만든다.
- **/scrape → /rank**: 여러 구인 사이트를 검색해 중복을 지우고 적합도로 정렬한다. 결과가 많으면 병렬 에이전트가 공고마다 다섯 기준으로 **일괄 채점**하고, 결격 조건은 바로 탈락, 마감 임박은 표시, 내려간 공고는 만료 처리.
- **/apply**: 적합도 평가 → 맞춤 CV·자기소개서 초안(LaTeX) → **두 번째 에이전트가 비평** → 수정 → 최종본. 채용 시스템(ATS)이 PDF를 제대로 읽는지도 검사한다.
- **/interview**: 실제 제출한 CV·공고·이전 라운드 피드백으로 단계별 준비 자료를 만들고, 예상 질문을 내 경험 사례에 연결, 모의 면접까지. 빈 경험은 **지어내지 않고** 솔직한 연결 답변을 만든다.
- **/outcome**: 결과 기록, 조용해진 지원 건(기본 10일)에 보낼 짧은 후속 메일 **초안만** 작성(절대 자동 발송 안 함, 건당 최대 2회).
- **/gmail-sync·/notion-sync·/html-report**: 메일에서 면접 초대·불합격 신호를 찾아 **승인받은 뒤** 기록, Notion에 읽기 전용 현황판, 오프라인 HTML 대시보드.
- **/upskill**: 내 프로필과 지원 공고 사이의 기술 격차 히트맵과 학습 계획.

## 눈여겨볼 설계
- **공고는 신뢰할 수 없는 입력**: 공고 안에 숨은 지시를 따르지 않고 본문 링크도 열지 않는다. 다만 README는 “에이전트 방어는 지시 수준이지 샌드박스가 아니다”라며 보내기 전에 직접 훑어보라고 적었다.
- **개인정보 경고**: 공개 저장소의 포크는 항상 공개라, 이름·연락처·희망 연봉이 들어가는 개인용은 **비공개 저장소**로 쓰라고 강조한다.
- **현지화**: 포털 검색은 덴마크 사이트(Jobindex 등)용이지만 핵심 흐름은 언어·국가 무관이고, `/add-portal`이 내 나라 구인 사이트용 검색 스킬을 만들어 준다. Claude Code는 유료 플랜이나 API 크레딧이 필요하고, Codex 등 다른 에이전트용 포크도 있다.

## 왜 중요한가
이 프로젝트가 인기를 끄는 이유는 기술보다 **구조**에 있다. ‘작성 에이전트 + 검토 에이전트’, ‘보내기 전 사람 승인’, ‘기록은 내 파일에’ — 이번 주 Anthropic 고용 보고서가 말한 “에이전트를 관리하는 일”을 개인 업무에 그대로 옮긴 모범 사례다. 구직이 아니라 **제안서·견적·클라이언트 응대** 같은 반복 업무에도 같은 틀을 쓸 수 있다.
