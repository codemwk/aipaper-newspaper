## 한줄 요약
[fal 블로그](https://blog.fal.ai/introducing-h3-max-by-fal/)(2026-08-27)와 [모델 페이지](https://fal.ai/minimax-h3-max)의 **H3 Max**는 MiniMax H3를 fal이 포스트트레이닝·추론 최적화한 비디오 모델이다. 메시지는 **퀄리티를 유지한 채 실시간보다 빠른 생성**.

## 지금 뭐가 뜨나
- **속도 주장**: 5초 영상을 대략 **3초 이내**에 뽑는 구성(블로그). Turbo는 동일 계열에서 더 공격적 처리량.
- **리스트 가격(페이지 표기, 변동 가능)**: H3 Max **480p $0.05/s · 768p $0.08/s · 1080p $0.16/s**. **Turbo는 각 해상도 절반**. 초당·해상도 티어 과금, 최소 구독 없음(페이지 설명).
- **포지션**: Boreal이 **광고 충실도 + 센트/초(finished second)** 를 판다면, H3 Max는 fal 마켓에서 **속도 + 해상도 티어**를 판다. 같은 “초당”이라도 제품 약속이 다르다.
- **주의**: 론칭 할인·무료 일일 쿼터·환율·프로모는 시점에 따라 바뀐다. **청구 전 모델 페이지 재확인**.

## 왜 중요한가
비디오 API 시장이 “한 모델 왕관”이 아니라 **원가 투명도(Boreal) vs 속도·해상도 SKU(H3 Max)** 로 쪼개지고 있다. 대량 숏폼 예산을 짤 때 보드를 목적별로 나눠 읽어야 한다.
