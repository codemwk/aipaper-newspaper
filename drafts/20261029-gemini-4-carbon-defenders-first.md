## 한줄 요약
구글의 새 최상위 모델 Carbon은 성능보다 **출시 순서**가 뉴스다. 코딩·보안 능력이 너무 강해져서, **먼저 방어하는 쪽(보안팀)에 주고 공격자보다 앞서게 한 뒤** 일반 공개한다([Google 발표](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)).

## 무엇이 달라졌나
| 영역 | 내용 (구글 발표) |
|---|---|
| 취약점 찾기 | SEC-bench Pro **88.2%** — 실제 소프트웨어 속 복잡한 결함을 스스로 발견 |
| 위험 검증 | ExploitGym **54.8%** — 실제로 악용 가능한지 확인해 고칠 순서를 정함 |
| 근본 패치 | CWE-bench **71.0%** — 찾은 문제를 동작하는 수정 코드로 |
| 안전한 코드 | 내부 기준 Argon 대비 **2배 이상** 성공률 |
| 긴 작업 | 내부 팀에서 **며칠씩** 막다른 길을 돌아 가며 대형 코드베이스 버그를 추적·수정 |

- 크롬 팀은 “다른 연구소의 대형 모델보다 **고품질 패치 생성에서 10배 이상** 낫다”고 보고했다고 한다(구글 측 인용).

## ‘행동’ 지표를 앞세운 이유
- **꼼수 감소**: Terminal-Bench 4.0에서 부정 성공 0.0%, 시도 0.4%. 실제 코딩 환경의 심각한 오정렬 경고는 약 80% 감소.
- **정직함**: 근거 없는 주장 **약 2배 감소**. 증거가 부족하면 지어내지 않고, 결과물에 한계를 적거나 “남은 필요 작업 목록”을 남긴다.
- **애매하면 묻기**: 추측해서 밀어붙이는 대신 출처를 찾고 **불일치를 먼저 사용자에게 보여 준다.**
- **선 넘지 않기**: 과잉 행동 26%↓, 덜 해 주기 29%↓.
- **프롬프트 인젝션**: Gray Swan 간접 인젝션 평가에서 공격 성공률 **0.0%**(Argon 0.7%).

## 언제, 얼마에
- 이번 주부터 **일부 사이버 방어 조직**에, 이후 Fairwind 프로그램으로 신뢰 파트너를 단계적으로 확대. 미국 정부의 자발적 출시 전 시험 절차에도 참여 중.
- 개발자·기업·일반 사용자 공개 시점은 미정(“가능한 한 빨리”).
- 도입가 입력 100만 토큰당 **$2**, 출력 **$10**(Argon과 동일), 캐시 입력은 95% 할인. 도입 기간 후 **$4/$20**.

## 왜 중요한가
- 이달 Anthropic의 사이버 인증 단계, 이번 Carbon까지 — **최상위 모델은 ‘누구에게 먼저 줄지’를 고르는 제품**이 됐다. 일반 사용자가 쓰는 시점은 점점 늦어질 수 있다.
- 에이전트를 오래 돌리는 사람에게는 점수보다 **“모르면 지어내지 않고 멈추는가”**가 실제 체감 품질이다. 공개되면 그 부분부터 확인해 볼 만하다.
