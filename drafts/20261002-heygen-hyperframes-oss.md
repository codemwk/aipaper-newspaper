## 한줄 요약
HeyGen의 [공식 $200M ARR 블로그](https://www.heygen.com/blog/heygen-surpasses-200m-arr)는 최근 출시물로 **HyperFrames**(Apache 2.0, 에이전틱 비디오 프레임워크)를 적었고 “첫 달 21,600 GitHub stars”를 언급했다. 저장소 [`heygen-com/hyperframes`](https://github.com/heygen-com/hyperframes) 설명은 “Write HTML. Render video. Built for agents.”이며, 2026-10-02 `gh` 확인 **stargazerCount 55,282**, 라이선스 Apache-2.0.

## 제품으로 보면
- 포지션: 바이브 코딩이 소프트웨어를 말하게 했듯, HyperFrames는 **에이전트가 비디오를 조립**하고 사용자는 디렉션(공식 서사).
- SaaS와 분리: 클라우드 아바타 결제(HeyGen credits)와 OSS 렌더 파이프라인이 한 브랜드 아래 **이중 레일**.
- 에이전트 스킬: Claude Code·Cursor 등용 가이드/스킬 문서가 저장소에 존재(커뮤니티·문서 트리).

## 왜 중요한가
콘텐츠 생성의 경쟁이 “더 예쁜 모델”만이 아니라 **에이전트가 호출하는 오픈 비디오 런타임**으로 이동한다. 자체 미디어 파이프라인을 가진 팀에게는 API 락인 전에 만져 볼 레이어다.
