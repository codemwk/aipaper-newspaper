## 한줄 요약
LongCat-2.5는 “**긴 일을 끝까지 하는**” 에이전트를 목표로 한 멀티모달 모델이다. 메이퇀은 학습 전 과정을 **중국산 AI 가속기**에서 돌렸다고 강조한다([LongCat 블로그](https://longcat.ai/blog/longcat-2.5/), [메이퇀 뉴스](https://www.meituan.com/news/NN261102280001343)).

## 무엇이 새로운가 (코드 없이)
- **그림을 글자처럼**: 이미지를 여러 단계의 ‘시각 단어’(이산 토큰)로 바꿔, 텍스트와 같은 형식으로 한 뼈대에 넣는다. 그래서 별도 비전 인코더 없이 웹페이지·3D 전시 페이지 같은 **시각 코딩**을 한다.
- **실패를 숙제로**: 실제 에이전트가 실패한 궤적을 모아, 통과 여부를 자동 검증할 수 있는 학습 과제로 바꿔 계속 추가한다. GitHub PR·이슈에서 과제와 환경을 합성하고, 테스트로 검증.
- **편법 차단**: 과제 환경에서 인터넷을 끄고 git 기록·캐시를 지운 뒤, LLM 심판이 궤적을 감사해 ‘점수만 따는’ 꼼수를 걸러낸다.
- **국산 칩 최적화**: 장기 문맥 학습, 4비트 가중치·활성값(W4A4) 추론. W8A8 대비 프리필 처리량 +43.3%, 디코드 +42.8%(회사 수치).

## 성능은 어디쯤 (회사 자체 표)
| 벤치마크 | LongCat-2.5 | 참고 |
|---|---|---|
| Terminal Bench v2.1 | 88.4 | Opus-5 89.1, GPT-5.6-Sol 88.8 |
| BrowseComp | 91.9 | Opus-5 90.8 |
| MCP Atlas | 83.1 | Opus-5 85.8 |
| JobBench | 65.4 | Opus-5 66.7 |

메이퇀 발표는 “다수 벤치마크에서 Claude-Opus-4.8과 Opus-5 사이, 일부는 Opus-5 이상”이다. 다른 모델 점수는 공개 자료 인용, 일부는 자체 측정이라 **독립 검증 전 참고치**로 보자.

## 왜 중요한가
- 순위보다 흥미로운 건 **제조법**이다. ‘실패 궤적 → 검증 가능한 과제’ 루프와 ‘보상 해킹 감사’는 에이전트 모델을 만드는 쪽이 공통으로 겪는 문제에 대한 구체적 답이다.
- 수출 규제 속에서 **1조급 모델을 국산 칩으로 학습·4비트 서빙**까지 했다는 건 중국 AI 인프라의 자립 신호. 사용은 longcat.ai 웹과 동시 공개된 API로 가능하다(가중치 공개는 이번 발표에 없음).
