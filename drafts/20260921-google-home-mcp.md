## 한줄 요약
[TechCrunch](https://techcrunch.com/2026/09/16/your-ai-agents-can-now-control-your-google-home-devices/)·[9to5Google](https://9to5google.com/2026/09/16/google-home-mcp/)(2026-09-16)에 따르면 Google은 **Home MCP**로 Nest 카메라·초인종·온도조절기·Matter 전구 등 Home 생태계를 **임의 MCP 에이전트**(Claude, OpenClaw, Hermes, Antigravity 등)에 연다.

## 지금 뭐가 뜨나
- 할 수 있는 예: 카메라 요약·교차 분석, 기기 상태 히스토리 질의, 음성으로 완료 알림, **맞춤 대시보드 생성**.
- 출시 범위: **미국 영어**, **Google Home Premium Advanced** 구독자부터 수주간 롤아웃. 월 **$20** / 연 **$200** 티어로 보도.
- 설정: Google Cloud 프로젝트 → Home MCP 구성 → 에이전트에 MCP 설정 전달 → 로그인·권한. Developer Center 가이드.
- 가드: 속도 제한, **문 잠금 해제 등 민감 동작 금지**. 자동화 관리는 아직 제한. Google도 “에이전트에 따라 예상 밖 동작” 경고.

## 왜 중요한가
트레이딩·코딩 MCP 다음으로 **물리 공간 컨텍스트**가 표준 프로토콜로 열린다. “에이전트 OS” 실험에서 Home은 센서·이벤트 피드다. 다만 구독 게이트·지역 제한이 있어 **일반화 시점는 미정**.
