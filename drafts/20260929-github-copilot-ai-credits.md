## 한줄 요약
[GitHub Blog(2026-04-27)](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)과 [공식 Plans 문서](https://docs.github.com/en/copilot/get-started/plans) 기준, Copilot은 **2026-06-01**부터 premium request 대신 **GitHub AI Credits**(토큰·모델 API 단가 기반)로 옮겼다. **좌석 가격은 유지**하되, 에이전트·채팅·리뷰가 크레딧을 먹고, **코드 완료(completions)·Next Edit는 유료 플랜에서 무제한·크레딧 미소모**다.

## 숫자 (공식)
- **Individual**: Pro **$10/월**, Pro+ **$39/월**, Max **$100/월** — 각각 base(+flex) AI 크레딧 패키지(문서 표: Pro total 1,500 / Pro+ 7,000 / Max 20,000 등).
- **Org**: Business **$19/좌석·월 → 1,900 credits/유저**, Enterprise **$39/좌석·월 → 3,900**. 조직 **풀링** + 엔터프라이즈·코스트센터·유저 **예산 캡**.
- **초과**: 조직 문서 기준 추가 사용 **$0.01 per AI credit**(퍼블릭 레이트). 전환 초기(6–8월) Business/Enterprise에 프로모 크레딧($30/$70)을 준 바 있음.

## 왜 중요한가
“시트가 싸다”는 착시가 깨지고, **에이전트 분당 비용**이 FinOps 대상이 됐다. Cursor·Claude Code와 같은 **좌석+사용량** 전쟁터의 MS/GitHub 공식 답이다.
