## 한줄 요약
[Lattice Prompt](https://www.latticesemi.com/en/About/Newsroom/PressReleases/2026/Lattice-Advances-FPGA-Design-with-New-Leadership-AI-Driven-Development-Tool-Lattice-Prompt)는 **FPGA 풀 디자인 플로우**를 자연어·에이전트 IDE에 붙이는 MCP 툴이다. UI 픽셀이 아니라 **하드웨어 설계 도구**를 “디자인 에이전트” 자리로 끌어올린 사례다.

## 핵심
- 발표: 2026-09-16. **무료 다운로드**, 최신 Lattice Radiant와 호환.
- MCP로 Claude Code / Cursor / VS Code 등 **선택 LLM·IDE**에 연결, 백그라운드에서 Radiant 오케스트레이션.
- 자연어로 시뮬레이션·합성·맵·배치배선·타이밍·비트스트림, 리포트·문서 자동 생성.
- 문서·데이터시트·지식베이스에 그라운딩. 대상: 중소형 Lattice FPGA.
- 생산성 “**10X or more**”는 **회사 주장** — 독립 벤치마크는 별도.

## 왜 중요한가
디자인/UI 슬롯을 “픽셀 툴”에만 가두지 않는다. MCP가 **전문 CAD 플로우**까지 표준 포트가 되면, 에이전트는 웹 UI뿐 아니라 실리콘 설계 데스크도 조율한다.
