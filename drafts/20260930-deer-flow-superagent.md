## 한줄 요약
[bytedance/deer-flow](https://github.com/bytedance/deer-flow)는 분~시간 단위 작업을 노리는 **오픈소스 슈퍼에이전트 하니스**다. README 기준 **DeerFlow 2.0은 ground-up rewrite**(v1 Deep Research는 `1.x` 브랜치). 서브에이전트·메모리·샌드박스·확장 skills·메시지 게이트웨이로 “연구·코딩·창작”을 오케스트레이션한다. 사이트 데모: [deerflow.tech](https://deerflow.tech).

## 평문으로 보면
- **한 줄 에이전트**: 문서화된 one-line setup으로 로컬/클라우드 모델을 붙인다(BytePlus Coding Plan·Doubao/DeepSeek/Kimi 등 권장 고지).
- **관측**: 자매 프로젝트 LLM Space로 스텝 검사·실패 리플레이·벤치.
- **라이선스**: MIT. 트렌딩에 에이전트 인프라 레포가 잔뜩인 흐름의 대표 주자.

## 왜 중요한가
“모델 하나”가 아니라 **하니스(샌드박스·메모리·스킬)**가 오픈소스 경쟁 축이 됐다. 개인 OS·자동화 루프를 짤 때 참고할 **조립식 뼈대**다. 프로덕션 전제 조건(권한·비용·감사)은 레포가 대신 보장하지 않는다.
