## 한줄 요약
[Spotware](https://www.spotware.com/news/ctrader-launches-official-mcp-servers/)는 **cTrader AI Agent Connect**를 공식 발표했다. Remote·Local **두 MCP 서버**와 Skills 라이브러리로, 에이전트가 cTrader에서 분석·차트·거래 작업을 직접 수행한다.

## 무엇이 돌아가는가
- **Remote MCP**: cTrader Web 설정에서 토큰 복사 → 에이전트에 붙여넣기. 계정·주문·포지션·시세 분석 중심.
- **Local MCP**: Windows cTrader. 계정·거래 + 마켓 분석 + **워크스페이스(차트) 제어**까지 더 넓다.
- **Skills**: 트레이더가 프롬프트를 처음부터 짜지 않도록 재사용 워크플로 묶음. Help Centre에 라이브러리 안내.
- 호환 예: Claude Code, ChatGPT Codex, Cursor, Gemini CLI 등 MCP 클라이언트.
- Spotware 표현: FX/CFD에서 **첫 내장형 AI 에이전트 솔루션**. CEO Ilia Iarovitcyn은 “질문 답변을 넘어 분석·체결에 참여하는 단계”라고 설명.

## 왜 중요한가
MT5 Build 6180이 테스터 QA에 머무는 동안, cTrader는 **주문·차트 조작까지 MCP로 연다**. 같은 “에이전틱 브로커” 키워드라도 플랫폼마다 가드레일이 다르다. MT5·ProreX 사용자는 경쟁 스택의 실행 경계를 비교할 때 이 문서를 기준점으로 두면 된다.
