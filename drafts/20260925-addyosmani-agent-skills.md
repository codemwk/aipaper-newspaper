## 한줄 요약
[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)는 **프로덕션급 엔지니어링 스킬팩**이다. 아이디어→스펙→구현→검증→리뷰→배포를 슬래시 커맨드로 고정한다(~98.9k★).

## 커맨드 맵
| 단계 | 명령 | 원칙 |
| --- | --- | --- |
| 정의 | `/spec` | 코드 전에 스펙 |
| 계획 | `/plan` | 작은 원자 태스크 |
| 구현 | `/build` | 한 슬라이스씩 (`/build auto` = 계획 승인 후 연속 실행) |
| 증명 | `/test` | 테스트가 증거 |
| 기준 | `/constraints` | 한 번 정하고 전역 강제 |
| 리뷰 | `/review` | 코드 건강 |
| 성능 | `/webperf` | 측정 후 최적화 |
| 단순화 | `/code-simplify` | 명료 > 영리 |
| 출하 | `/ship` | 빠른 출하가 더 안전 |

컨텍스트에 따라 API 설계·프론트엔드 UI 스킬 등이 **자동 활성화**된다고 README가 설명한다.

## 왜 중요한가
스킬 붐의 한쪽 끝은 도메인 특화(보안 감사), 다른 끝은 **보편 엔지니어링 규율**이다. 에이전트에게 “시니어처럼 일하게” 만드는 OS 레이어 — 퍼스널 코딩 에이전트·대시보드 개발 루틴에 바로 이식 가능.
