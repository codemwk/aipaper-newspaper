## 한줄 요약
OpenAI의 최대 후원자인 Microsoft가 **자기 손으로 만든 초대형 모델**의 첫 관문을 넘었다. 2026-10-15 Microsoft AI(MAI)는 **MAI-Base-2**의 사전학습을 마쳤다고 발표했다 — 총 **2.8조 파라미터**, 토큰마다 일하는 건 **800억**인 MoE(전문가 혼합) 구조다([Microsoft AI](https://microsoft.ai/news/frontier-pre-training-at-microsoft-ai/)).

## 숫자로 보는 MAI-Base-2
- **구조**: 모든 층에 MoE. MAI-Base-1(6월)보다 크고 더 성기다.
- **데이터**: 총 **50조 토큰** 학습 혼합, 고유 토큰은 Base-1 대비 약 36% 증가. **비전 데이터가 18%**(고유 4.5조 토큰) — 별도 이미지 인코더 없이 처음부터 그림과 글을 같이 배운 ‘네이티브 비전’. 지식 기준 시점 2026년 3월.
- **연산**: GB200 GPU **1만 6천 장으로 38일**(8~9월). 평균 MFU(이론 성능 대비 실효율) 21%, 실제 학습이 진행된 시간 비율 89%.
- **성능(회사 측정)**: 코드·STEM·수학·질의응답 사내 비공개 평가에서 시험한 모든 공개 가중치 모델보다 좋은 점수. 가장 강한 공개 기반 모델 **DeepSeek-V4-Pro-Base와 같은 수준에 도달하는 데 필요한 연산이 4.2~12.3배 적다**고 추정했다.

## ‘증류 없음’을 강조한 이유
MAI는 학습 데이터가 **다른 모델 출력을 베끼는 ‘증류’ 없이** 자체 수집·처리한 ‘유기적 데이터’라고 거듭 밝혔다(웹 크롤러는 robots.txt 준수). 이 출처 관리 덕분에 **가중치를 신뢰할 수 있는 파트너에게 Azure Foundry로 라이선스**할 수 있다는 논리다. 최근 업계에서 ‘남의 모델 증류’가 법적·윤리적 쟁점이 된 상황을 겨냥한 차별화다.

## 지금 쓸 수 있나? — 아니다
MAI-Base-2는 아직 **후속 학습(post-training) 중**이다. API도, 가중치도, 출시일도 없다. 사전학습만 끝난 ‘기반 모델’은 대화·도구 사용 능력을 따로 가르쳐야 제품이 된다. MAI는 이미 **MAI-Base-3** 준비에 들어갔다고 했다.

## 왜 중요한가
① **공급자 다변화**: Copilot·Office에 들어가는 두뇌를 OpenAI에만 기대지 않겠다는 신호가 구체적 숫자로 나왔다. ② **‘효율’ 경쟁**: 비교 기준이 중국 DeepSeek라는 점이 상징적이다 — 미·중 모두 “같은 성능을 몇 배 적은 연산으로”가 승부처가 됐다. ③ **기업용 가중치 라이선스**: API로 빌려 쓰는 것과 별개로, 데이터 출처가 깨끗한 가중치를 자기 인프라에 들이고 싶은 기업 수요를 노린다. 다만 모든 비교는 Microsoft 자체 평가이고, 실제 실력은 후속 학습을 거친 제품이 나와야 판가름 난다.
