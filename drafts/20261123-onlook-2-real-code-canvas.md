## 한줄 요약
디자이너가 Figma에서 그린 화면을 개발자가 다시 만드는 대신, **처음부터 실제 코드 위에서 디자인하자**는 도구다. **Onlook 2.0**이 11/19 오픈소스로 다시 나왔고, 같은 날 Hacker News 런칭도 했다([Onlook 공지](https://onlook.substack.com/p/the-brand-new-onlook-is-here), [GitHub v2.0.2](https://github.com/onlook-dev/onlook/releases/tag/v2.0.2)).

## 무엇이 되나
- **진짜 앱이 캔버스에**: GitHub 저장소나 로컬 폴더를 열면 Onlook이 개발 서버를 띄운다. 각 프레임은 **내 앱을 실제로 돌리는 브라우저**다. 실제 데이터로 보이고, ‘미리보기’로 눌러 볼 수 있다.
- **아이디어를 한꺼번에**: “제품의 모든 흐름”, “이 컴포넌트의 모든 상태”, “이 화면 10가지 버전”을 시키면 캔버스에 나란히 뜬다. 요소 하나를 골라 “변형 쇼케이스를 만들어”라고 하면 된다. 만든 사람의 말로는 “코드 위에서 크리에이티브 디렉팅하는 느낌”이다.
- **반응형 확인**: 데스크톱·태블릿·모바일 프레임을 나란히 본다.
- **안전한 복사본**: 작업은 원본 폴더가 아닌 **별도 작업 복사본(git worktree)**에서 하고, 결과는 **일반 PR**이 된다. 엔지니어에게 리뷰를 받거나 그냥 버리면 된다.
- **아티팩트**: 저장소 밖에 사는 가벼운 HTML 스케치. 화면 일부를 ‘찍어’ 참고 자료로 쓰거나, HTML·PNG·JPEG·PDF로 내보내 동료에게 보낸다.

## 돈과 AI
- **AI 모델을 팔지 않는다.** 사용자가 이미 낸 **Claude Code나 ChatGPT(Codex) 구독**으로 에이전트가 코드를 고친다. Onlook 서버가 나와 코드 사이에 끼지 않는다.
- 데스크톱 앱 **무료**, 편집기 **Apache 2.0**. 지금은 **맥 전용**(애플 실리콘·인텔), 윈도우는 준비 중이다. 나중에 팀용 유료 클라우드를 낼 계획이지만 “내 컴퓨터에서 할 수 있는 건 계속 무료”라고 했다.
- 1.0은 React+Tailwind 프로젝트에서만 됐고, 큰 코드베이스에서 느렸다. 코딩 에이전트가 어떤 코드든 읽게 되면서 **에이전트 중심으로 다시 만들었다.** 웹 버전, Storybook 버전도 시도했다가 접었다고 솔직히 적었다.

## 왜 중요한가
지난번 저장하신 **Meta Astryx**(에이전트가 읽는 오픈 디자인 시스템)와 이어진다. Onlook 2.0의 데스크톱 앱 UI 자체가 **Astryx로 만들어졌다.** Astryx는 이번 주 GitHub 주간 트렌딩에도 다시 올랐다(+3,967★). 오늘 실린 배민 CLAYDesign과 같은 흐름이다. **디자인의 최종 산출물이 ‘그림’에서 ‘실제로 돌아가는 코드’로 옮겨 가고 있다.** 웹사이트·제품 UI를 다루는 스튜디오라면, 시안 단계부터 클라이언트에게 “눌러지는 진짜 화면 10개”를 보여 주는 방식이 현실적인 비용으로 가능해졌다.
