## 한줄 요약
2026-09-22, Anthropic이 [Claude Opus 5.5](https://www.anthropic.com/claude-opus-5-5)를 내고 약 한 시간 뒤 OpenAI가 **GPT-6 Sol·Luna**를 내놓으며 API 가격이 한 단계 내려갔다. “누가 더 똑똑한가”보다 **에이전트 시간당 비용**이 바로 움직이는 날이었다.

|------|-------------------------|------|
| GPT-6 Luna | $0.10 / $0.50 | 초저가 고볼륨 |

- **Anthropic 공식**: 기본 설정에서 Opus 5 대비 전형 워크로드 **약 40% 저렴**, 출력 **30%+ 빠름**. Fable 5.1급 성능에 Opus 계열 소통·토큰 효율 개선. Sonnet/Haiku 5.5는 “수주 내”.
- **Simon Willison**(2026-09-22): GPT-6가 GPT-5.6 동급 대비 **대략 반값**. Codex·Claude Code 기본 모델을 Sol·Opus 5.5로 교체했다고 기록([블로그](https://simonwillison.net/2026/Sep/22/opus-and-sol-and-luna/)).
