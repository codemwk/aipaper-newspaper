## 한줄 요약
[OpenClaw 2026.9.5 릴리즈 노트](https://docs.openclaw.ai/releases/2026.9.5)는 개인 에이전트 런타임을 **“한 명의 챗봇”에서 “역할 팀”**으로 옮기는 UI·설치 개선이 핵심이다. (대량 PR 롤업 릴리즈.)

## 지금 뭐가 뜨나
- **Specialist team**: Control UI에서 코디네이터·리서처·라이터·리뷰어 프리셋. 생성 전 **제안 승인**. `openclaw agents list`로 복구.
- **Atomic Updates**: 다음 버전을 검증한 뒤 전환. 공식 플러그인은 동의 단순화, 미검증 플러그인은 기존 동의.
- 일상: 게이트웨이 재시작 없이 플러그인 설치, 대화 공유, 미팅/통화용 **GPT Live**, 브라우저 페이지와 병행 작업.
- **Conversation archiving**: 오래된 대화를 압축 보관(기본 off, 30일 등 설정). DB 스키마 업그레이드 있어 **백업 후 업데이트**.
- 생태계: Home MCP·mt5-trading-mcp README 등에서 OpenClaw 등록 예시가 자주 등장 — “MCP 클라이언트 기본값” 후보.

## 왜 중요한가
에이전트 뉴스의 무게중심이 모델 점수에서 **운영 하네스**(팀·업데이트·보관·권한)로 이동 중이다. 퍼스널 AI 저널·대시보드 OS를 만들 때도 같은 층이다.
