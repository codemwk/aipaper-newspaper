## 한줄 요약
지난번 저장하신 OpenMontage(에이전트용 영상 스튜디오)와 이어지는 소식이다. Clayzo는 모션 디자인을 **에이전트가 읽을 수 있는 텍스트**로 바꿔, “40번째 프레임 이징만 천천히”가 한 줄 수정이 되게 하려 한다([Product Hunt 요약](https://www.hunted.space/product/clayzo), [Product Hunt](https://www.producthunt.com/products/clayzo)).

## 어떻게 일하나 (코드 없이)
1. 프로젝트에 Clayzo를 설치하고 로그인하면, 에이전트에게 **스킬 2개**가 생긴다: 애니메이션 작성용, 미리보기·내보내기용.
2. 에이전트가 Clayzo 형식으로 애니메이션을 쓴다 — 도형, 글자, 키프레임, 스프링, 커스텀 효과/셰이더, 카메라 이동, 오디오, **호버·누르기·드래그 같은 인터랙션 상태**까지.
3. CLI로 **특정 프레임을 즉시 렌더해 에이전트가 직접 보고** 어색한 부분을 스스로 고친다.
4. 결과는 애니메이션+에셋이 묶인 **.clayzo 파일 하나**(영상보다 최대 ~40배 작음). 웹·iOS·Mac 앱에선 WebGL/Swift 플레이어로 실시간 재생, 필요하면 MP4·GIF·WebM으로.

## 디자이너에게 무엇이 바뀌나
- 모션이 영상 파일이 아니라 **살아 있는 UI 자산**이 된다. 같은 파일이 랜딩 페이지 인터랙션이자 출시 영상이 된다.
- “코드로 영상 만들기”는 Remotion, Anthropic의 Claude Motion(Team·Enterprise 전용 베타)도 하는 일이다. Clayzo의 차별점은 **무료 + 내 에이전트 그대로 + 프레임 단위 자기 검토**다.
- 지난주 Rive CLI 1.8이 ‘에이전트가 고치고 사람이 검토하는’ 구조를 내세운 것과 같은 방향. 모션 디자인 도구들이 **에이전트를 1순위 사용자**로 다시 설계 중이다.

## 아직 답이 없는 질문 (댓글에서)

- 여러 작품에서 **캐릭터·스타일을 고정**하는 방법은?
