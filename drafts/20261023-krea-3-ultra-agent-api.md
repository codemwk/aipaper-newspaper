## 한줄 요약
이미지 툴 **Krea**가 자체 모델 **Krea 3**를 베타에서 정식으로 올리고, API에 **‘Ultra’ 생각 모드**를 붙였다. 한 번 그리고 끝이 아니라 **후보를 여러 장 만들고 → 프롬프트와 참조 이미지에 비춰 스스로 검토하고 → 가장 나은 1장을 2K로** 돌려준다([Krea 변경 로그, 10/20](https://www.krea.ai/docs/changelog)).

## Ultra 모드 요점
- 사용법: Krea 3 요청에 `thinking_mode`를 `ultra`로.
- 조건: **Max 요금제 이상**, **참조 이미지 최소 1장**.
- 시간: 수 분 걸릴 수 있어 웹훅이나 긴 대기 시간 권장.
- 가격: 생성 1회당 **$0.20 추가**. (Krea 3 API 기본 가격은 1K 이미지 $0.03부터 — 10/15 공지)
- 다른 모드: 일상 편집용 `fast`, 복잡한 다단계 편집용 `high`. 예전 이름 `instant`/`medium`은 **오늘(10/23) 종료**되니 API 사용자는 확인 필요.

## 같은 주에 붙은 것들
- **Agent API**: 내 앱에서 HTTP로 Krea 에이전트 세션을 시작·대기·후속 지시. 백그라운드로 돌기 때문에 요구사항을 프롬프트에 다 담아야 하고, 비용·권한 확인은 자동 승인된다(비용은 API 잔액이 아니라 워크스페이스 컴퓨트 단위에서 차감). 같은 기능을 Krea MCP로도 쓸 수 있다.
- **데스크톱 앱 조작**: Photoshop에 이어 **Blender** 같은 앱도 에이전트가 다룬다. 3D 생성 결과도 에이전트 사이드바에서 열린다.
- **기억**: 에이전트가 내 **다른 세션 대화를 찾아 읽고** 맥락·파일을 재사용.
- **영상**: FLUX 3 Max로 5~20초, 오디오 포함 클립(720p/1080p).
- **비용 미리 보기**: 10/19부터 MCP 생성 도구에 `preflight: true`를 주면 실행 없이 견적과 잔액만 확인.

## 왜 중요한가
이미지 생성의 다음 경쟁은 “한 장의 품질”이 아니라 **“생성-검토-선택을 누가 대신 해 주느냐”** 다. Ultra는 그 검토 루프를 모델 안으로 넣었고, Agent API·Blender 조작은 Krea를 ‘이미지 사이트’에서 **크리에이티브 작업을 대행하는 에이전트**로 바꾸려는 움직임이다. 클라이언트 작업이라면 ‘수 분 + $0.20’을 시안 단계가 아니라 **최종 컷**에만 쓰는 식의 배분이 합리적이다.
