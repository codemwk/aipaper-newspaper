## 한줄 요약
[Runway](https://runway.com/news/company-news/runway-davinci-resolve)가 **DaVinci Resolve Studio** 안으로 들어왔다. 클립을 내보내 브라우저에 올렸다가 다시 가져오던 왕복을 줄이고, 플레이헤드 위에서 생성·리스타일한 뒤 타임라인에 바로 올린다.

## 핵심
- **발표**: 2026-09-23. 플러그인 **무료** 다운로드(macOS·Windows). **Resolve Studio 19+** 필요.
- **워크플로**: 패널에서 프롬프트 → 피드에서 완료 확인 → Media Pool·타임라인 import.
- **Edit Studio**: 플레이헤드 또는 인/아웃 구간. **Aleph 2.0**으로 앵커/키프레임(최대 5) 리스타일, **원본과 같은 길이**.
- **결제**: Runway 계정 로그인, 워크스페이스·크레딧·생성 비용 사전 표시. **유료 플랜 크레딧** 사용.
