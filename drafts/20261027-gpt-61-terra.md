## 한줄 요약
‘가장 똑똑한 모델’이 아니라 **‘매일 많이 돌릴 모델’**이 업그레이드됐다. 송장 읽고 회계 프로그램에 입력하기, 도면 해석, 양식 채우기, 영상 편집 같은 **반복 업무용**으로, 값은 내리고 컴퓨터 조작 능력은 올렸다([OpenAI 발표](https://openai.com/index/introducing-gpt-6-1-terra)).

## 무엇이 달라졌나 (모두 OpenAI 자체 측정)
- **컴퓨터 사용**: ‘Agents’ Last Exam’(건축 도면을 3D 모델로 바꾸기, 애니메이션을 컷별로 검토해 타임코드 로그 만들기 같은 전문 업무)에서 중간 추론 기준 GPT-5.6 Terra보다 **15%p 높고 비용은 약 3분의 1**. 토큰당 가격이 10분의 1인데 **GPT-6 Astra와 비슷한 점수**.
- **속도**: GPT-6 Astra·GPT-6.1 Sol보다 작업 완료가 **3배 이상 빠르다**.
- **사실 정확도**: 오류를 유도하는 질문 모음에서 저추론 오류율 **53.6% → 16.7%**, 최대 추론 **4.3%**.
- **코딩**: Terminal-Bench 4.0 최대 추론 **50.3%**(GPT-5.6 Terra 21.5%). 다만 OpenAI도 “가장 복잡한 코딩은 Sol·Astra가 낫다”고 적었다.
- **보안 등급**: 자체 위험 기준(Preparedness Framework)에서 사이버 보안 ‘Critical’ 기준에 해당 → Astra와 같은 보호장치 적용.

## 가격과 사양 ([모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-terra))
| 항목 | 값 |
|---|---|
| 입력 / 캐시 입력 / 출력 | $1 / $0.05 / $5 (100만 토큰당) |
| 긴 프롬프트 | 입력 27.2만 토큰 초과 시 요청 전체에 입력 2배·출력 1.5배 |
| 배치·Flex | 50% 할인 / Fast 모드 2배 |
| 문맥 | 105만 토큰(입력 최대 92.2만), 출력 최대 12.8만 |
| 입출력 | 텍스트·이미지 입력 → 텍스트 출력 (음성·영상 미지원) |
| 지식 기준일 | 2026-06-01 |
| 지원 도구 | computer_use, MCP, skills, hosted_shell, web_search 등 (도구 호출은 Responses API 필요) |

- 같은 날 **Amazon Bedrock**에 정식 출시, ChatGPT Work·Codex도 Bedrock 경유로 이 모델을 쓰게 설정할 수 있다([AWS](https://aws.amazon.com/about-aws/whats-new/2026/10/openai-gpt-6-1-terra-on-amazon-bedrock/)).

## 왜 중요한가
- **에이전트 비용의 ‘기본값’이 내려간다.** 에이전트는 한 작업에 모델을 수십 번 부른다. 이번 주 AI 비즈니스 Nevis 사례처럼 “정확도 1%p보다 원가 25배가 더 중요하다”는 회사들에겐, 상위 모델급 컴퓨터 조작을 반값에 주는 중간급 모델이 실제 배치 대상이다.
- **ChatGPT 구독자에겐 ‘같은 한도로 더 많은 일’.** OpenAI는 같은 사용량 한도로 GPT-5.6 Terra보다 더 많은 작업을, Sol·Astra보다는 훨씬 많은 작업을 처리한다고 했다.
- **주의**: 비교 수치는 전부 OpenAI가 고른 평가다. Claude Opus 5.5 대비 “작업당 비용 약 9배 낮다”는 주장도 회사 계산이다. 내 업무(예: 송장·차트 캡처 읽기)로 먼저 작게 시험해 보는 게 맞다.
