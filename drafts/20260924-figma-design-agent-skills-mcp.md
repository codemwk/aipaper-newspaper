## 한줄 요약
[Figma Design Agent](https://www.figma.com/blog/agent-custom-tools-context-skills/)는 캔버스 위에 사는 디자인 에이전트다. 프롬프트로 시작하되, **Skills·첨부·MCP·생성형 플러그인/셰이더**로 “우리 팀 방식”을 심는다.

## 무엇이 새로워졌나
- **생성형 플러그인**: PropsKit으로 네이티브처럼 보이는 재사용 툴. 로컬 플러그인 개발 환경 없이도 에이전트에게 툴을 만들게 할 수 있다.
- **셰이더**: WebGPU 기반 effect/fill. Tools 탭에 클래식 플러그인·Weave·위젯과 함께 배치.
- **컨텍스트**: 인터뷰/카피/데이터 파일 첨부, 다른 Figma 파일 링크 참조, 웹 검색, **MCP 커넥터**(GitHub·Atlassian·Slack 등)로 티켓·데이터를 끌어온다.
- **Skills**: 반복 프롬프트를 슬래시 커맨드로 저장·팀 공유. 협업자 기본 공개 히스토리.

## 요금·좌석
Professional / Organization / Enterprise의 **Full seat** 오픈 베타. Collab·Dev·View는 드래프트에서. **베타 기간 에이전트 사용은 무료**. 플러그인/셰이더 **사용**은 전 플랜 무료, **에이전트로 만드는 것**은 GA 이후 AI 크레딧.

## 왜 중요한가
어제 UI UX Pro Max가 “에이전트 스킬로 디자인 지능”이었다면, 오늘은 **디자인 툴 자체가 에이전트+스킬+MCP 런타임**이 되는 신호다. 퍼스널 OS·대시보드 UI를 에이전트에 맡길 때 기준이 “화면이 나온다”에서 “우리 시스템·토큰을 안다”로 올라간다.
