## 한줄 요약
디자인 파일은 이제 사람만 열지 않는다. **코딩 에이전트가 Figma MCP 서버로 시안을 읽고 만든다.** Figma가 11/17 그 문을 관리하는 기능을 냈다. **허용한 외부 앱만 연결되게 하는 승인 목록**이다([Figma 릴리스 노트](https://www.figma.com/release-notes/)).

## 무엇이 바뀌나
- **승인 목록**: 관리자가 팀이 쓸 수 있는 **OAuth 앱**(Figma 계정으로 로그인해 권한을 받는 외부 앱)을 정한다. 여기엔 **Cursor, Claude Code 같은 MCP 클라이언트**가 포함된다.
- **요청 심사**: 팀원이 새 앱을 쓰고 싶으면 요청을 보내고, 관리자는 관리 콘솔의 새 **Extensions 탭**에서 검토·승인하고 승인된 앱을 관리한다.
- **대상**: Organization·Enterprise 요금제. 며칠에 걸쳐 순차 배포된다.

## 최근 Figma 흐름 속에서
- 11/12: **Figma 에이전트 정식 출시**, 3D 변형 공개 베타. 3D 레이어는 Dev Mode에서 CSS로 복사되고, 코딩 에이전트도 MCP로 3D 디자인을 읽고 만든다.
- 11/3: 연결된 GitHub 저장소를 Figma로 **복제하는 기능이 기본 켜짐**(관리자가 저장소별로 끌 수 있음).
- 즉 디자인 ↔ 코드 사이의 문이 계속 넓어지고 있고, 이번 기능은 그 문에 **경비실**을 둔 셈이다.

## 왜 중요한가
에이전트에게 Figma를 열어 주면 편하지만, **어떤 앱이 디자인 시스템과 미공개 시안에 접근하는지** 아무도 모르는 상태가 되기 쉽다. 큰 조직부터 승인제로 가는 건 자연스러운 수순이다. 1인·소규모 스튜디오라면 이 기능 대상은 아니지만, 원칙은 같다. **연결해 둔 AI 앱 목록을 가끔 점검하고, 안 쓰는 연결은 끊는 습관**이다. 클라이언트 작업 파일이라면 더욱 그렇다.
