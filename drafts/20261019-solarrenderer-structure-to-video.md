## 한줄 요약
게임 엔진이나 AI 에이전트는 이미 장면의 **배치·움직임·카메라**를 꽤 잘 만든다. 부족한 건 그걸 **진짜처럼 보이는 영상으로 칠하는 단계**다. 싱가포르국립대(NUS) 연구진의 **SolarRenderer**는 정확히 그 단계만 맡는다. 슬로건부터 “The agent builds it. We render it.”이다([프로젝트 페이지](https://enderfga.cn/SolarRenderer/)).

## 어떻게 작동하나 (코드 없이)
1. **입력**: ‘구조 영상’(회색 박스로 만든 3D 장면, 사람 뼈대, 깊이 지도, 연필 스토리보드 등) + 선택적으로 첫 프레임 이미지 + 프롬프트.
2. **역할 분담**: 구조 영상이 **레이아웃·움직임·카메라를 프레임마다 고정**하고, 첫 프레임과 글이 **세계의 생김새**(시대, 화풍, 조명)를 정한다. 같은 회색 박스 영상을 우키요에 풍, 사막 도시, 우주 오페라로 각각 렌더할 수 있다.
3. **구조**: 영상 모델 **MiniMax-H3는 얼려 둔 채** LoRA(작은 추가 학습 모듈) 두 개만 붙인다. 하나는 구조를 따르게 하는 **제어 LoRA**, 하나는 **4스텝 만에 렌더하는 가속 LoRA**. “이건 깊이 지도다” 같은 **구조 종류 이름표가 필요 없다** — 프롬프트에 입력 이름만 적으면 된다.
4. **스트리밍**: 블록 단위로 순서대로 렌더하는 버전도 있어, 영상이 다 만들어지기 전에 앞부분부터 볼 수 있다.

## 숫자
- **4스텝 샘플링**은 50스텝보다 **12.3배 빠르면서** 화질·구조 충실도가 더 좋았다고 주장.
- 처리 가능한 구조 **16종 중 11종은 학습 때 본 적 없는 것**: 포인트 클라우드, 2D 포즈 뼈대, 와이어프레임, 노멀맵, **연필 스토리보드**, 복셀, **아이가 그린 크레용 그림**, 실루엣, 컬러 깊이 지도, 자율주행식 3D 박스, Mixamo 캐릭터.
- **비교**: 다른 연구 15개가 자기 페이지에 올린 데모 86건을 그들의 구조 입력 그대로 다시 렌더해 **49승 13무 24패**. 판정은 Gemini 모델이 쌍별 비교로 했고, 사람 블라인드 테스트도 같은 방향이었다고 한다(자체 평가).
- **공개물**: 208개 사례 일반화 벤치마크, 53개 정답 포함 테스트셋, LoRA 4개(전체 클립용·스트리밍용 × 제어·가속), 학습 인덱스 136,289개 중 **57,738개를 영상과 함께** 공개([Hugging Face](https://huggingface.co/Enderfga/SolarRenderer)).

## 왜 중요한가
이 방식은 영상 제작을 **“3D 블로킹 → AI 렌더”** 두 단계로 나눈다. 감독은 회색 박스로 동선과 카메라만 정하고(혹은 에이전트에게 맡기고), 룩은 나중에 여러 버전으로 뽑는다. 연필 콘티나 아이 그림까지 받아 준다는 건 **스토리보드가 곧 입력**이 된다는 뜻이다. 지난주 소개한 Code Video Model(코드로 프리비즈 후 MiniMax로 렌더)과 같은 흐름이고, 둘 다 MiniMax-H3를 바닥에 깔았다. 한계: 백본 MiniMax-H3가 필요하고, 성능 비교는 연구진 자체 평가다.
