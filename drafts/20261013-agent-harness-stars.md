## 한줄 요약
GitHub에서 지금 크게 보이는 AI 저장소 중 상당수는 **새 가중치**가 아니라 **에이전트를 붙잡는 뼈대**다. 2026-10-13 `gh api` 기준 [ECC](https://github.com/affaan-m/ECC) **~277,850★**, [hermes-agent](https://github.com/NousResearch/hermes-agent) **~253,109★**, [claude-mem](https://github.com/thedotmack/claude-mem) **~100,060★**.

## 무엇이 인기인가 (코드 덤프 없이)
- **ECC**: Claude Code·Codex·Cursor 등을 위한 **성능 최적화 하네스** — 스킬, 본능(instincts), 메모리, 보안, 리서치 우선 개발을 묶는다고 자기 소개. “모델을 고른 뒤에도 남는 운영 계층”.
- **Hermes Agent**: “The agent that grows with you”. 성장·지속 사용을 내세운 에이전트 런타임(Nous Research). 단일 채팅창이 아니라 **함께 자라는 에이전트** 서사.
- **claude-mem**: 세션에서 한 일을 캡처·압축해 **다음 세션에 관련 맥락을 주입**. Claude Code·Codex·Gemini·Hermes·Copilot 등 다수 하네스와 연동한다고 명시 — **기억 플러그인** 포지션.
- **패턴**: 9–10월 AiPaper가 다룬 T3 Code·openrig·google/skills와 같은 줄기다. 오늘은 개별 릴리스 뉴스 대신 **스타 규모가 보여주는 수요**를 한 장에 모은다.

## 왜 중요한가
모델 API 가격·벤치 경쟁만 보면 “다음 버전”만 보이지만, 개발자 스타는 **세션 단절·도구 호출·보안·기억**을 해결하는 쪽에 몰린다. Muse Wonder의 Active Memory, Granola의 회의 컨텍스트, LLM Wiki 팀 게이트와 같은 질문이다 — **에이전트가 무엇을 붙잡고 다음으로 넘어가나**.

## 기억할 것
- 스타는 마케팅·바이럴에 민감하다. 프로덕션 적합도·라이선스·보안 감사와는 별개.
- 이미 다룬 저장소의 **심화 튜토리얼 재탕이 아니라** “지금 인기 기술 카테고리” 브리핑으로 읽을 것.
