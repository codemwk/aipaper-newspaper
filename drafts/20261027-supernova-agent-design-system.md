> 지난번 저장하신 ‘에이전트가 읽는 디자인 시스템’ 기사들(DESIGN.md, Figma 가이드라인, TypeUI)과 이어지는 소식입니다 — 이번엔 에이전트가 디자인 시스템을 ‘읽는’ 데서 ‘관리하는’ 쪽으로 넘어갔습니다.

## 한줄 요약
디자인 시스템에서 제일 미뤄지는 일은 **새 컴포넌트가 아니라 관리**다. 빈 문서, 설명 없는 토큰, 이름 바꾸기, 폐기 공지. Supernova는 이걸 **대화 한 줄로 맡기는 에이전트**를 붙였다([Supernova 블로그](https://www.supernova.io/blog/introducing-supernova-agent)).

## 맡길 수 있는 일 (공식 예시)
| 일 | 요청 예 |
|---|---|
| 답 찾기 | “에러 문구엔 어떤 토큰 써야 해?” |
| 문서 점검 | “비어 있거나 거의 빈 문서 페이지 목록 보여 줘” |
| 문서 작성 | “Checkbox 문서를 구조·사용법·Do/Don’t로, 다른 컴포넌트 문서 방식대로 써 줘” |
| 토큰 정리 | “설명 없는 토큰에 설명 달아 줘. 애매하면 물어봐” |
| 일괄 이름 변경 | “space-1…space-8을 space-xs…space-3xl로” |
| 폐기 | “Tag를 폐기 처리하고 Chip으로 안내 문구 추가” |
| Figma 연결 | “이름이 같은 Figma 컴포넌트를 우리 컴포넌트에 연결해 줘” |
| 에이전트용 맥락 | “글쓰기 가이드 페이지를 **스킬**로 바꿔 줘” |
- CSV 색상표, 스크린샷, **브랜드 가이드 PDF**를 첨부할 수도 있다.

## 사람이 쥐고 있는 것
- **내 권한 = 에이전트 권한.** 내가 못 보는 건 에이전트도 못 보고, 요금제 한도도 그대로.
- **게시·삭제는 대기.** 삭제 전엔 지워질 항목 전체를 목록으로 보여 준다.
- **바뀐 것은 전부 목록으로.** 답변마다 수정한 항목을 이름으로 알려 주고 바로 열어 볼 수 있다.
- **되돌리기**: 문서 수정은 페이지 기록에서 복구. 다만 **원클릭 실행 취소는 아직 없다** — 같은 대화에서 “되돌려 줘”라고 요청해야 한다.
- 공식 권장 습관: **먼저 점검, 그다음 변경.** “안 쓰는 토큰 뭐야?” → 목록 확인 → “지워 줘.”

## 비용
- 메시지당 **50 워크스페이스 크레딧**(베타 중 변경 가능). 요금표 기준 Starter(무료) 월 1,000크레딧, Pro(월 399달러) 월 1만 크레딧([요금](https://www.supernova.io/pricing)). 단순 계산으로 Starter는 월 20메시지, Pro는 200메시지 수준.

## 왜 중요한가
- **표의 마지막 줄이 핵심.** 여기서 만든 스킬·컨텍스트는 엔지니어 팀의 **코딩 에이전트가 읽는 재료**다. 디자인 시스템을 관리하는 에이전트가 곧 다른 에이전트들이 의존하는 맥락을 최신으로 유지하는 셈이다.
- **ANDRSN 관점**: 브랜드 가이드 PDF를 넣어 토큰·문서로 바꾸고, 글쓰기 톤을 스킬로 만드는 흐름은 “브랜드를 에이전트가 읽을 수 있는 형태로 납품”하는 서비스의 실무 도구가 된다.
- 주의: 토큰 이름을 일괄로 바꿨을 때 코드 저장소의 참조까지 함께 바뀌는지는 공지에 나와 있지 않다. 내보내기 파이프라인을 돌린 뒤 코드 쪽 반영을 따로 확인하는 게 안전하다.
