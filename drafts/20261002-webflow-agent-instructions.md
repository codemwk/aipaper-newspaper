## 한줄 요약
Webflow가 [Agent Instructions Generation](https://webflow.com/updates/agent-instructions-generation)(2026-09-02)으로 **라이브 사이트**에서 Brand Guidelines, Design System, Asset Guidelines, CMS Guidelines **초안**을 뽑게 했다. 이어 [AI code components visual editing](https://webflow.com/updates/ai-code-components-visual-editing)은 생성 React 컴포넌트를 **네이티브 요소처럼** Style Panel·캔버스 텍스트로 다듬게 한다.

## 제품으로 보면
- Instructions: 빈 에디터가 아니라 **실제 사이트 컨텍스트**에서 초안 → 전부 편집·재생성 가능, 잠금 없음(공식).
- Visual editing: 코드 컴포넌트 내부 요소 선택·스타일, 프롬프트에 요소를 컨텍스트로 넣어 **스코프 변경**, 작은 수정은 프롬프트 없이 캔버스에서.
- Framer Skills(규칙 메모리)·Figma Weave(노드 스코프)와 같은 계열: **에이전트에게 줄 브랜드·디자인 시스템 문서를 제품이 생성**.

## 왜 중요한가
“에이전트가 사이트를 고친다”의 병목은 모델보다 **지침 파일의 최신성**이다. Webflow는 지침 생성과 시각 편집을 한 캔버스에 묶었다. 노코드/로우코드 팀의 에이전트 온보딩 비용이 내려간다.
