## 한줄 요약
[jaychempan/Agent-Leaderboard](https://github.com/jaychempan/Agent-Leaderboard)는 AI 에이전트 생태계 GitHub 저장소를 **보드별로** 모아 스타 순으로 매일 갱신한다. Skills / MCP / Prompt / Frameworks / Auto Research 다섯 판.

## 무엇을 보나
- 추적 규모(README): Skills 500+ · MCP 1,500+ · Prompt 1,100+ · Frameworks 1,200+ · Auto Research 100+.
- 최소 스타 컷·키워드로 노이즈를 줄인 **디스커버리 레이어**. 코드 튜토리얼이 아니라 “지금 어디에 관심이 몰리는지” 지도.
- 상위권에 자주 보이는 축: 에이전트 스킬 팩, MCP 서버, LangChain급 오케스트레이션 — **설치형 스킬이 프레임워크만큼 뜨는** 2026 패턴을 숫자로 보여 준다.
- 보완 리스트: [linny006/awesome-agent-skills](https://github.com/linny006/awesome-agent-skills)(자동 크롤·품질 레이팅), [microsoft/skills](https://github.com/microsoft/skills)(Azure·Foundry 도메인 스킬·MCP 설정).

## 왜 중요한가
하네스·MCP·스킬 저장소가 폭증하면 개인 빌더·PKM 사용자는 **고르기**가 병목이다. 리더보드는 만능 추천이 아니라 **관심의 온도계**. 어제 다룬 개별 하네스 대신, 오늘은 “지도 레이어” 자체를 짧게 챙긴다.
