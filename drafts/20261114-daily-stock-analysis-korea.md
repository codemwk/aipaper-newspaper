## 한줄 요약
“AI가 대신 매매”가 아니라 **“AI가 매일 아침 브리핑”**하는 쪽이 GitHub에서 가장 큰 인기를 끌고 있다. **daily_stock_analysis**는 이번 주 GitHub 트렌딩 5위에 올랐다(+3.6천 별, 누적 약 7.15만)([Githot 주간](https://githot.dev/en/weekly), [GitHub](https://github.com/ZhuLinsen/daily_stock_analysis), MIT).

## 무엇을 해 주나
- **관심 종목 목록**(예: `005930.KS` 같은 한국 종목 코드)을 넣으면, 시세·차트·기술 지표·뉴스·공시·기본 지표를 모아 LLM이 분석한다.
- 결과는 **‘결정 대시보드’** 형식이다. 핵심 결론, 점수, 추세, 매수·매도 가격대, 리스크 경고, 촉매 요인, 행동 체크리스트가 들어간다. 이걸 **텔레그램·디스코드·슬랙·이메일**(중국 메신저 포함)로 보낸다.
- **에이전트 질의**: 이동평균, 엘리어트 파동, 추세, 이벤트, 성장 등 **15가지 내장 전략**으로 이어서 질문할 수 있다. 웹 작업 화면에서는 백테스트와 보유 종목 관리도 된다.
- **서버 없이 무료로**: 저장소를 포크하고 GitHub Actions 시크릿에 LLM API 키와 알림 채널을 넣으면 매일 자동으로 돈다. Gemini, Claude, OpenAI 호환 API, DeepSeek, Ollama 로컬 모델을 쓸 수 있다.

## 주의할 점
- **주문 기능은 없다**. README 면책 조항도 “학습·연구용이며 투자 조언이 아니다”라고 밝힌다. 오히려 이 점이 장점이다. 사람이 결정하는 구조가 기본이다.
- 기본 데이터 소스(AkShare·Baostock·YFinance)는 무료지만 **안정성을 보장하지 않는다**. 한국 주식은 시장마다 데이터 범위가 다르니 ‘시장 지원 범위’ 문서를 먼저 확인해야 한다.
- README 맨 위의 스폰서 링크(모델 중계 서비스 등)는 제휴 링크다. API 키는 **공식 제공사 키를 쓰는 게 안전하다**.
- LLM이 써 주는 “매수 가격대”는 근거가 그럴듯해 보여도 **검증된 신호가 아니다**. 이번 주 다룬 ‘속이기 어려운 퀀트 루프’ 연구에서도 샤프 지수 2.94짜리 전략이 홀드아웃 구간에서 0.26으로 떨어졌다.

## 왜 중요한가
지난번 저장하신 TradingAgents(LLM 여러 개가 분석가·트레이더 역할을 나눠 맡는 프레임워크)와 이어지는 소식이다. 차이는 **실행 방식**이다. 연구용 프레임워크에서 “**포크하고 키만 넣으면 매일 아침 메신저로 오는**” 생활 도구로 내려왔다. MT5 자동매매로 바로 가기 전에, **분석은 AI가, 판단과 주문은 사람이** 하는 단계부터 써 보기 좋은 구조다.
