## 한줄 요약
“Claude에서 한 이야기를 ChatGPT가 모르고, Cursor는 또 처음부터 묻는다.” 이 문제를 **“기억을 앱 밖으로 꺼내 내가 소유하고, AI들은 MCP로 빌려 쓴다”**로 푸는 제품이 이번 주 두 개 나왔다. 같은 목표, 정반대 철학이다.

## Cobrain — AI가 쓰고, 밤에 스스로 정리하는 마크다운 두뇌
- **v1.19(10/13)**: cursor.directory에 **Cursor 플러그인** — 연결 설정과 에이전트용 지침을 함께 배포. 이미 Claude 플러그인 디렉터리(1.15), ChatGPT 플러그인(1.13, 전 플랜), Claude Code·Codex·Antigravity 가이드가 있다([릴리스 노트](https://cobrain.space/releases)).
- **유닛(1.18)**: 고객·프로젝트처럼 추적할 대상을 만들면 **카드 + 결정 기록** 두 파일로 시작하고, AI가 “이게 뭐고 왜 여는지” 물어 첫 결정을 적는다. AI용 규칙·교훈·말투 파일은 쓸 내용이 생길 때 만들어진다 — 빈 템플릿 대신 **필요할 때 자라는 구조**.
- **The Dream(1.14)**: 사용자 시간대의 **밤마다** 바뀐 노트를 다시 읽어 **중복·모순·깨진 링크**를 찾고, 안전한 건 AI가 고치고 나머지는 묻는다(주간/월간 선택). 삭제는 휴지통으로.
- **첨부 읽기·암호화(1.16)**: PDF·Word·Excel·PowerPoint·Keynote를 AI가 직접 읽고, 스캔 페이지는 이미지로, 영상은 몇 프레임을 본다. 노트·첨부 모두 **두뇌별 키로 암호화**.
- **누가 썼나 표시(1.11)**: 노트에 “Codex · Anna”처럼 **어느 AI가 누구 대신** 썼는지 서명.
- **가격**: 무료 **1,000노트**·연결 AI 무제한·공유 3개(읽기 전용); Pro는 노트 무제한·공유 무제한·첨부 2GB; **Team 좌석당 월 $7**(3석부터). 현재 **베타라 결제는 아직 받지 않는다**([가격](https://cobrain.space/pricing)). 노트는 폴더 속 `.md`로 언제든 일괄 내보내기.

## AI Twin — 아무것도 저절로 저장하지 않는 기억
- **10/12 출시**(영국 스코틀랜드 등록 법인, 데이터 영국 저장). 메모·편지 사진·음성 메모·파일·이메일로 넣되, **모든 캡처는 ‘대기 검토(Pending Review)’에서 사람이 승인해야** 저장된다([런치 글](https://www.ai-twin.co.uk/journal/ai-twin-is-live)).
- **유형화**: 사람은 사람으로, 날짜는 날짜로, 문서는 문서로 저장 — 나중에 정확히 찾기 위해서. 모든 항목에 **출처**가 붙고, 사실이 바뀌면 옛 버전을 날짜와 함께 보존.
- **연결**: MCP 지원 어시스턴트가 **허용한 등급(tier)만** 본다. Claude 지원, ChatGPT는 유료 플랜 + 개발자 모드 필요. 주요 읽기·쓰기는 감사 로그로 남는다.
- **하지 않는 것**: 상시 녹음 없음, 감정 추정 없음, 학습 사용 없음. 웹 클리퍼·폰 공유·메일/캘린더 연동은 **아직 미구현**이라고 스스로 밝힘. 첫 7일 무료.

## 왜 중요한가
LLM Wiki가 “AI가 내 노트를 위키로 **정리**”하는 패턴이었다면, 이번 두 제품은 **여러 AI가 한 기억을 공유**하는 계층이다. 선택지는 분명하다: **Cobrain = 자동화 우선**(AI가 쓰고 밤에 스스로 청소, 사람은 예외만 처리) vs **AI Twin = 동의 우선**(사람이 하나하나 승인, 대신 느리다). 개인 OS를 설계한다면 “일 기억(프로젝트·결정)은 Cobrain식 자동 정리, 삶 기억(가족·계약·건강)은 AI Twin식 승인 저장”처럼 **기억의 종류에 따라 정책을 나누는 것**이 답에 가깝다. 두 서비스 모두 초기 베타·소규모 팀이라 장기 존속성은 미지수 — 그래서 둘 다 강조하는 **‘언제든 전부 내보내기’**를 실제로 확인해 두자.
