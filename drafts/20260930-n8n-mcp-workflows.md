## 한줄 요약
[czlonkowski/n8n-mcp](https://github.com/czlonkowski/n8n-mcp)는 n8n 자동화 플랫폼의 **노드 문서·프로퍼티·오퍼레이션·템플릿**을 MCP로 노출해, Claude·Cursor 등이 **올바른 노드 조합으로 워크플로를 설계**하게 한다. README 기준 노드 **2,864**(코어 836+커뮤니티 2,028), 템플릿 **2,352**, AI 도구 변형 **267** 등을 구조화해 제공한다.

## 쓸 때 주의
- 저자 경고: **프로덕션 워크플로를 AI로 직접 편집하지 말 것** — 복사본·개발 환경·익스포트 백업 후 검증.
- Docker/npm/Railway 배포 경로가 정리돼 있어 “에이전트+iPaaS” 실험 진입 장벽이 낮다.

## 왜 중요한가
퍼스널 OS·뉴스 파이프라인처럼 **반복 자동화**가 늘어날수록, 에이전트에게 필요한 건 만능 브라우저가 아니라 **노드 카탈로그에 정통한 도구 서버**다. Zapier Central류 폐쇄형과 대비되는 오픈 레퍼런스.
