## 한줄 요약
Penpot은 Figma의 오픈소스 대안이자, MCP 서버로 에이전트가 직접 캔버스를 만지는 흐름에서 자주 언급되는 툴이다. **2.19.0(11/9 GitHub 릴리스)**의 핵심은 **디자인 토큰을 라이브러리에서 공유**하는 기능이고, **2.19.1(11/11)**은 보안 수정 4건이다([Penpot 릴리스 노트](https://penpot.app/release-notes/2-19-is-this-it), [GitHub Releases](https://github.com/penpot/penpot/releases)).

## 무엇이 바뀌었나 (2.19)
- **공유 디자인 토큰**: 토큰을 한 라이브러리에 두고, 연결된 모든 파일이 그걸 쓴다. 컴포넌트·색상처럼 라이브러리 업데이트와 **자동 동기화**. 테마·세트는 파일마다 고를 수 있다. “토큰이 진짜 단일 원천(single source of truth)”이 되는 셈.
- **면별 선 두께(per-side stroke)**: 사각형·보드의 위·오른쪽·아래·왼쪽 선 두께를 따로. 토큰과도 연결된다. 카드 하단 구분선 같은 UI 패턴을 꼼수 없이 그린다.
- **단축키 커스터마이즈**: 재지정·충돌 경고·초기화, 설정 내보내기/가져오기.
- **패스 편집기 개편**과 **WebGL 렌더러**(선명한 텍스트, 빠른 내보내기 — 설정에서 켜야 함).
- 커뮤니티 수정 중 **MCP 플러그인 연결 상태에서 페이지 이동 시 크래시**가 고쳐졌다. 에이전트 연동을 쓰는 사람에겐 체감되는 수정이다.

## 2.19.1 보안 수정
편집자 권한 팀원이 대기 중인 초대 토큰을 볼 수 있던 문제, 공유 링크 범위 밖으로 댓글 작성자 신원이 새던 문제, 권한 검사 없는 ‘모든 스레드 읽음’ API, 그리고 **“정화된” SVG가 실제 스크립트를 품을 수 있던 문제(CVE-2026-105694)**. 외부 SVG를 자주 붙여 넣는 팀이라면 바로 올리는 게 좋다.

## 왜 중요한가
지난번 저장하신 **DESIGN.md·디자인 시스템 MCP** 흐름과 이어진다. 에이전트가 디자인 시스템을 읽으려면 토큰이 **파일마다 복제된 사본이 아니라 한 곳에서 관리되는 계약**이어야 한다. 2.19는 오픈소스 쪽에서 그 전제를 갖춘 업데이트다.

## 주의
셀프호스팅은 **브레이킹 체인지**가 있다: 대형 인스턴스는 업그레이드 전에 파일 페이로드 마이그레이션을 수동 실행해야 하고, Admin Console이 기본 활성화되어 별도 서비스 배포·환경변수 설정이 필요하다. 업그레이드 가이드를 먼저 볼 것.
