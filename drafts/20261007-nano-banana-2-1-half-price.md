## 한줄 요약
Google이 10월 6일 **Nano Banana 2.1**(모델 ID `gemini-nano-banana-2.1`)을 내놨다. 공식 블로그 글도 벤치마크 표도 없이, 10/5 Google Flow 모델 목록에 잠깐 떴다 사라진 뒤 다음 날 AI Studio 계정의 짧은 게시물로 공개됐다. 핵심은 **한 장당 가격이 Nano Banana 2의 절반**이라는 점이다([Apidog 정리](https://apidog.com/blog/nano-banana-2-1/), [TechCity](https://www.techcityauthority.com/2026/10/nano-banana-2-1-live-google-flow.html)).

## 가격 (Gemini API 유료, 표준 기준)
| | 1K | 2K | 4K | 입력 /M |
|---|---|---|---|---|
| **Nano Banana 2.1** | **$0.0336** | **$0.0504** | **$0.0756** | $1.50 |
| Nano Banana 2 | $0.067 | $0.101 | $0.151 | $0.50 |
| Nano Banana Pro | $0.134 | $0.134 | $0.24 | $2.00 |

- 이미지 출력 토큰 단가가 $60→**$30**/M로 내려갔고, 장당 토큰 수는 같다. 1K 1,000장이면 **$33.6 vs $67**.
- 1K 가격은 저가형 Nano Banana 2 Lite와 같은데, 2.1은 **2K·4K까지** 된다. 배치 처리하면 다시 절반.

## 무엇이 좋아졌다고 하나 (Google 주장)
- **텍스트 렌더링**: 메뉴판·포스터·UI 목업의 글자가 덜 깨진다.
- **말로 하는 마스크 편집**: 영역을 칠하지 않고 “이 부분만 바꾸고 나머지는 그대로”라고 쓰면 모델이 범위를 추론.
- **캐릭터·제품 일관성**: 여러 번 편집해도 같은 얼굴·같은 패키지 유지, 레퍼런스 이미지 **최대 14장**.
- **검색 그라운딩**: 웹 검색에 더해 **Google 이미지 검색**까지 근거로 사용(실존 인물 사진은 제외). 모든 결과물엔 SynthID 워터마크.

## 함정
- **입력 토큰 3배**($0.50→$1.50/M), 텍스트·사고 출력도 $3→$7.50/M. 레퍼런스 이미지를 많이 넣는 편집 작업은 절감 폭이 줄거나 역전될 수 있다.
- **512px 티어 없음**, Gemini API **무료 티어 없음**.
- 품질 향상은 **아직 수치로 검증되지 않은 주장**이다.

## 왜 중요한가
이미지 생성은 이제 “누가 더 예쁘냐”보다 **“장당 얼마에 글자까지 맞게 뽑느냐”**의 단가 싸움이다. 썸네일·카드뉴스·상세페이지를 대량으로 만드는 1인 크리에이터라면 같은 프롬프트로 2와 2.1을 나란히 돌려 **글자 정확도와 실제 청구액**을 비교해 보고 넘어가는 게 맞다.
