## 한줄 요약
생성 미디어 API를 “내가 골라 호출”하던 단계에서, **에이전트 스킬이 모델·단가·일관성을 대신 고르는** 층으로 올라왔다. Scenario Labs의 공식 스킬 저장소가 11/5 전후 GitHub에서 급상승했다([scenario-labs/skills](https://github.com/scenario-labs/skills)).

## 지금 뭐가 뜨나
- **Scenario MCP 스킬**: 프로덕션용 이미지·영상·오디오·3D. “쓰기 전에 가격을 보여 주고”, 캐릭터·브랜드 일관성을 유지한다고 설명.
- **크리에이티브 앱 드라이버**: 두 번째 세트는 MCP가 아니라 **앱이 떠 있는 상태**에서 ZBrush·Blender·Maya·Unreal·Unity·Godot·Roblox Studio를 에이전트가 조작.
- **호환**: Claude Code, Cursor, Codex, Copilot 등 70+ 에이전트 스킬 형식.
- **라이선스·규모**: **MIT**, 11/5 기준 별 약 **2,993**. 하루 만에 별 +200대 유입이 Agent Tools Today 등에 집계됨.

## 왜 중요한가
지난번 저장하신 **ArtCraft·VoiceStudio·OpenMontage** 같은 ‘에이전트용 크리에이티브 스튜디오’ 흐름의 상업 MCP 버전이다. Fal이 **인프라 가격표**라면 Scenario 스킬은 **에이전트 UX에서 그 가격표를 고르게 하는 포장**이다. 3D·게임 엔진까지 한 스킬 패밀리로 묶은 점이 차별점.
