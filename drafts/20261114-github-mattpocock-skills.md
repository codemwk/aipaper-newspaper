## 한줄 요약
이번 주 GitHub 주간 트렌딩 상위권에는 ‘에이전트 스킬’ 저장소가 많았다. 그중 **mattpocock/skills**(+8.7천 별)가 가장 분명한 메시지를 낸다. “**과정을 통째로 소유하는 프레임워크는 통제권을 빼앗는다. 작고, 모델을 가리지 않고, 고쳐 쓰기 쉬운 스킬을 조합하라.**”([GitHub](https://github.com/mattpocock/skills), MIT, [Githot 주간](https://githot.dev/en/weekly))

## 네 가지 실패, 네 가지 처방
1. **에이전트가 내가 원한 걸 안 만든다** → `/grill-me`: 시작 전에 에이전트가 **질문을 계속 던지게** 해서, 설계의 모든 갈림길을 정리한다. 저자가 꼽는 가장 인기 있는 스킬이고, 코드가 아닌 일에도 쓸 수 있다.
2. **에이전트가 너무 장황하다** → **공유 용어집**(`GLOSSARY.md`): 프로젝트 고유 용어를 정해 두면 “스무 단어로 말할 걸 한 단어로” 말한다. 이름 짓기가 일관되고 토큰도 아낀다.
3. **코드가 안 돈다** → `/tdd`(실패하는 테스트를 먼저 쓰고 고치는 루프), `/diagnosing-bugs`(재현 → 최소화 → 가설 → 계측 → 수정 → 회귀 테스트).
4. **진흙 덩어리 코드베이스** → `/improve-codebase-architecture`: 며칠에 한 번 돌려서 구조를 개선할 후보를 HTML 리포트로 받는다. 저자도 “점검 도구일 뿐, 엉킨 코드를 대신 풀어 주지는 않는다”고 선을 긋는다.

## 비개발자에게도 쓸모 있는 것들
- `/handoff`: 지금 대화를 **인수인계 문서**로 압축해서 다른 에이전트가 이어받게 한다.
- `/to-questionnaire`: 혼자 답할 수 없는 결정을 **상대에게 보낼 질문지**로 바꾼다.
- `/wait-what`: 에이전트 설명이 이해되지 않을 때, 빠진 맥락을 채워 쉬운 말로 다시 설명하게 한다.
- `writing-for-agents`: 스킬, AGENTS.md처럼 **에이전트가 읽는 문서를 쓰는 법**.

## 같은 주의 다른 신호
같은 주간 목록에는 Vercel의 브라우저 자동화 CLI **agent-browser**(+4.6천), 에이전트 팀을 일정·메모리와 함께 운영하는 **LobeHub**(+1.2천)도 있었다. 정리하면 이렇다. 에이전트에게 **손**(브라우저·데스크톱)을 주는 도구와, 그 손이 **엇나가지 않게 하는 습관**(스킬)이 동시에 뜨고 있다.

## 왜 중요한가
AI 작업의 병목은 모델 실력보다 **처음 정렬(무엇을 원하는지)**에 있다는 경험담이 별 32만 개짜리 저장소로 모였다. 클라이언트 브리프를 받을 때 `/grill-me`처럼 “**에이전트가 나를 인터뷰하게**” 하는 방식은 브랜드 전략 작업에도 그대로 쓸 수 있다.
