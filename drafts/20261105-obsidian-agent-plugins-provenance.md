## 한줄 요약
에이전트가 내 볼트를 **읽기만** 하던 단계에서 **쓰기 시작**하자, 이제 플러그인들의 경쟁 포인트는 “얼마나 똑똑하냐”보다 **“틀렸을 때 되돌릴 수 있냐, 근거가 살아 있냐”**로 옮겨 가고 있다. 지난번 저장하신 **LLM Wiki·기억 신선도(freshness)** 소식과 바로 이어진다.

## Smart Second Brain — 검토 대기열이 기본
- 키워드와 의미를 섞은 **하이브리드 검색**, 링크·태그·내용으로 노트를 묶는 **자동 주제 그래프**. 이 둘은 AI 연결 없이도 동작.
- AI를 붙이면 에이전트가 노트를 찾고 읽고 **수정하되, 모든 변경은 검토 대기로** 올라간다. 웹 검색, Dataview·Tasks·Canvas 연동, 노트 기반 차트·대시보드.
- Ollama·oMLX 로컬 또는 OpenAI·Anthropic·OpenRouter. 로컬 모델끼리 쓰면 아무것도 밖으로 안 나가고, **텔레메트리 없음**. 데스크톱·모바일 모두([플러그인 페이지](https://community.obsidian.md/plugins/smart-second-brain)).

## Agent LLMs 0.7.15 — 안전장치 목록이 길다
- **AI 변경 기록 + 안전한 undo**: 최근 20건의 전후 스냅샷. 그 사이 내가 파일을 고쳤다면 덮어쓰지 않고 건너뛴다.
- **출처 추적**: 요약 노트가 원문 조각별 해시를 기록 → 원문이 바뀌면 ‘낡음’ 표시, 재생성 시 차이를 보여 준다.
- **인용 검증**: 답변에 인용된 노트 경로·헤딩이 실제로 있는지 확인, 없으면 표시.
- **모순 검토·중복 후보·고아 노트 링크 제안**: 대부분 LLM 호출 0회, 아무것도 자동 삭제·병합하지 않음.
- 그 밖에 결정 기록장, 오래 안 연 노트 5개 다시 보여 주기, 대화에서 결론·미결 질문 추출([플러그인 페이지](https://community.obsidian.md/plugins/agent-llms)).

## 왜 중요한가
LLM Wiki를 직접 만들 계획이라면, 이 두 플러그인의 기능 목록은 그대로 **설계 체크리스트**다: 에이전트 수정은 검토 후 반영, 요약엔 원문 해시, 인용은 자동 검증, 삭제는 절대 자동으로 하지 않기.

## 주의
기능 설명은 각 플러그인의 문서 기준이며 직접 테스트한 결과가 아니다. 클라우드 모델을 붙이면 노트 내용이 해당 회사로 전송된다.
