## 한줄 요약
로컬에서 돌리려고 모델을 **양자화(숫자 정밀도 낮추기)**하거나 **가지치기(가중치 덜어내기)**하면, 평균 점수는 조금만 떨어지는데 특정 능력은 통째로 사라질 수 있다. 노스웨스턴대 연구진은 **무엇이 먼저 사라지는지에 정해진 순서가 있는지**를 물었다([arXiv 2611.11695](https://arxiv.org/abs/2611.11695)).

## 어떻게 실험했나
- 지시 학습된 모델 **8종**에 **손상 7가지**를 강도를 높여가며 가했다. 무작위 손상 4종(가우시안 노이즈, 가중치 0으로 만들기, 뉴런 제거, 층 제거)과 실제 배포에 쓰는 압축 3종(Wanda, SparseGPT, GPTQ)이다.
- 과제 16개를 **답하는 방식 4가지**로 물었다. 보기에서 고르기, 답만 쓰기, JSON으로 쓰기, 답을 두 번 쓰기.
- 예측을 미리 등록해 두고(사전 등록) 검증했다.

## 발견 다섯 가지
- **손상 방법은 ‘속도’만 정하고, ‘순서’는 정하지 않는다.** 원리가 전혀 다른 무작위 손상 4종에서 과제가 무너지는 순서의 상관이 중앙값 **0.90**이었다. 같은 모델 안에서 가지치기·양자화와도 **0.875**였다.
- **원래 자신 없던 과제가 먼저 무너진다.** 손상 전 모델이 정답과 오답 사이에 둔 확률 차이(마진)가 작은 과제가 먼저 무너졌다. 단순히 “어려운 과제”라서가 아니다.
- **드문 지식이 먼저 사라진다.** 학습 말뭉치에 적게 나온 답일수록 먼저 잊었다. 틀린 답도 **더 흔한 쪽으로** 쏠렸다. 수도를 틀릴 때 둘 중 더 자주 등장하는 도시를 댄 경우가 62~100%였다.
- **고르기보다 써내기가 먼저 무너진다.** 객관식 대비 무너지는 속도가 답만 쓰기 1.5배, **JSON 2.5배, 두 번 쓰기 8배**(무작위 손상 기준)였다. 형식이 엄격할수록 약하다.
- **미리 예측할 수 있다.** 무작위 손상으로 한 번 잰 ‘취약성 프로필’이 압축 후 어떤 과제·사실이 먼저 사라질지 맞혔다. 과제 4개로 보정하면 남은 정확도 오차가 0.11~0.12로, 균일하게 떨어진다고 가정할 때(0.20~0.21)의 절반 수준이었다. 다른 모델 계열의 프로필을 빌려도 거의 비슷했다.

## 사람의 뇌와 닮은 점
연구진은 **의미 치매(semantic dementia)**를 비교 대상으로 든다. 이 환자들은 덜 친숙한 지식을 먼저 잃고, 알아보기보다 이름 대기를 먼저 못 하며, 틀릴 때는 친숙한 답으로 쏠린다. 신경망이 **어디가 손상됐는지보다 무엇을 배웠는지**에 따라 잊는 순서가 정해진다는 해석이다.

## 한계
- **짧은 답 과제에만** 해당한다. 추론·코드·지시 따르기·함수 호출 같은 긴 답 과제에서는 순서가 유지된 경우가 16쌍 중 10쌍에 그쳤다. 가지치기에서는 여러 단계 추론이 더 약해졌다.
- GPTQ 양자화에서는 순서가 **모델 간에 옮겨지지 않았다**.

## 왜 중요한가
llama.cpp 1.0 같은 로컬 엔진으로 양자화 모델을 돌리는 사람에게 실용적인 체크리스트가 된다. 평균 점수만 보지 말고 **① JSON·정해진 형식 출력, ② 드문 고유명사·전문 용어, ③ 원래 모델도 아슬아슬하던 과제**부터 시험해 보라는 것이다. 세컨드 브레인을 작은 로컬 모델로 돌리는 경우, **내 노트에만 있는 드문 이름**이 가장 먼저 틀린다는 뜻이기도 하다.
