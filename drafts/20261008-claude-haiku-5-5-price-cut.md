## 한줄 요약
Anthropic이 10월 7일 **Claude Haiku 5.5**를 냈다. 스스로 “가장 싸고, 가장 빠르고, 가장 유능한 소형 모델”이라 부른다. 요약·압축(compaction)·분류·DB 질의 같은 **대량·반복 작업**과, Opus 5.5·Sonnet 5.5 밑에서 일하는 **서브에이전트**용이다([Anthropic](https://www.anthropic.com/claude-haiku-5-5)).

## 가격이 핵심 (100만 토큰당)
| | Haiku 5.5 (≤10만 / >10만 토큰 프롬프트) | Haiku 4.5 | Sonnet 5.5 |
|---|---|---|---|
| 입력 | $0.10 / $0.50 | $1.00 | $2.00 |
| 출력 | $0.50 / $2.50 | $5.00 | $10.00 |
| 캐시 읽기 | $0.01 / $0.05 | $0.10 | $0.10 |

- 10만 토큰 이하 요청은 **90% 인하**, 초과는 50% 인하. Anthropic은 이전 Haiku 요청의 약 90%가 10만 토큰 이하였다며 “평균 약 75% 저렴”이라고 계산한다(새 토크나이저로 작업당 토큰이 약간 늘어난 점 반영).
- **Haiku급 최초로 effort(노력) 설정**을 지원 — 비용과 지능 중 어느 쪽에 맞출지 고른다.

## 성능은 (회사 발표 수치)
- 컴퓨터 사용 OSWorld 2.1(오프라인 부분집합) **72.4%**(Haiku 4.5는 15.7%, Sonnet 5.5는 83.9%).
- Terminal-Bench 4.0 **39.2%** — 복잡한 에이전트 코딩은 여전히 Sonnet·Opus(70.6%) 몫이라고 Anthropic도 인정한다.
- 고객 후기: HubSpot CRM 평가 92.8%, Asana 작업 지연 30%+ 감소, Box는 Haiku 4.5 대비 11점 상승·지연 절반.

## 함께 발표된 것
- **Sonnet 5.5 캐시 읽기 $0.20→$0.10** — 에이전트 작업 대부분에서 약 20% 저렴.
- **Max·Team 구독자 월 API 크레딧**: Max 5x $100, Max 20x $200, Team 최대 $500(팀 공유). 이번 주 배포.
- Python·TypeScript SDK에 **컴퓨터 사용·브라우저 사용(베타)** 지원 추가.

## 왜 중요한가
가격표가 “큰 모델이 생각하고, 작은 모델이 손발을 움직인다”는 구조를 밀고 있다. 내 노트 자동 요약, RSS 기사 분류, 볼트 정리 같은 **매일 수백 번 도는 작업**은 Haiku 5.5로, 기획·판단은 상위 모델로 나누면 비용이 크게 준다. 구독자 크레딧은 “구독 → API 실험”으로 사용자를 끌어오는 장치다.
