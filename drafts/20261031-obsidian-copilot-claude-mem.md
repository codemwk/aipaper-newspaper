## 한줄 요약
세컨드 브레인에 에이전트를 붙이면 두 가지가 중요해진다. **노트를 더 풍부하게 다루는 능력**, 그리고 **내 계정으로 무엇이 실행되는지 아는 것**. 이번 두 업데이트가 정확히 그 둘이다.

## ① Obsidian Copilot 4.0.17 — 노트 안의 그림까지
([릴리스 노트](https://github.com/logancyang/obsidian-copilot/releases/tag/4.0.17))
- **Excalidraw 연동**: Copilot 안의 에이전트가 손그림풍 다이어그램을 **새로 그리고, 기존 그림을 읽고 고친다.** 라벨과 화살표가 도형에 붙은 채 유지된다. 채팅에는 작업한 그림 카드가 뜬다.
  - 개발자 테스트: 같은 다이어그램을 Copilot 밖의 Codex보다 **토큰 60% 적게, 시간 23% 덜** 써서 그렸다.
  - Excalidraw 플러그인 **2.29 이상** 필요.
- **검색 크기 제한**: 설정 → Copilot → Miyo에서 **최대 결과 수·검색 변형 수** 조절, 특정 폴더만 검색 지시 가능 → 에이전트가 볼트를 과하게 퍼 오지 않게.
- **Send now**: Claude가 답하는 도중 대기 중 메시지를 바로 끼워 넣기.
- 관련 노트 목록에 **폴더 경로** 표시(같은 제목 노트 구분).

## ② claude-mem 15.7 — 기억 갱신이 ‘다른 AI’로 새던 문제
([릴리스 노트](https://github.com/thedotmack/claude-mem/releases/tag/v15.7.0))
- 무슨 일이었나: ‘My Work’ 자동 갱신이 Claude Code의 답을 거절하면(주로 1,200자 넘는 리뷰), 다음 로그인된 에이전트로 넘어갔다. Codex가 깔린 PC에선 설정을 Claude로 해 뒀어도 **사용자 ChatGPT 계정으로 숨은 Codex 실행**이 돌았다 — 보고된 사례는 **4일간 약 230회**.
- 수정: 거절된 답은 **그 에이전트에서 갱신을 끝낸다.** 아예 실행 불가(로그아웃·크래시)일 때만 다음 에이전트로 넘긴다.
- 기본 노트 작성 모델을 날짜 고정 ID 대신 **항상 최신 Haiku 별칭**으로. 저장소 규칙에도 “기본값에 날짜 고정 모델 ID 금지”를 명시.
- 그 밖에: 30일 지난 로그 자동 정리, 상위 Git 저장소의 관계없는 기억이 하위 환경으로 새지 않게 하는 명시적 상속, GitLab·Hugging Face·npm 토큰 가림 처리 확대, 이미지 인식 관찰 1단계(**기본 꺼짐**).

## 왜 중요한가
- 기억 도구는 백그라운드에서 **내 구독으로** 돈다. “설정은 A인데 실제론 B가 돌았다”는 비용·프라이버시 모두의 문제다. 업데이트 전이라면 Codex 사용 기록을 한 번 확인해 볼 만하다.
- 지난번 저장하신 Obsidian Copilot V4·claude-mem 기사와 이어지는 소식이다.
