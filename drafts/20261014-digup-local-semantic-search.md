## 한줄 요약
세컨드 브레인의 가장 큰 구멍은 **“노트로 옮기지 않은 것들”**이다 — 스크린샷, 녹음, PDF, 영상. [DigUp](https://github.com/ARahim3/DigUp)은 그걸 **노트로 옮기지 않고도 의미로 찾게** 해 주는 무료 Mac 앱이다. 10/8 생성 후 10/14 기준 **약 2,316★**.

## 어떻게 동작하나
- **엔진**: AiPaper가 10/7 다룬 Google DeepMind **EmbeddingGemma 2** — 텍스트·이미지·오디오·비디오를 하나의 공간에 넣는 멀티모달 임베딩(740M, Apache 2.0, 100+ 언어). DigUp은 그 모델의 **소비자용 첫 실전 앱** 격이다.
- **검색 예**: “영상 속 얼룩말” → 얼룩말이 나오는 순간으로 재생 / “수면 얘기하는 부분” → 팟캐스트 해당 분 / “임대차 계약의 반려동물 조항” → PDF 해당 페이지에 하이라이트 / 영어로 검색해 벵골어·아랍어 메모 찾기 / (옵션) “백오프로 재시도하는 코드” → 에디터의 해당 줄.
- **정확 일치도**: 송장 번호·에러 코드·이름은 파일명·문서·스크린샷 속 글자에서 **글자 그대로** 매칭 — 의미 + 문자열 하이브리드.
- **사용법**: 폴더 선택 → 모델 1회 다운로드(865MB) → 어느 앱에서든 **⇧⌘Space**. 메뉴바에서 인덱싱 진행·일시정지.
- **프라이버시**: 인덱싱한 내용은 **Mac 밖으로 나가지 않음**. 온라인은 모델 다운로드와 하루 1회 업데이트 확인뿐(끌 수 있음), 계정·텔레메트리 없음.
- **조건**: Apple Silicon, macOS 14+. Windows·Linux는 예정.

## 왜 중요한가
LLM Wiki가 “정리된 지식을 에이전트가 **컴파일**”하는 레이어라면, DigUp은 **정리 전의 원재료를 찾는** 레이어다. 둘을 합치면 “다 옮겨 적어야 한다”는 PKM의 세금이 줄어든다 — 원재료는 로컬 시맨틱 검색으로 찾고, 반복해서 쓰는 지식만 위키로 승격. 클라우드에 개인 파일을 올리지 않는다는 점도 개인 OS 설계에 중요한 기준이다.
