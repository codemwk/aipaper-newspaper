## 한줄 요약
‘말하는 캐릭터’ 영상은 보통 **목소리 툴 → 영상 툴 → 립싱크 수정**을 오가야 했다. Chimera는 대본·목소리 연출·영상 프롬프트를 **한 화면, 한 번의 생성**으로 묶었다([Creators Toolbox, 10/21](https://creatorstoolbox.com/blog/elevencreative-chimera-talking-characters)).

## 만드는 순서
1. **캐릭터**: 이미지를 올리거나 ElevenCreative 아바타 선택.
2. **목소리**: 내 오디오를 올리거나, 대본을 쓰고 목소리를 고르거나 **캐릭터에 맞게 새로 디자인**.
3. **감정 연출**: Eleven v4 오디오 태그 — `[whispers]`(속삭임), `[laughs]`(웃음), `[yells]`(외침) 등으로 단어마다 분위기·타이밍 지정.
4. **영상 프롬프트**: 움직임·배경·조명·카메라를 평소처럼 서술, 화면비·해상도 선택 → 한 번에 생성.
- ElevenLabs의 표현: “Eleven v4가 **목소리에 감정을 넣고**, Seedance 2.5가 그 감정을 **얼굴로 옮긴다**.”

## 알아 둘 것
| 항목 | 내용 |
|---|---|
| 출시 | 10/21, ElevenCreative 안 |
| 영상 모델 | Seedance 2.5 — 최대 30초, 참조 최대 50개(이미지 30·영상 10·오디오 10). 해상도는 개발 문서엔 480p/720p, 홍보 페이지엔 ‘네이티브 1080p’로 서로 다르게 적혀 있음 |
| 요금 | Chimera 별도 가격·크레딧 공지 없음. 영상 생성은 유료 플랜 필요(ElevenLabs 문서) |
| 지역 | ElevenLabs는 Seedance 2.0·2.5가 미국에서도 이용 가능하다고 안내(다른 일부 영상 모델은 미국 제한) |

## 왜 중요한가
- **음성 회사가 ‘영상 스튜디오’가 되는 방식**: 영상 모델을 직접 만들지 않고, 남의 최상급 영상 모델(Seedance) 위에 **자기 강점(목소리의 감정 연출)**을 얹었다. 크리에이티브 플랫폼들이 모델 경쟁 대신 ‘조합과 연출 UI’로 차별화하는 흐름의 전형.
- **‘감정 태그’가 새로운 연출 언어**: 배우에게 “여기서 속삭여”라고 지시하던 것을 대본 안 태그로 쓴다. 광고·설명 영상·짧은 드라마에서 **한 장의 캐릭터 이미지로 일관된 인물**을 유지하기 쉬워진다.
- 주의: 실존 인물 이미지·목소리 사용은 각 플랫폼 정책과 초상권 문제가 따른다. 공지는 가격도, 1회 생성 비용도 밝히지 않았으니 실사용 전 크레딧 소모를 직접 확인할 것.
