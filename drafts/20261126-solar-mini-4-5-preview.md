## 한줄 요약
한국 회사 **업스테이지**의 작은 모델 새 버전이 미리보기로 나왔다. 핵심은 **싸고, 길게 읽고, 도구를 부를 수 있다**는 것([업스테이지 콘솔 문서](https://console.upstage.ai/docs/models/solar-mini-4-5-preview), [OpenRouter](https://openrouter.ai/upstage/solar-mini-4-5)).

## 사양
- **크기:** 총 **35B**, 활성 **3B.**
- **문맥:** **512K 토큰**, 최대 출력 **128K.**
- **기능:** 채팅, **추론 모드**, 구조화 출력, **도구 호출.**
- **학습 데이터 기준:** 2026년 8월.
- 회사 설명: 업스테이지 자체 학습법으로 **에이전트 성능이 크게 향상**(구체적 점수는 문서에 없음).
- **언어:** 문서상 지원 언어 표기는 영어.

## 가격·일정
- 정가: 입력 0.10 / 출력 0.40 / 캐시 0.01달러(100만 토큰당).
- **미리보기 기간 90% 할인 → 입력 0.01 / 출력 0.04 / 캐시 0.001달러.**
- **12/3 정식 출시.** 그날부터 `solar-mini-4-5-preview` 호출은 자동으로 정식 모델로 넘어간다.
- 사용처: 업스테이지 콘솔·Playground, OpenRouter, 온프레미스.
- API 입력은 학습에 쓰지 않고, 서비스 제공에 필요한 경우가 아니면 저장하지 않는다고 명시.

## 왜 중요한가
- 긴 문서·로그를 통째로 넣고 요약·분류·추출하는 **‘대량 잡일’**에 맞는 가격대다. 12/3 전까지는 사실상 공짜에 가까운 시험 기간이다.
- 에이전트 파이프라인에서 **비싼 모델 앞단의 필터·요약 담당**으로 붙여 보기 좋다.
- 주의: 지원 언어가 영어로만 표기돼 있어, 한국어 품질은 직접 확인이 필요하다. 성능 수치는 아직 공개되지 않았다.
