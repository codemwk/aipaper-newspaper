한줄 요약

TencentCloud/TencentDB-Agent-Memory는 대화·문서·코드를 재사용 가능한 네 가지 메모리 자산 — Chat Memory, Skill, LLM-Wiki, Code-Graph — 으로 바꿔 에이전트·프레임워크에 장착하는 팀 레벨 메모리 허브다(작성 시점 약 27,414 stars, 2026-09-28 갱신).

왜 눈에 띄나

  • 개인 Obsidian 위키와 달리 거버넌스·공유·장착(equip) 을 전제로 한다.
  • LLM-Wiki와 Code-Graph를 같은 제품 언어로 묶어, “노트 앱”과 “코드 지능” 사이의 간극을 메우려 한다.
  • 오픈소스 에이전트 스택이 모델 API에서 메모리 플레인 경쟁으로 이동 중임을 보여 준다.

왜 중요한가

퍼스널 OS·AI 저널리스트를 구독 상품화할 때, 단일 유저 Markdown만으로는 부족하고 팀/워크스페이스 메모리 SLA가 필요하다. 이 레포는 그 카테고리의 공개 신호다.
