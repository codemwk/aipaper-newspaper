[10/21] AI 모델: Domyn Edge — 40억 파라미터 에이전트 모델을 ‘완성품’이 아니라 ‘학습 중간 단계’째로 공개, 은행이 자기 용어로 이어서 키울 수 있게

이탈리아 Domyn이 10/20 Edge 단계적 공개 시작: 다단계 작업·도구 사용용 40억(4B) 파라미터 에이전트 모델, 이탈리아 CINECA 슈퍼컴퓨터 Leonardo(유럽 공공 컴퓨팅)에서 처음부터 학습. 사전학습·중간학습·지도 미세조정 단계별 중간 체크포인트부터 Hugging Face에 공개, 학습 코드는 GitHub, 후학습 단계들은 11월까지 순차 공개. 회사는 같은 크기 ‘완전 공개’ 모델 중 최고 성능이라고 주장. 로컬 하드웨어 실행. 고객·투자자: 이탈리아 정부, Fincantieri, BNY(투자자), 그 외 Eurizon·Rabobank·G42 투자.

분류: AI 모델

한줄 요약

대부분의 ‘오픈 모델’은 다 구워진 빵만 나눠 준다. 이탈리아 AI 회사 Domyn은 2026-10-20 반죽 단계부터 나눠 주기 시작했다. 40억 파라미터 에이전트 모델 Edge를 학습 중간 체크포인트, 학습 레시피, 도구와 함께 순차 공개한다(Domyn).

무엇이 공개되나

  • 모델: 다단계 에이전트 작업과 도구 사용에 맞춘 4B 소형 모델. 이탈리아 CINECA의 슈퍼컴퓨터 Leonardo에서 처음부터 학습했다(유럽 공공 컴퓨팅 자원 활용).
  • 단계적 공개: 오늘은 사전학습 → 중간학습 → 지도 미세조정 각 단계의 중간 체크포인트부터. 여러 후학습(post-training) 단계는 11월까지 이어서 나온다. 가중치는 Hugging Face, 학습 코드는 GitHub.
  • 성능 주장: “같은 크기의 완전 공개 모델 중 최고”(회사 발표 기준, 독립 검증 전).
  • 실행: 호환되는 로컬 하드웨어에서 돌릴 수 있어, GPU 인프라를 크게 갖추기 어려운 제조 현장 같은 곳을 겨냥한다.

왜 ‘중간 단계’를 주나

최종 모델은 이미 특정 방향(말투, 안전 규칙, 범용 지시 수행)으로 굳어 있다. 중간 체크포인트를 받으면 그 갈림길 이전으로 돌아가 내 데이터로 다른 방향으로 키울 수 있다. Domyn이 든 예시는 은행이 자기 용어와 거래 모니터링 절차에 맞춰 Edge를 이어 학습하는 것이다. 연구자에게는 ‘능력이 학습 중 언제 생기는지’를 들여다볼 창이 된다.

누가 만들었나

Domyn은 규제 산업용 ‘주권형(sovereign) AI’ 회사다. 이탈리아 정부, 조선사 Fincantieri, BNY(투자자이기도 함)와 일하고, Eurizon Capital·Rabobank·아부다비 G42가 투자했다. 6월 유럽연합 집행위원회가 선정한 EU 24개 공식 언어 오픈소스 모델 컨소시엄(EUROPA)도 이끈다.

왜 중요한가

요즘 소형 모델 경쟁의 축은 ‘더 똑똑한 4B’보다 ‘누가 마음대로 고칠 수 있나’로 옮겨 가고 있다. 큰 모델에 모든 일을 맡기는 대신, 반복되는 특정 업무(예: 내 매매 로그 분류, 브랜드 문서 태깅)는 작게 특화한 모델이 로컬에서 처리하고 어려운 판단만 큰 모델에 넘기는 구조 — Domyn도 Edge를 그런 ‘팀원’으로 설명한다. 단, 지금 공개된 건 중간 단계다. 바로 쓸 완성형 비서를 기대한다면 11월 최종 공개를 기다리는 게 맞다.
