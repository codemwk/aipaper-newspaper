[10/29] GitHub 트렌드: OpenBot(~3.2천★, 하루 +1천) — Codex·Claude·Grok을 ‘동료’처럼 각자 책상에 앉히는 데스크톱 앱. 작업 대기열·파일 주고받기·에이전트끼리 대화. 단, 지금은 ‘확인 없이 전부 허용’ 모드

nightly-labs/openbot이 이번 주 급상승(약 3,170★, 하루 +1,053). 여러 코딩 에이전트(Codex·Claude Code·Grok CLI·OpenCode·Gemini·Cursor CLI·Cline)를 각자의 작업 폴더·대화·작업 대기열을 가진 ‘상주 동료’로 만들고, 에이전트끼리 메시지·파일을 주고받으며 내장 브라우저를 조작한다. 공유 채널에서 작업 담당자를 정하고 위임·중지·재배정도 가능. 다만 개발 미리보기 단계라 에이전트가 첫 동의 후 ‘전체 접근·승인 없음’으로 실행되고, 라이선스는 비상업용(PolyForm Noncommercial)이다.

분류: GitHub 트렌드

한줄 요약

AI 에이전트를 “한 번 부르고 끝”이 아니라 “책상이 있는 팀원”으로 두고 싶은 사람이 늘고 있다. OpenBot은 그걸 데스크톱 앱 하나로 만든다(OpenBot README, 주간 급상승 정리).

무엇을 하나

  • 에이전트마다 책상: 각자 작업 폴더·대화·모델·추론 설정을 가진 상주 에이전트. 대화가 길어지면 맥락을 자동 압축.
  • 일 맡기기: 선입선출 작업 대기열(일시정지·재개·취소, 앱이 죽어도 유지).
  • 팀플레이: 에이전트끼리 메시지·답장·이미지·파일 전달. 공유 채널에서 담당자 1명을 정하고 위임·중지·재개·재배정·보관.
  • 브라우저와 컴퓨터: 에이전트가 여는 내장 브라우저, 선택적으로 macOS·Windows·Linux 화면 조작.
  • 지원: Codex, Claude Code, Grok CLI, OpenCode, Gemini, Cursor CLI, Cline + Ollama·LM Studio 등 로컬 모델 서버.

같은 흐름

  • 이번 주 함께 뜬 makecindy/cindy(10/28호 소개), 그리고 8만★의 Ruflo(Claude Code·Codex용 에이전트 무리·기억 하네스)도 같은 방향 — ‘에이전트 한 명’에서 ‘에이전트 팀 운영’으로.
  • 차이는 권한 기본값이다. Ruflo 콘솔은 ‘읽기+묻기’가 기본이고 자동 모드에서도 네트워크·결제·삭제는 확인을 받는다. OpenBot은 아직 반대쪽 끝에 있다.

왜 중요한가

에이전트 여러 명을 굴리면 병목은 모델이 아니라 “누가 무엇을 맡았고, 어디까지 허락했나”를 보는 화면이다. OpenBot이 뜨는 이유는 그 ‘팀 운영 화면’을 처음으로 그럴듯하게 보여 줬기 때문 — 권한 기본값이 바뀔 때가 실사용 시점이다.
