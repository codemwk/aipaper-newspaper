[11/4] 새로운 각도: 학습 없이 ‘가중치를 직접 고쳐 쓴다’ — MIT 연구진, 최신 LLM이 신경망 숫자를 읽고 고치고 처음부터 짰다. 0.016%만 바꿔 수학 7.9% → 48.1%

MIT CSAIL(Takehi·Teoh·Zhang·Khattab)이 11/2 ‘Weight-Space Programming’ 초기 결과를 공개. GPT-6 Astra가 가중치 숫자만 보고 어떤 게임용 네트워크인지 맞히고, 실패하는 자동차 제어 정책을 가중치 3.5% 수정으로 1,024회 전부 성공시키고, 도구·데이터 없이 Breakout 정책을 한 번에 써서 1억 스텝 PPO를 이겼다. Qwen3.5-0.8B의 ‘생각 루프’ 원인 방향을 찾아 가중치 0.016%를 빼 MATH-500 7.9%→48.1%. 반면 루프가 없는 Gemma 3 270M은 개선 못 함.

분류: 새로운 각도

한줄 요약

지금까지 신경망의 숫자(가중치)는 사람이 아니라 학습 알고리즘(경사하강법)만 쓰는 것이었다. 이 연구는 범용 LLM이 그 숫자를 코드처럼 읽고, 디버깅하고, 고쳐 쓰기 시작했다는 첫 신호를 보고한다(연구 블로그 11/2, The Register 11/3).

실험이 보여 준 것

종류실험결과
읽기같은 구조의 게임 정책 4개(가중치 17,253개)를 숫자로만 주고 “무슨 게임?”4개 모두 정답(예: Breakout은 ‘패들’이 맨 아래 줄에 있다는 흔적으로)
읽기작은 언어 모델의 중간 층만 주고 “무슨 언어로 학습?”Python·로마자 일본어·영어 3개 모두 정답, 복사 헤드(induction head)도 정확히 지목
고치기경사로 앞에서 멈추는 자동차 정책(17만 가중치)3.5% 수정, 도구 없이 한 번에 → 1,024회 전부 성공(원래 0%)
처음부터 쓰기규칙·소스코드만 보고 Breakout 정책 가중치를 텍스트로 작성517.4점 vs PPO 1억 스텝 15.8점
고치기(실제 LLM)Qwen3.5-0.8B “수학 잘하게”루프 원인 방향을 찾아 13만 가중치(0.016%) 수정 → MATH-500 7.9%→48.1%, IFEval 21.0%→62.3%

한계도 정직하게 적었다

  • 똑같이 학습시킨 두 Gemma 270M 중 아첨(sycophancy)하는 쪽을 가중치만으로는 못 골랐다. 어텐션 패턴을 보게 해 주자 맞혔다.
  • 원래 루프가 없는 Gemma 3 270M은 수학을 올리지 못했다. 연구진 표현대로, 가중치 편집은 “능력을 가리던 장애물을 치울 수는 있어도, 없는 능력을 더하지는 못했다.”

왜 새로운 각도인가

  • 오늘 GitHub 트렌딩 6위 heretic(하루 +699★)은 대조 프롬프트로 검열·‘AI 말투’·아첨을 학습 없이 걷어 내는 도구다. 사람이 짠 수학 기법으로 하던 ‘훈련 없는 수정’을, 이 연구는 LLM이 스스로 추론해서 한다. 같은 날 두 갈래가 나란히 보인다.
  • 가능성: 벤치마크를 돌리기 전에 가중치만 보고 백도어·숨은 능력을 감사, 데이터 없이 능력 추가·삭제, 구조가 다른 모델 사이에서 ‘회로’ 이식. 연구진은 다음 단계로 벤치마크와 하네스를 만드는 중이라고 했다.

주의

동료 심사 전 블로그 결과이고, 대부분 작은 네트워크다. 다만 모든 실험 로그를 공개했고(GitHub 로그), 수정된 Qwen 모델은 Hugging Face에서 제3자가 재구성·재평가했다.
