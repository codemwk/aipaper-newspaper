[11/11] GitHub 이번 주: ‘에이전트에게 맡기되 결정은 내가’ — 폰 조작 Pinky·Poki, 백그라운드 일꾼 agent-autoloop

11/4~11/10 AI 에이전트 저장소 주간 순위 상위에 ‘사람이 승인하는 자동화’가 몰렸다. 에이전트가 내 아이폰·안드로이드를 조작하되 결제·전송은 내가 허락하는 Pinky, 아이폰 전용 Poki, 터미널 에이전트를 백그라운드로 돌리다 애매할 때만 카드를 보내는 agent-autoloop.

분류: GitHub 트렌드

이번 주 분위기

Upstar의 주간 AI 에이전트 순위(11/4~11/10) 1위는 DIYgod/pinky(+1.7k★, 신규), 3위 KKKKhazix/agent-autoloop(+3.2k★), 4위 JosssphZhou/poki(+909★, 신규)였다. NVIDIA auto-ontology, vercel-labs/agent-desktop처럼 지난번 다룬 강자들 사이에서, 새로 뜬 것들의 공통 키워드는 ‘사람이 결정권을 쥔 자동화’다(Upstar 순위).

Pinky — 에이전트가 내 폰을 쓰되, 위험한 단계는 내가 클릭

  • Claude Code·Codex·Cursor 등 MCP를 쓰는 에이전트가 실제 아이폰(iOS 17.4+)·안드로이드(10~17)를 조작한다. 사용자는 컴퓨터 화면에서 지켜보다 승인하거나 직접 넘겨받는다.
  • 결제·거래·송금은 기본으로 대기하고, 설정에서 메시지 전송·주문·삭제·전화·앱 설치까지 승인 대상으로 늘릴 수 있다. 버튼 인식은 10개 언어.
  • 핵심 설계: 승인 규칙이 에이전트 지시문이 아니라 Pinky 게이트웨이에서 실행된다. 화면 속 텍스트가 에이전트를 꼬드겨도 스스로 승인할 수 없다.
  • 은행·지갑·비밀번호 관리자 앱은 기본으로 에이전트에게 안 보이고, 비밀번호·OTP 칸에는 입력 불가. 폰 PIN은 저장하되 에이전트는 볼 수 없다.
  • 네이티브 앱(16~22MB), Apache-2.0, 계정 불필요(GitHub).

Poki — 아이폰을 ‘사람처럼’ 쓰는 실험

에이전트에게 “내 아이폰에 Poki 설치해 줘”라고 하면 설치 스킬이 가능한 단계를 대신하고, Apple 계정 입력·신뢰 탭 같은 iOS가 요구하는 일만 사람이 한다. 사람처럼 타이핑하는 전용 키보드는 아직 기기 검증 전 실험 단계라고 스스로 밝힌다. AGPL-3.0(GitHub).

agent-autoloop — 터미널 에이전트를 ‘출근’시키기

Claude Code·Codex 같은 CLI 에이전트는 보통 사람이 터미널을 지켜야 돌아간다. agent-autoloop은 정해진 시간 작업·새 이슈·에러 같은 이벤트를 받아 규칙대로 에이전트에게 배정하고, 에이전트는 한 바퀴 일하고 종료한다. 데이터 삭제·재시작·결제·외부 메시지 같은 애매한 결정만 카드로 슬랙·디스코드·飞书 등에 보내고, 답하면 이어서 끝낸다. 대기 중에는 프로세스도 토큰도 쓰지 않는다. 클라우드 서버 불필요, 진행 상황·토큰·비용은 명령 한 줄로 확인(GitHub).

왜 중요한가

지난번 저장하신 LYIO 태그(에이전트 하네스·메신저→작업 흐름)와 정확히 이어지는 흐름이다. 이제 경쟁 포인트는 “에이전트가 얼마나 많이 하나”가 아니라 “무엇을 반드시 사람에게 물어보게 강제하나, 그 강제를 어디서 집행하나”다. 프롬프트로 부탁하는 안전장치는 프롬프트 인젝션에 뚫리고, 게이트웨이·서버에서 집행하는 안전장치는 뚫리기 어렵다. 아래 트레이딩 MCP 기사와 같은 원리다.

주의

폰 조작 에이전트는 개발자 모드·자동화 권한을 요구한다. 업무폰·금융 앱이 있는 기기라면 별도 기기나 에뮬레이터에서 먼저 시험할 것.
