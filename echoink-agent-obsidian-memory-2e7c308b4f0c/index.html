[11/9] 세컨드 브레인: EchoInk Agent 2.8.10 — ‘보이고 고칠 수 있는’ 장기 기억과 기억 별자리, 그리고 읽어야 할 개인정보 조항

Obsidian 플러그인 EchoInk(11/6, 2.8.10)는 장기 기억을 열람·수정·내보내기·삭제·고정할 수 있게 하고, 지식 점검(체크업)에서 수정안을 미리 본 뒤 확정한다. 기본 기능은 MIT, 일부 PRO는 별도 라이선스. 로컬 저장이지만 모델 요청에는 노트가 전송된다.

분류: 세컨드 브레인

한줄 요약

EchoInk는 Obsidian 사이드바에 사는 개인 지식 에이전트다. 11/6 2.8.10에서 ‘1인 회사’(모듈 담당 에이전트), 기억 별자리(memory constellation), 지식 체크업이 들어왔다(Obsidian 커뮤니티 플러그인 페이지).

눈여겨볼 설계

  • 보이고 고칠 수 있는 장기 기억: 열람, 수정, 내보내기, 삭제, 복원, 고정이 가능하고, 기억이 ‘흐려져도’ 삭제되지는 않는다. 지식 검색은 개인 기억 폴더를 제외한다.
  • 지식 체크업: 도메인 트리를 정리하고 빠른/깊은 점검을 돌린 뒤 고칠 내용을 미리 보고 확인한다. 손으로 쓴 내용은 보존하며 증분 갱신한다. (깊은 점검은 모델 크레딧 사용)
  • @Agent 편집: 노트 안에서 부르면 수정안을 제안하고 확인 후에만 쓰며 되돌리기 가능(PRO).
  • MCP 서버(PRO): 같은 컴퓨터의 외부 에이전트에 지식·프로필·기억을 읽기 전용으로 공유, 기본 꺼짐, 루프백 주소만 사용.

읽어둘 점

  • 데이터는 로컬에 저장되고 기본으로 볼트 전체를 올리지 않는다. 다만 선택한 모델 서비스에는 필요한 노트·첨부·기억이 전송된다.
  • 라이선스는 컴포넌트별: 기반은 MIT, 재무·영어 일기·PRO 경로는 별도 PRO 라이선스(완전한 오픈소스 아님). 계정·스킬 다운로드는 echoink.cn 서버를 거치고, 클라이언트 텔레메트리는 없다고 명시.
  • 업그레이드 전 볼트·설정 백업을 권고, 다운그레이드는 플러그인 파일만 교체하는 방식이 지원되지 않는다. 플러그인 크기가 Obsidian Sync Standard의 5MB 한도를 넘는다. 모바일은 베타.

왜 중요한가

LLM Wiki류의 공통 약점은 에이전트가 쌓은 기억을 사람이 점검할 수 없다는 것이다. ‘기억을 사람이 보고 고치는 UI’와 ‘수정안 미리보기 후 확정’은 Obsidian 볼트 위생의 좋은 기준선이다. 저장해 두신 obsidian 태그(기억 최신성) 글들과 같은 질문이다.

주의

검증된 성능 비교는 없고, 기능 대부분이 데스크톱 전용이거나 PRO다. Windows·Linux 네이티브 검증은 불완전하다고 개발자가 밝혔다.
