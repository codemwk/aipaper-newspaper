[11/10] AI 모델: 앤트그룹 Ling-3.2-flash — 텍스트·이미지·영상을 한 모델로, 560B MoE(활성 25B)·100만 토큰. OpenAI·Anthropic 호환 API, 출시 후 2주 무료

앤트그룹 Ling 팀이 11/5 Ling-3.2-flash를 냈다. 처음부터 텍스트·이미지·영상을 함께 받는 네이티브 멀티모달 MoE로 총 560B, 추론당 25B 활성, 컨텍스트 100만 토큰. 복잡한 시각 이해, 여러 단계의 에이전트 작업, 3D 이해·상호작용, 의료 멀티모달을 겨냥. OpenAI·Anthropic 프로토콜 호환 API로 바로 붙일 수 있고 첫 2주는 무료.

분류: AI 모델

한줄 요약

중국 빅테크의 ‘플래시급 멀티모달’ 경쟁에 앤트그룹이 합류했다. Ling-3.2-flash는 11/5 공개된 네이티브 멀티모달 MoE로, 총 560B 파라미터 중 추론 한 단계마다 25B만 쓰고, 100만 토큰 컨텍스트를 지원한다(TechNode, 11/6, Ant Ling 개발자 문서).

무엇이 다른가

  • 입력: 텍스트·이미지·영상을 처음부터 함께 학습한 구조(나중에 비전 인코더를 붙인 방식이 아니라는 뜻의 ‘네이티브’).
  • 겨냥한 일: 복잡한 시각 이해, 여러 단계의 장기 에이전트 작업, 3D 이해와 상호작용, 의료 멀티모달.
  • 접근: 온라인 채팅과 함께 OpenAI 호환·Anthropic 호환 API를 제공한다. 기존 에이전트 하네스에서 엔드포인트만 바꿔 시험해 볼 수 있다는 뜻이다. 출시 후 2주간 무료(11/19 전후까지로 추정).

같은 주의 맥락

이번 주에만 텐센트 Hy4(오픈 가중치, 컴퓨터 사용), 메이투안 LongCat 2.5, 바이두 ERNIE 5.5 Flash Base, Moonshot Kimi K3.1 Pro 등 중국발 멀티모달·에이전트 모델이 몰렸다. 공통점은 100만 토큰 컨텍스트 + 에이전트 작업 + 공격적인 가격이다. Ling-3.2-flash는 그중 두 회사의 API 규격을 모두 흉내 내 갈아타기 비용을 낮춘 쪽이다.

왜 중요한가

긴 영상을 통째로 넣고 “이 장면들에서 제품이 나오는 구간만 골라 요약해 줘” 같은 일을 하려는 콘텐츠 제작자, 화면을 읽어야 하는 에이전트 빌더에게 시험해 볼 만한 후보가 하나 늘었다. 무료 기간에 내 작업 몇 개로 직접 비교해 보는 게 가장 정확하다.

주의

벤치마크·가격(무료 기간 이후)·가중치 공개 여부는 이번 발표에서 확인하지 못했다. 성능 주장은 회사 설명 기준이다.
