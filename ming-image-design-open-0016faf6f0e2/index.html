[11/27] 디자인: ‘UI 시안·상세페이지·공간 렌더’ 전용 이미지 모델이 MIT 오픈소스로 — 앤트그룹 Ming-Image-0.2-Design, Figma식 구조화 프롬프트로 글자까지 정확하게

앤트그룹 inclusionAI가 11/25 가중치를 올리고 11/26 Ming-Image-0.2-Design을 공개했다. 이커머스 대표 이미지, UI 디자인 시안, 공간 렌더링을 겨냥한 6B 디자인 특화 이미지 모델로, 복잡한 구도·조명·텍스트 렌더링을 개선했고 MIT 라이선스라 상업적으로 쓸 수 있다. Figma 스타일 JSON 구조화 프롬프트를 권장하며, 디자인을 투명 레이어(캐릭터 부위 단위까지)로 나누는 Layer 모델은 다음 주 공개 예정이다.

분류: 디자인

한줄 요약

범용 이미지 모델로 UI 시안을 뽑으면 글자가 깨지고 레이아웃이 흐트러진다. Ming-Image-0.2-Design은 처음부터 “디자인 산출물”을 목표로 만든 오픈 모델이다(Hugging Face 모델 카드, GPUJournal, 11/26).

무엇을 하나

  • 겨냥한 산출물: 이커머스 대표 이미지(소재 디테일·제품 정보), 웹/UI 디자인 시안(여러 섹션 레이아웃과 일관된 스타일), 공간 디자인(구조·빛·그림자).
  • 개선점: 복잡한 구도, 사실적인 조명, 텍스트 렌더링. 모델 카드 예시는 랜딩 페이지의 내비게이션·헤드라인·버튼·카드 3장 문구를 “적힌 그대로 렌더링, 문구 추가 금지”로 지시한다.
  • 구조화 프롬프트: 더 좋은 결과를 위해 Figma 스타일 JSON 프롬프트와 프롬프트 보강기(Ling-3.0-flash-VL 또는 Qwen3.8-27B)를 권장.
  • 웹으로 잇기: 같은 회사 언어 모델 Ling-3.2-flash와 함께 쓰면 디자인 콘셉트를 인터랙티브 페이지로 바꿀 수 있다고 설명.
  • 레이어 분해: 전작 0.1-Design-Layer가 디자인을 투명 레이어로 나눴고, 새 Layer 모델은 캐릭터 부위 단위까지 나눈다(GPUJournal에 따르면 다음 주 공개 예정 — 아직 출시 전).

실사용 정보

  • 파라미터: DiT 6B(모델 카드 표 기준). 기본 2048×2048, 샘플링 12단계.
  • 검증된 하드웨어는 80GB GPU 한 장(H100·A100 80GB급). 개인 PC보다는 GPU 임대나 서비스 형태가 현실적이다. 서빙은 vLLM-Omni 권장.
  • MIT 라이선스 — 상업 이용·수정·재배포 가능.
  • 앤트는 Artificial Analysis 텍스트→이미지 차트에서 오픈 웨이트 1위(11/25 기준)라고 주장(회사 주장, 독립 재현 전).

왜 중요한가

  • 디자인 시스템을 에이전트에게 읽히는 흐름(DESIGN.md, Stitch, Astryx)과 맞물리면, “토큰·컴포넌트 규칙 → 구조화 프롬프트 → 시안 이미지 → 레이어 분해 → 코드”라는 파이프라인의 이미지 단계가 오픈소스로 채워진다.
  • 실제 작업에선 이미지 시안을 최종 UI로 쓰기보다, 무드·레이아웃 탐색과 상세페이지 대량 변형에 쓰는 것이 맞다. 레이어 모델이 나오면 ‘편집 가능한 시안’으로 한 걸음 더 간다.
  • 주의: 순위·성능은 앤트 발표, Layer 모델은 아직 예고 단계다.
