[11/26] 세컨드 브레인: ‘말하면 받아 적고, 기억은 보여 주는’ 쪽으로 — Genspark SecondBrain VoicePad 출시, n8n의 개인 에이전트 Nod는 내가 고칠 수 있는 기억으로 GitHub 급상승

Genspark가 11/24 85g짜리 데스크톱 기기 SecondBrain VoicePad를 내놨다. 키 다섯 개와 마이크 두 개로 속삭여도 받아 적고, 군말을 지운 글을 아무 앱에나 넣으며, 회의록 에이전트 같은 작업을 키 하나에 묶는다(1월 출하). 같은 주 GitHub에선 n8n Labs의 오픈소스 개인 에이전트 Nod가 일주일에 1천 개 넘는 별을 받았다. 몇 달치 대화를 기억하고, ‘일을 어떻게 했는지’ 메모를 남겨 다음에 쓰며, 그 기억을 사용자가 보고 고치고 지울 수 있다.

분류: 세컨드 브레인

한줄 요약

세컨드 브레인의 병목은 늘 두 곳이다. 넣는 입구(캡처)와 꺼내 쓰는 기억. 이번 주 두 제품이 각각 그 자리를 건드렸다.

입구: Genspark SecondBrain VoicePad (11/24 발표)

  • 무엇: PC·Mac에 블루투스로 붙는 키 5개 + 마이크 2개 데스크톱 기기. CNC 알루미늄, 85g(PR Newswire).
  • 받아쓰기: 들어 올려 보통 목소리나 속삭임으로 말하면, 군말과 말 더듬기를 지운 깔끔한 글이 지금 쓰는 앱에 바로 들어간다. 마이크가 입 가까이 있어 시끄러운 사무실에서도 안정적이라는 설명.
  • 키마다 할 일 지정(무료 Genspark Super App에서): ChatGPT·Claude·Notion 등 앱 열기, 받아쓰기 시작, 회의록 에이전트(두 번 눌러 녹음 → 끝나면 요약), 복사·붙여넣기 같은 단축키, 여러 단계를 묶은 Smart Actions(예: 한 번 누르면 Claude를 열고 받아 적은 질문을 제출).
  • 일정: 지금 사전 주문, 첫 생산분 2027년 1월 출하. 가격은 보도자료에 없다.

기억: n8n Labs ‘Nod’

  • 11/10 연구 미리보기로 나온 오픈소스(Apache 2.0) 개인 에이전트. 이번 주 GitHub 주간 목록 4위(약 3,500★, +1,011)에 올랐다(n8n 블로그, GitHub, GitStock).
  • 내 컴퓨터 안 샌드박스와 자체 브라우저로 구독 해지, 가격 감시, 거래처 포털에서 청구서 내려받기 같은 일을 끝까지 한다. 보내기·결제·게시·삭제 전엔 별도 확인 단계가 내가 요청한 일인지 검사한다.
  • 세컨드 브레인 관점의 핵심 세 가지:

- 몇 달치 대화를 기억. 장기 기억 벤치마크 LongMemEval 93.2%(회사 발표).
- ‘일을 어떻게 했는지’ 메모를 남겨 다음에 다시 쓰고, 사이트가 바뀌면 메모를 고친다 — 사실 기억이 아니라 방법 기억(절차 지식)을 쌓는 셈.
- Nod가 나에 대해 저장한 것은 전부 보고, 고치고, 지울 수 있다. 데이터·기억·로그인은 Nod가 도는 기기에 남는다.

  • 비용: 앱은 무료, 모델 비용은 내 API 키나 ChatGPT 요금제(로컬 모델도 가능). 작업마다 영수증, 월 한도, 5달러 넘으면 확인. 노트북이 잠들면 멈춘다(상시 켜 둔 Mac mini·서버 권장).

왜 중요한가

  • LLM Wiki·Obsidian 에이전트를 쓰는 입장에서 보면 그림이 맞춰진다. 입구는 음성 한 번, 정리는 위키, 그리고 에이전트는 “무엇을 아는지”뿐 아니라 “어떻게 했는지”를 기록해야 다음 일이 빨라진다.
  • Nod의 “내가 볼 수 있고 고칠 수 있는 기억”은 Obsidian 볼트 원칙(내 파일, 내 소유)과 같은 방향이다. 개인 에이전트를 고를 때 기억 열람·수정·삭제 가능 여부를 첫 체크 항목으로 둘 만하다.
  • 주의: VoicePad는 가격 미공개·아직 출하 전, Nod는 연구 미리보기이며 93.2%는 자체 측정이다.
