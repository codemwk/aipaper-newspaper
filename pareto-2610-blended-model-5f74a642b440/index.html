[10/19] AI 모델: Pareto 26.10 정식판 — 여러 모델이 한 요청을 같이 푸는 ‘블렌드 모델’, 가격은 입력 $0.80·출력 $3.20로 26.9 대비 최대 68% 인하, 구독 토큰은 두 배

Unbiased AI(10/15): 10/1 프리뷰였던 Pareto 26.10을 정식 릴리스로 전환, API의 pareto 별칭이 26.10을 가리킴. 요금은 100만 토큰당 입력 $0.80·캐시 $0.03·출력 $3.20(26.9는 $2.50·$0.25·$7.50) — 프리뷰 가격을 그대로 확정. 컨텍스트 100만 토큰. ‘블렌드 모델’: 요청마다 여러 프런티어·오픈 모델이 함께 작업. 구독자 주간 한도 2배 — Personal 주 5,000만 토큰 $10, Personal Max 주 6억 토큰 $100. 26.9는 계속 제공, OpenRouter·Cloudflare 경유 트래픽은 데이터 무보존 등급. 평가 하네스 공개.

분류: AI 모델

한줄 요약

“어떤 모델을 쓸까?” 대신 “여러 모델을 한 번에 섞어 쓰면 어떨까?” — Unbiased AI의 Pareto는 이 질문에서 나온 서비스다. 9월 ‘스텔스’로 소개했던 26.9에 이어, 2026-10-15 Pareto 26.10이 프리뷰를 졸업했다. 눈에 띄는 건 성능 주장보다 가격이다(Unbiased AI 블로그).

무엇이 바뀌었나

  • 정식 전환: API에서 pareto 별칭이 이제 26.10을 가리킨다. 고정하려면 pareto-26.10, 예전 버전이 필요하면 pareto-26.9도 계속 쓸 수 있다.
  • 가격 확정 (100만 토큰당):
버전입력캐시 입력출력
26.9$2.50$0.25$7.50
26.10$0.80$0.03$3.20

프리뷰 때 “졸업해도 가격을 올리지 않겠다”고 약속했고 지켰다. 입력은 68%, 출력은 57% 싸졌다.

  • 컨텍스트 100만 토큰. OpenRouter에도 같은 가격으로 올라 있고 도구 호출을 지원한다(OpenRouter).
  • 구독자 한도 2배(같은 가격): Personal은 주 5,000만 토큰에 월 $10, Personal Max는 주 6억 토큰에 $100. 채팅 기본값도 26.10.

‘블렌드 모델’이란

Pareto는 하나의 신경망이 아니다. 회사 설명에 따르면 요청마다 여러 프런티어 모델과 오픈 모델이 함께 작업한다. 사용자는 모델 하나를 부르듯 쓰지만, 뒤에서는 여러 모델의 답을 조합하는 셈이다. 그래서 회사는 벤치마크 점수(10/1 프리뷰 측정치)보다 “우리 평가 하네스를 직접 돌려 보고, 무거운 실제 작업에 붙여 청구서를 비교하라”고 권한다.

왜 중요한가

에이전트 시대의 비용은 대부분 출력 토큰과 반복 호출에서 나온다. 같은 일을 1/3 가격으로 할 수 있다면, 성능이 조금 낮아도 바꿀 이유가 생긴다 — 이번 주 Replit이 비용·성능을 이유로 기본 모델을 바꾼 것과 같은 흐름이다. 주의할 점: 블렌드 모델은 어떤 모델이 어떤 비율로 답했는지 투명하지 않을 수 있고, 데이터 처리 조건이 경로마다 다르다(OpenRouter·Cloudflare 경유는 데이터 무보존 등급, 직접 API는 요금제별 약관 확인). 민감한 자료를 넣기 전에 Data Policy부터 읽자.
