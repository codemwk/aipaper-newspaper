[10/17] GitHub 트렌드: esp32-iphone-agent(~2.8K★) — $7짜리 보드 하나로 AI가 ‘진짜 아이폰’을 쓴다, AirPlay가 눈·USB 마우스가 손, 탈옥·맥·개발자 계정 없이

onehumanbeing/esp32-iphone-agent(10/12 생성, MIT, ~2.8K★, 이번 주 신규 레포 3위): ESP32-S3 보드가 아이폰 화면 미러링(AirPlay)을 받아 BLE로 앱에 넘기고, USB HID 마우스·키보드로 탭·스와이프·입력. 두뇌는 같은 아이폰의 앱 — OpenAI 호환 비전 모델에 스크린샷을 보내 계획·실행. 포인터 보정, 실행 기록 재생·내보내기. iOS 18+. ‘컴퓨터 없는’ 버전으로 진화.

분류: GitHub 트렌드

한줄 요약

AI 에이전트가 웹 브라우저나 데스크톱을 조작하는 건 익숙해졌지만, 아이폰은 애플이 외부 자동화를 거의 막아 둔 영역이다. 이번 주 GitHub 신규 레포 3위에 오른 esp32-iphone-agent는 우회로를 하드웨어로 냈다 — 7달러짜리 ESP32 보드를 꽂으면 AI가 사람처럼 화면을 보고 손가락처럼 누른다(GitHub).

어떻게 작동하나 (코드 없이)

  • 눈 — AirPlay: 보드가 자기 Wi-Fi 핫스팟을 열고 아이폰의 ‘화면 미러링’ 목록에 *ESP32 Agent*로 뜬다. 보드는 영상을 해독하지 않고 그대로 BLE로 앱에 넘긴다. 아이폰은 그동안 셀룰러 데이터로 AI 모델과 통신.
  • 손 — USB HID: 보드가 표준 USB 마우스·키보드로 인식된다. 아이폰의 AssistiveTouch를 켜면 마우스 포인터가 생기고, 클릭은 탭, 드래그는 스와이프가 된다.
  • 두뇌 — 같은 아이폰의 앱: 앱이 화면을 캡처해 OpenAI 호환 비전 모델(어떤 것이든)에 보내고, ‘계획자’와 ‘실행자’가 탭·스와이프·그리기·타이핑·홈 버튼 같은 동작을 고른다. 다이내믹 아일랜드에 진행 상황 표시.
  • 오차 잡기: 포인터가 상대 좌표라 앱이 위치를 추적하고, 정밀한 탭 전엔 포인터를 흔들어 화면에서 찾아 보정한다. 동작 뒤엔 화면이 바뀌었는지 모델에 알려 준다. 연결이 끊기면 멈췄다가 같은 단계에서 재개.
  • 복기: 모든 실행이 폰에 남아 탭·스와이프가 그려진 채 단계별 재생, 스크린샷·동작 기록을 내보내 다른 에이전트가 분석하게 할 수 있다.
  • 예시 작업: “월·화 반복 오전 8시 알람 맞추고 저장” — 에이전트가 자기 앱을 나가 시계 앱을 열고 휠을 돌려 시간을 넣고 요일을 체크한다.

숫자와 조건

MIT 라이선스, 10/12(KST) 생성, 현재 약 2,840★. iOS 18 이상, XIAO ESP32-S3 계열 보드. 초기 버전(맥/리눅스 컴퓨터가 미러링 수신)은 v0.1.0으로 남겨 두고, 지금은 보드+폰만으로 돈다. 제작자는 README에 “이슈·댓글에 올라오는 ‘빠른 설치’ 한 줄 명령은 우리 것이 아니니 실행하지 말라”는 경고를 붙였다 — 인기 레포를 노린 악성 명령이 실제로 돌고 있다는 뜻이다.

왜 중요한가

이 프로젝트가 뜨는 이유는 “API가 없는 앱도 에이전트가 쓸 수 있다”는 점이다. 은행·증권·배달 앱처럼 공식 연동이 없는 서비스, 혹은 모바일 UI QA(디자인 시안대로 화면이 동작하는지 반복 확인)에 바로 응용된다. 반대로 위험도 크다: 화면을 보는 AI가 잠금이 풀린 폰 전체를 만지는 구조라, 금융 앱이나 개인 메시지가 있는 메인 폰보다는 테스트용 공기계에서 시작하는 게 맞다. Shareuhack 주간 리포트도 “실제 기기를 제어하는 에이전트는 상위권이라는 이유만으로 실사용에 넣지 말라”고 했다.
