[11/5] GitHub 트렌드: 이번 주 인기는 ‘에이전트에게 감각 기관 달기’ — 역공학·데스크톱 조작·귀·취향까지

10/28~11/4 AI 저장소 별 증가 순위를 보면 에이전트에게 새 능력을 붙이는 도구가 강세다. 앱·바이너리를 역공학하는 rea(+2.9만), 세션 기억 claude-mem(+8.4천), 데스크톱 AI 팀 Orkas(+247%), 안드로이드 온디바이스 에이전트 Mika, 소리를 듣는 earshot, 비용 통제 TokenEconomizer. Vercel의 agent-desktop은 스크린샷 대신 OS 접근성 트리로 앱을 조작한다.

분류: GitHub 트렌드

한줄 요약

이번 주 GitHub에서 빨리 큰 저장소들은 대부분 에이전트에게 눈·손·귀·기억을 붙이는 부품이다(800개 저장소 일일 스냅샷 기준, AgentDataCo 11/4).

지금 뜨는 기능들

  • 역공학 — rea (+29,489★): 앱 동작부터 네이티브 바이너리까지 에이전트로 뜯어보는 도구. 관련 ‘awesome’ 목록 3개가 함께 크고 있다. 닫힌 앱의 동작을 이해해 자동화·대체 도구를 만드는 흐름.
  • 기억 — claude-mem (+8,352★), hindsight (+4,077★): 세션 사이에 맥락을 이어 주는 메모리. 지난번 저장하신 claude-mem이 이번 주에도 상위권이다.
  • 데스크톱 팀 — Orkas (+247%): 로컬 우선 MIT 오픈소스. ‘사령관’이 목표를 할 일로 쪼개 여러 에이전트에게 맡긴다.
  • 폰 조작 — Mika (Kotlin, +6,022★): 안드로이드에서 앱·웹을 직접 조작하는 온디바이스 에이전트.
  • 귀 — earshot (+24%): CPU만으로 에이전트가 소리를 듣고 검토·생성.
  • 돈 — microsoft/TokenEconomizer (+45%): 코딩 에이전트 비용을 경험 기반으로 통제. 지난번 저장하신 headroom·ponytail(이번 주 +5,543★) 같은 ‘토큰 절약’ 계열이다.

주목: Vercel agent-desktop

스크린샷을 보고 픽셀을 찍는 대신, macOS·Windows·Linux의 접근성 트리(화면 요소 목록)를 JSON으로 읽고 요소마다 붙은 ref로 클릭·입력한다. 모델은 들어 있지 않고 루프는 내 에이전트가 돈다. 별은 현재 약 1.5만 개, Apache-2.0(저장소). README는 스냅샷에 개인 화면 내용이 담길 수 있으니 공개 로그에 올리지 말라고 경고한다.

왜 중요한가

작업 영역이 코드에서 실제 앱·폰·데스크톱으로 넓어지고 있다. 스크린샷 방식보다 접근성 트리 방식이 싸고 안정적이라, MT5 같은 데스크톱 앱 자동화를 생각할 때도 눈여겨볼 접근이다.
