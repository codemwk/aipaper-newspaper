[11/8] 디자인: Figma 에이전트가 ‘편집 가능한 벡터’를 그린다 — 스트로크·레이어 그룹·스타일 참조, 이미지는 클릭 한 번에 객체 선택

Figma가 11/5 에이전트의 벡터 일러스트·아이콘 생성을 개선했다. 선은 채우기 대신 스트로크로, 레이어는 기능별로 묶고, 기존 일러스트를 스타일 참조로 붙이면 브랜드에 맞는 아이콘을 대량 생성. 11/6엔 이미지 속 객체를 클릭하면 자동 선택(macOS 앱). 같은 주 Subframe도 에이전트가 캔버스에서 시안 여러 개를 나란히 만드는 기능을 냈다.

분류: 디자인

한줄 요약

AI가 만든 아이콘의 고질병은 “보기엔 그럴듯한데 고칠 수가 없다”였다. Figma는 11/5 업데이트에서 에이전트 생성 벡터를 디자이너가 이어서 편집할 수 있는 구조로 바꿨다(Figma 릴리스 노트).

무엇이 바뀌었나

  • 스트로크로 그린다: 라인 작업을 채우기(fill)가 아닌 스트로크로 만들어, 다시 그리지 않고 선 굵기·끝 모양을 바꿀 수 있다.
  • 기능별 레이어 그룹: 독립 레이어가 직관적으로 묶여 반복 수정이 쉽다.
  • 스타일 참조: 기존 일러스트를 붙이면 그 스타일로 추가 컴포넌트·온브랜드 아이콘을 대량 생성.
  • 바로 애니메이션: 깔끔한 레이어 구조라 Figma Motion으로 사람이든 에이전트든 움직임을 붙일 수 있다.
  • 11/6 이미지 편집: Select area 도구에서 객체를 클릭하면 자동 선택 — 테두리를 손으로 따지 않아도 분리·삭제(macOS 데스크톱 앱 한정).

같은 주 경쟁 소식

Subframe은 11/4 에이전트가 캔버스에서 실시간으로, 시안 여러 개를 나란히 만들고 선택한 요소만 정밀 수정하도록 개편했다. Subframe 앱 안에서도, 원격 Subframe MCP로 외부 에이전트에서도 된다(Subframe 체인지로그).

왜 중요한가

디자인 에이전트 경쟁의 축이 “얼마나 예쁘게 한 장 뽑나”에서 “뽑은 결과를 사람이 얼마나 쉽게 이어받나”로 옮겨가고 있다. 스트로크·레이어 구조·스타일 참조는 디자인 시스템 관점의 편집 가능성이다. 저장해 두신 디자인 에이전트(Figma Agent, Magic Patterns, Lovart) 흐름의 연장선이다.

주의

품질 비교 수치는 공개되지 않았다. 객체 선택은 macOS 앱에서만. 에이전트 사용량은 지난 11/6에 다룬 Figma AI 크레딧 정책의 영향을 받으니 팀 요금제에서 확인할 것.
