[11/14] 세컨드 브레인: 회의 녹화가 ‘두 번째 뇌’가 된다 — Clipto Studio, 몇 년치 회의·통화 영상을 ChatGPT·Claude가 내 컴퓨터에서 검색

Clipto가 11/12 회의·발표·화상통화 녹화를 AI 비서가 검색하고 분석하게 하는 메모리 플랫폼 Clipto Studio를 냈다. MCP로 ChatGPT·Claude 등에 연결되고, 모델은 맥·윈도 PC에서 로컬로 돈다. 말·화자 목소리·표정·화면 속 시각 정보를 미리 색인해, ‘프로젝트 범위가 언제 바뀌었나’ 같은 질문에 타임스탬프와 원본 링크로 답한다.

분류: 세컨드 브레인 / PKM

한줄 요약

노트 앱의 기억은 대부분 글이다. 하지만 업무 지식의 상당 부분은 회의 녹화와 통화 안에 묻혀 있다. Clipto Studio는 이 영상들을 AI 비서가 검색할 수 있는 데이터셋으로 바꾼다(AI Agent News, SiliconANGLE 11/12 보도 요약).

어떻게 작동하나

  • 데스크톱 앱이 녹화 파일을 미리 색인한다. 말(전사), 화자별 목소리, 표정, 화면에 나온 시각 정보까지 구조화한다. 모델은 맥·윈도 PC에서 로컬로 돈다.
  • 앱의 MCP 탭에서 ChatGPT·Claude 등에 연결하면, 비서가 이 메타데이터를 검색해 타임스탬프와 원본 링크가 붙은 답을 준다(Clipto MCP 안내).
  • 회사가 든 예시: 6개월 넘는 통화 기록에서 프로젝트 범위가 바뀐 시점 찾기, 수천 건 통화에서 고객 불만과 직접 인용 뽑기.
  • 최근 구글 연구 과학자 출신 메이 한(Mei Han) 박사를 수석 과학자로 영입해 경량 멀티모달 구조를 맡겼다.

주의할 점

  • 녹화에는 동의 없이 공유되면 안 되는 정보가 많다. 로컬 색인이라도 AI 비서와 연결하면 검색 결과 일부가 비서 쪽으로 전달된다. 어떤 폴더를 연결하고 누가 접근하는지 먼저 정해야 한다.
  • 요금과 지원 언어(한국어 전사 품질 포함)는 보도에 나와 있지 않다.

왜 중요한가

LLM Wiki나 옵시디언 볼트는 “적어 둔 것”만 기억한다. 클라이언트 미팅에서 오간 말, 결정이 바뀐 순간은 대부분 적히지 않는다. 지난 11/11 소개한 ‘회의 녹음 28개를 옵시디언 위키로’ 사례가 녹음 → 노트 변환이었다면, Clipto는 녹화 자체를 검색 가능한 기억으로 두는 반대 접근이다. 스튜디오 운영이라면, 결정 사항은 위키로 옮기고 원본은 Clipto 같은 색인에 남기는 이중 구조가 현실적이다.
